# モンスター設定

`monsters.csv` は114種類のモンスター設定の正本です。値は旧方式の階層倍率を適用せず使用します。

変更後は `python scripts/compile-monsters.py` で `dist/monster-data.js` を生成し、`python scripts/compile-monsters.py --check` と `node tests/game.cjs` で検証してください。確定名を変更・追加する場合、生成スクリプトの名前→固定ID対応も更新します。行の並べ替えは自由です。モンスターを追加する場合は、48×48・グレー4値の固有画像を `dist/assets/monsters/<ID>.png`（原画は `art-src/monster-sprites-v3/`）に置き、`dist/game.js` の `MONSTER_SPRITES` にIDを登録します（`node tests/monster-sprites.cjs` が漏れを検出します）。

- 通常遭遇は該当階層の守護者以外から1〜3列を抽選。各列の頭数は「群れの数」。守護者は各階の下り階段のマスに1体。
- 1〜10Fに固有の敵と各階1種の守護者を設定しています。出現階層は「1F・2F」のように複数指定できます。
- 行動抽選は毎ターン、敵1体につき1回。逃走→仲間呼び→ブレス→呪文の確率帯を割り当て、残りは物理攻撃。各項目の記載確率をそのまま使います。
- 攻撃回数は物理行動時の独立した命中判定回数。毒・麻痺・即死・Lv吸収・奪取は命中後にそれぞれ独立抽選。即死時は以降の吸収・奪取を行いません。
- 仲間呼びは同じ列に同種を1体追加。生存数の列上限を守り、新たな敵は次の敵ターンから行動。呼んだ敵も討伐報酬の対象です。
- 「魔法使い呪文Lv」「僧侶呪文Lv」は0〜13、「呪文使用率」は0〜100の整数です。非術者は3列とも0。術者は戦闘中の系統Lv以下から呪文を選びます。ブレスは全生存者へ記載ダイスを個別に振り、AC判定を行いません。守る・堅牢の旗の軽減は適用されます。
- 「後衛攻撃：不可」の物理攻撃は前衛を狙い、前衛全滅時のみ後衛。可なら全生存者から抽選。呪文とブレスの対象は各効果に従います。
- Lv吸収は1回1Lv、最低Lv1。経験値は吸収後Lvの必要累計値に戻し、HP/MP上限は職業別成長ダイスの平均（四捨五入）分を減少。STR再計算、HP/MPは新上限まで。習得済み呪文と装備は維持します。
- 奪取は攻撃対象の未装備アイテム1つ。装備品は対象外。対象なしなら何も失いません。
- 炎半減は火炎・大火炎・超火炎に適用（端数切捨て）。氷半減は吹雪・大吹雪に適用（端数切捨て）。耐性は「炎半減・氷半減」のように「・」で複数指定でき、「なし」は単独で指定します。毒無効は敵用状態付与処理で判定。現状、味方側に毒を与える呪文・武器はないため、毒無効が通常戦闘で発動する機会はありません。
- 経験値はCSVの値をそのまま累積。金貨は既存ルールのダイス結果÷3（切捨て）を維持。未探索戦闘の宝箱では従来どおり開封時に3倍。逃げた敵は経験値・金貨・ドロップ対象外。
- 敵が全ていなくなってから、倒した敵の報酬を配分。全員が逃げた場合は宝箱なし。死亡・逃走・召喚・ダメージ・Lv変化はログの表示タイミングに合わせて描画します。
- 旧セーブのパーティー・地図・所持品は維持。進行中の旧戦闘は新IDへ一度だけ移行し、残HPは新データの最大値以内に補正します。

`notion-monsters.json`（114種）・`notion-spells.json`（45種）は同期スナップショットです。`node tests/notion-sync.cjs` でゲームデータと照合します。敵の呪文ID・習得Lv・対象・効果の参照元は `dist/spells.js` の `MAGIC`、敵使用可の集合とダイスの上書きは `dist/monsters.js` にあります。
