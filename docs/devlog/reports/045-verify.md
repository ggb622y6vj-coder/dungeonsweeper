## 追記: 390 の「XP+6373」の原因調査 — バグではない（テスト側の作り物）
- 原因:
  - 亡霊には吸収（drain .1）がある。
  - 吸収されると monsters.js で `m.level--; m.xp=requiredXP(m.level,i)` となり、XP は新しいLv（11）の必要値（xpTargets[11]）に置き換わる。
  - fixture は Lv12 なのに XP を低いまま（約0）にしていたため、レベルが下がったのに XP が増えたように見えた。
  - 普通のプレイでは XP ≥ xpTargets[12] なので、吸収されれば XP は減る。
- 再現: node harness で createParty([2])、Lv12・xp0、敵は 亡霊/骸骨の衛兵/亡霊、ディスペルで attack()。
  - seed 183: 3体とも失敗 →「1レベルを吸収された」→ Lv11・xp=6120（= xpTargets[11]）
  - seed 544: 同じく xp=6467
- 「3体とも失敗」は確率どおり（.4×.05×.4 ≈ 0.8%）。
