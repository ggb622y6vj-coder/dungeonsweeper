# 136　ログダイアログと迷宮のパーティー表示

実施日 2026-11-24。対象ブランチ `hold/136`。

## 実装

- 迷宮のログ欄（`#log`）のクリック／タップで「ログ」ダイアログを開く。×、Esc、ダイアログ外の背景で閉じる。
- ログ本体に描画された行を色付けごと複製し、戦闘・ログ再生中も表示済みの行を同期する。迷宮画面は最新行が先頭。ダイアログは古い順に並べて開いたときに末尾を表示し、末尾を読んでいる間は新しい行に追従する。
- 迷宮のパーティー欄（`#party`）から前衛・後衛の区切りラベルと対応するCSSを削除し、十字キーの操作欄（`.controls`）の上に8pxの余白を追加した。
