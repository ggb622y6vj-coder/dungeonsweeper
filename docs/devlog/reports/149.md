# 149　モンスター画像の表示位置とクイック攻撃の潜伏・奇襲

`hold/149` の作業ツリーに実装。使用モデルは gpt-6.2-sol、推論強度は medium。[仕様149](../specs/149-sprite-position-and-quick-stealth.md)

## 実施内容

- 戦闘中のモンスター画像をシーンの高さの5%分だけ下げた。画像読み込み失敗時のSVGでも枠と文字を20単位下げた。
- 近距離武器を装備した後衛の盗賊・忍者は、クイック攻撃で「隠れる」を選び、潜伏中は先頭の生存敵グループへ「奇襲」する。通常の武器攻撃ができるメンバーがいなくても、この条件を満たすメンバーがいればクイック攻撃を使える。
- この後衛の盗賊・忍者が恐怖・睡眠中の場合は「守る」を選ぶ。潜伏の成否と奇襲後の解除は既存の戦闘処理に従う。
