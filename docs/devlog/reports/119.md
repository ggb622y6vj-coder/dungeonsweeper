## 実装内容（dist/game.js のみ）

- 生成：fresh() の末尾（罠・特殊マスの配置後）で、floor===3 のときだけ 1d4 個を振り、対象マス（trap が false かつ type が空）から重複なくランダムに選んで `spin: true` を付ける。
- 発動：歩行の移動処理 cell() で、移動が確定した位置のマスが spin のとき `s.dir = Math.random()*4|0` を1回だけ静かに適用する。setPlayerPosition には入れていないため、転移の罠・落とし穴・転移呪文・階段／昇降機の到着・逃走などでは発動しない。
- 永続性：セルオブジェクトの属性として保持され、rememberFloor／復元とセーブ（ash-v1）でそのまま残る。属性のない旧セーブのマスでは発動しない。セーブ形式の変更なし。
- 表示の変更なし（盤面・地図・一人称視点に印を出さない）。CSS の変更なし。
