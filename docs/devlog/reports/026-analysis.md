# 026 序盤(1F-3F)バランス分析
基準: origin/main 7b91da1 のクリーンコピー /tmp/c26、パッチ版 /tmp/c26p（026+026a 適用）。/workspace/dungeonsweeper は未変更。
## 原因
1. **経済（ゲーム側の主因）**: 1F 5.5G/戦、2F 7.5G/戦。遠征あたり 0-20G。蘇生 100G×Lv を払えず、死者→削除→Lv1 補充の循環でレベルが上がらない（bot 20遠征で新人 39-47人、蘇生 5-8回）。装備も買えない。
2. **装備なしの 2F 崖**: 1F Lv1 通常 98%/死0.09 → 2F Lv2 84%/死0.70。ガーディアン 2F Lv2 73%、3F Lv3 61%。一方 shop 装備ありなら 2F Lv2 ガーディアン 94%、3F Lv3 96%、3F Lv4 95% と目標内 → 戦闘数値自体より「装備・蘇生の金が無い」が本質。
3. **XP カーブ**: 1F は 6.2XP/人/戦、Lv3 には 255-380XP 必要＝1F で約 50 戦（10遠征超）。Lv3-4 で 3F 到達は 2F で稼ぐ前提。
4. **bot 側の弱点（ゲーム問題ではない）**: 1F ボス直後 Lv1 のまま降りる、HP25%まで撤退しない、死者を Lv1 で即補充。人間ならもっと早く帰る。bot6（平均Lv≧階+1 まで降りない、HP40%/死者1で帰還）でも 20遠征では 2F 止まり。

## 評価
- 026（寺院費用スケール）は効果大：補充が半減以下、レベル維持が可能に。推奨。
- 026a（ダイス平準化）は装備なしでは小幅改善、shop装備ありではほぼ誤差（全て 89-100% 内）。2F>3F の逆転は無し。優先度は 026 より低い。
- 未達: 「Lv3-4 で 3F 到達」は 20遠征の bot では未達（XP カーブ律速）。次案候補は 1F/2F の XP or ゴールド ×1.5（未検証、上限2件のため todo 化せず）。
