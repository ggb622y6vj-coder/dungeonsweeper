# 091 実装レポート：発動中の呪文の確認・重複使用防止、気付け薬ログの色、装備ボタンの出し分け

仕様書: docs/devlog/specs/091-active-spells-and-fixes.md

## 実装（Codex、gpt-6-astra／推論 high、1回、79,118トークン、切り替えなし）

モデル選択の理由：複数ファイル（game.js、spells.js、index.html）にまたがり、持続状態の定義と spellReason の判定順序に触れるため、新ルール（2026-11-09）により上位モデル＋高推論を指定した。実行ヘッダーで model: gpt-6-astra、reasoning effort: high を確認。

### 変更1：気付け薬ログの「沈黙」の色

- 原因：coloredLog() が呪文名を部分一致で色付けし、状態異常の名前である「沈黙」（呪文 montino と同名）まで呪文色になっていた。
- dist/game.js の coloredLog() に、色を付けない語句の一覧 plainPhrases を追加し、「麻痺・睡眠・沈黙・恐怖」「沈黙が解けた」を入れた。アイテム名（073）と同様に1語として扱い無着色で出す。
- 呪文「沈黙」を唱えたログと敵が沈黙したログは変更なし。文言・効果・セーブは不変。

### 変更2：発動中の呪文

- dist/spells.js に activeSpellEffects() を新設。持続状態は 透視（milwa／lomilwa、s.milwaSteps>0 か s.light）、警戒結界（s.watchful）、鉄壁（s.teppeki）の3つ。
- 重複防止：spellReason() の最後（MP不足の後）に「発動中」の判定を追加。既存の理由の優先順位は不変。探索の呪文一覧と戦闘の呪文選択の両方に効く（どちらも spellReason／castMagic を通る）。
- dist/index.html のステータス画面（#statsdialog）のヘッダーに「発動中の呪文」ボタン（#activespells、初期 hidden）を追加し、専用ダイアログ（#activespelldialog）を新設。renderStats() の先頭で renderActiveSpells() を呼び、ボタンの表示と一覧（状態名・効果・残り期間）を毎回更新する。透視の残り期間は、大透視なら「町へ戻るまで」、透視なら「あとN歩」。
- 解釈（仕様書にも明記）：防御・大防御は戦闘中だけ敵側の戦闘状態に残るため対象外。敵への弱体、判別・開放（即時効果）も対象外。

### 変更3：装備ボタン

- dist/game.js の renderInventory() で、装備ボタン（data-equip）を「その職業で装備できる（w.classes に jobOf(i) を含む）か、現在装備中」のときだけ描画するよう変更。装備中アイテムの「外す／装備中」は残る。equip() のガード、売却・薬ボタンは不変。
