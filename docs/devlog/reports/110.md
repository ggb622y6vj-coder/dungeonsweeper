## 実施内容

- データ（Muse が用意）：
  - `data/loot-tables.json` の pools を {medicineShare, rankWeights, medicineIds} 形式へ移行。medicineShare は現行プールの薬比率（T1 2/35、T2 4/32、T3 4/43、T4 5/25、T5 4/26）、rankWeights は現行プールのランク構成数（T1 は決定②により R1:24・R2:8 のみ）。groups・monsterGroups は不変。
  - `data/notion-items.json` の全行に「ランク」を転記（装備76件に 1〜5、薬5件は null）。転記元は試案に ID 付きで明記された登録値。
- 実装（Codex）：
  - `dist/weapons.js` の全装備76件に lootRank を追加（スナップショットの「ランク」と一致、薬には付けない）。
  - `dist/loot.js` の LOOT_TABLES を新形式に一致させ、`rollChestItems` の T→アイテム部分を、薬分岐（medicineShare）→ランク重み抽選→そのランクの全装備から等確率、に差し替え。floor 引数は互換のため残置し未使用。
  - `tests/chest-loot.cjs` を新方式に組み替え（データ整合、到達可能性の固定乱数ウォーク、確率近似、T1 で R3 が出ないこと、不正データ検出、宝箱の確定・再読込・旧形式互換の維持）。`tests/chest-loot-browser.py` も追随。
  - `tests/notion-items.cjs` にランク照合を追加（装備は lootRank == スナップショットの「ランク」、薬はランクなし）。
  - `docs/SPECIFICATION.md` の宝箱の説明をランク方式に更新。
