## 変更内容

1. 一人称ビューのアイコン秘匿（dist/game.js）: face() の symbol 決定で、降り階段（⇩）と上り階段（⇧）にも探索済み（c.open）の条件を付けた。未探索の階段マスは他の未探索マスと同じ表示になる。盤面表示は不変。
2. 地図ウィンドウの階表示（dist/index.html / dist/game.js）: ダイアログのヘッダーの span に id="maptitle" を付け、render() で .maplocation と同じタイミングで「地図（地下N階）」に更新するようにした。ドック側の表示は不変。
3. 図書館の薬タブ（dist/library.js）: 薬サブタブ先頭の所持数カウント段落（薬 n/5）を削除。他のサブタブは不変。
4. 旧呪文名の整理:
   - 薬5件の説明（dist/items.js）から「〇〇相当：」を除去し効果文のみにした。
   - モンスターの呪文名（data/monsters.csv と compile-monsters.py の MONSTER_SPELLS キー）を現在名へ: 火炎・大火炎・吹雪・大吹雪・魔弾（沈黙は不変）。コンパイラで dist/monster-data.js を再生成。生成データの差分は呪文名のみ。
   - 調査時の見落としの訂正: マダルトは CSV に3件あり（事前調査では未使用と判断）、大吹雪への置き換え対象に含めた。spell-sync-logic.cjs の期待値も追随。
