2. 宝箱ボタンの表記：dist/index.html の #chestcalfo の表示を「カルフォ」から「仕掛解除」に変更（dist/ 内の他の「カルフォ」表記はなし）。動作・id は不変。
3. 呪文リストのレベル順：renderMagic() の絞り込み直後にレベル昇順の安定ソートを追加。系統タブ内・詠唱／閲覧の両モードに適用され、先頭行の data-key-default は最下位レベルの呪文になる。
- 既存テストの追従修正（すべて旧仕様の期待値を新仕様に合わせたもので、シナリオと検証の強さは維持）：

  - tests/spell-sync-logic.cjs：全移動経路で透視が持続する前提に書き換え（移動後の歩数 30、対角視界が新階でも効くことを確認）。lomilwa の検証部分は、前に唱えた milwa が残るようになったため歩数を 0 に戻してから唱える形に調整。
  - tests/pitfall.cjs：落とし穴で落下しても歩数が保持される期待値（12）に更新。
  - tests/117-antimagic-zone-browser.py：昇降機・落とし穴でゾーン外に着地した場合、以前は移動処理自体が milwaSteps を 0 にしていたため一部解除の期待値だったものを、全効果が保持される期待値に更新（ゾーン内着地での解除＝CLEARED のケースは不変）。
  - tests/spell-list.cjs：リスト順の期待値をレベル昇順（halito, reload, tempt）に更新。
