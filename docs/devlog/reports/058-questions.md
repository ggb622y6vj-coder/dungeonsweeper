# 058〜060 確認したいこと

Q1. 「識別」の成功率はどう決めますか？
 - A（おすすめ）：術者と敵のレベル差で決める。カティノと同じ式「49＋5×(術者Lv−敵Lv)」%、5〜95%
 - B：術者のIQで決める（IQ×5%。IQ15なら75%）
 - C：固定の確率（例：70%）

Q2. 判定は列ごとに1回でよいですか？
 - A（おすすめ）：列全体で1回。成功すればその列は全部識別
 - B：1体ずつ判定（同じ列でも、識別できた個体とできない個体が混ざる）

Q3. 失敗したとき、MPは消費しますか？
 - A（おすすめ）：消費する（ほかの呪文と同じ）
 - B：消費しない

Q4. 戦闘中に毎ターン自動で起きる識別（IQ×3%）はどうしますか？
 - A（おすすめ）：残す（戦闘画面では確定名に変わるが、図書館には反映しない）
 - B：なくして、識別は呪文だけにする

Q5. 呪文で識別していないモンスターは、図書館に何を表示しますか？
 - A（おすすめ）：不確定名と撃破数だけ
 - B：不確定名だけ
 - C：不確定名に加えて、見た目で分かる情報（出現階・攻撃回数など）

Q6. 今あるセーブで、すでに図書館に載っているモンスターはどうしますか？
 - A（おすすめ）：識別済みとして引き継ぐ（今まで見えていた情報が消えない）
 - B：全部「未識別」に戻す（呪文で識別し直す）

Q7. 物理ダメージの表記はどうしますか？
 - A（おすすめ）：ダイスだけ（例：2d8）。攻撃回数は別の行に表示
 - B：回数をまとめて書く（例：2d8×2）

Q8. 状態異常ではない特殊能力（ブレス・即死・レベル吸収・アイテム奪取・仲間呼び など）は、どう表示しますか？
 - A（おすすめ）：同じ形のタグで、目立たない灰色系にする
 - B：今までどおりの文字（タグにしない）
 - C：即死・レベル吸収だけ赤系のタグで目立たせ、ほかは灰色

Q9. リストにない「命中補正・AC・耐性（炎半減など）」はどうしますか？
 - A（おすすめ）：命中補正・ACは載せない。耐性は特殊能力のタグとして残す
 - B：3つとも載せない
 - C：3つとも載せる（項目を追加）
