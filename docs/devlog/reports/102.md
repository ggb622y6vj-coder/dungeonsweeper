# 指示書102 報告書：Notion DB の差分反映

## 概要

ユーザーが更新した Notion のモンスター／アイテム／呪文 DB と、リポジトリのスナップショット（data/notion-*.json）を全件照合し、差分を分類のうえ実装した。仕様は docs/devlog/specs/102-notion-db-sync.md。

- アイテム: 既存71件の装備職へ上級職（侍・忍者・君主・司教）を反映。新規9件（塗毒の小刀／塗毒の隠し刀／猛毒の隠し刀／吸魂の杖／吸魂のメイス／血の代償／代わり身の胸当て／代わり身の兜／ヘッドライト）と6つの新しい仕組み（攻撃時毒付与、敵の毒ダメージ、ダメージ連動MP回復、呪文コストのHP転化、代わり身の自動回復／異常無効化、階移動時の周囲開示）を追加。
- 呪文: 32件の MP・数値・説明を反映（ダルト 6d6→6d6+2、旗視の文言と MP 5→2 など）。
- モンスター: 差分17件はすべて Notion 側のセル破損（特殊欄JSONの name に余分な語句）で、ゲームが使う id・対象・ダイスは不変のため対象外。スナップショットは変更していない。Notion 側の修正はユーザーの判断に委ねる。
