# 指示書107 実施報告：薬のスタック所持

## 依頼と解釈

ユーザーの依頼は docs/devlog/specs/107-item-stacking.md に原文のまま記録。解釈（対象は薬5種のみ、内部形式は ID 配列のまま、枠はスタック数＋装備品数で数える、ボックスにも同じ数え方、セーブ形式不変、Notion に「スタック最大数」欄を追加）は Muse が提示し、ユーザーが承認。実装担当はユーザーが Codex を指定した。

## 実装（Codex：gpt-6-astra、推論 high、101,500トークン）

- dist/items.js：MEDICINES に stack を追加（傷薬10・解毒剤10・気付け薬5・上傷薬5・霊薬3）。枠数ヘルパー stackMaxOf / usedSlots / canAccept と、表示行合成 itemRows / itemRowName を新設。lootRecipient と medicineSlots（チャンク単位）を差し替え。薬ダイアログの表示は「枠N」から個数表示（「傷薬 ×3」）へ。
- dist/game.js：buy / renderShop / renderInventory（チャンク行＋代表枠、見出しは usedSlots）を差し替え。アイテムボックスの預ける・取り出す判定を canAccept に、容量表示を usedSlots に変更。ensureProfile の切り捨てを枠数ベース（末尾から削り、装備参照を掃除）に変更。
- dist/party.js：transferItem / renderTransfer を canAccept ベースに差し替え（選択中のアイテムごとに渡せる相手を絞る）。
- 戦闘中の薬使用予約は、予約枠の ID が変わっていたら同じ ID の最後の添字を消費するフォールバックを追加。
- docs/SPECIFICATION.md にスタックの規則を追記。
- テスト：新規 tests/item-stacking.cjs（数理・入手・使用・譲渡・ボックス・読み込み）と tests/item-stacking-browser.py。tests/notion-items.cjs にスタック最大数の照合を追加。tests/item-box.cjs は枠数ベースの前提に追随。
