## 実施内容

### 変更1：保存済みの階へ移動した時に到着ログを出す
- `travelFloor`（保存データから復元し、町からでなく、実際に階が変わった場合）と `travelElevator`（保存データから復元した場合）の成功経路に `地下N階に到着した。` のログを追加した。
- 未踏の階では従来の「迷宮に到着。守護者のいる部屋を探そう。」が到着文として表示されるため、二重に出さない。回帰テストを `tests/elevator.cjs` に追加した（階段の上下・昇降機、未踏階の非重複）。あわせて `tests/game.cjs` の到着ログの再生待ちを調整した。

### 変更2：階層ごとのテーマカラー
- `render()` が現在の場所から帯を決め、`body[data-floor-theme]` に設定する。町・1F=green（従来パレットのまま無変更）、2〜3F=blue、4〜5F=yellow、6〜7F=orange、8〜9F=red、10F=purple。
- CSS は帯ごとの変数（基調・パネル・カード・ボタン・境界線）を `dist/index.html` に追加し、非 green 帯では背景グラデーションとパネル／ダイアログ／カード／セル／ログ等の背景を上書きする。黄色帯は暗い黄土・オリーブ寄りとし、全帯とも金色アクセントと明るい文字が読める暗さにした。
- 一人称ビュー（scene）の SVG 内部の色は「ダンジョン内の光景」として従来のままにした（ページの基調色の対象外）。意味色（HP/MP バー、旗、ログの色付け、現在地ハイライト）は全帯で従来どおり。
- 帯の切り替わりの回帰テストを `tests/elevator.cjs` に追加した。

### 変更3：図書館の詳細ウィンドウ廃止
- `dist/library.js`：項目をボタン化する処理（onclick、`role="button"`、`aria-haspopup`、tabIndex）を除去した。項目内の詳細（dl）表示は従来どおり残っている。
- `dist/index.html`：`#librarydetaildialog` を除去し、`dist/library.js` の閉じるボタンのハンドラも除去した。`dist/keynav.js` は図書館リストのスクロール操作（キーで一覧をスクロール）を項目の非ボタン化に合わせて調整した。
- 既存テストを追随させた：`tests/library.cjs`（詳細ダイアログ前提の確認を「クリックしても開かない・一覧表示は従来どおり」に変更）、`tests/library-identify.cjs`（同様の観点で実施者が更新）、図書館関連のブラウザテスト6本。

### 変更4：鍛冶屋のタブ分けと購入ポップアップ
- `dist/index.html` の鍛冶屋ダイアログにタブ（武器／頭／胴体／足、`role="tab"`、`aria-controls="shopitems"`）を追加し、`renderShop()` が選択中タブの分類（`part` なし=武器、head/body/feet）だけを表示する。図書館タブと同じ roving tabindex 方式で、キーボード操作（keynav の Q/E・左右移動）も図書館と同様に効く。初期タブは武器、メンバー切替では維持、開き直すと武器に戻る。新規テスト `tests/shop-tabs.cjs`／`tests/shop-tabs-browser.py` を追加した。
- 購入通知：`buy()` の `#shopnotice` への表示をやめ、要素ごと除去した。代わりに `#shoppurchasedialog`（モーダル）に同じ文言 `（名前）が（アイテム名）を購入した。` を表示し、`SHOP_PURCHASE_NOTICE_MS`（500ms）後に自動で閉じる。`cancel` イベントを抑止して Esc では閉じられない。表示中はモーダルのため背後の操作はできない。金貨・所持品・一覧の更新は従来どおり購入時に即時行われる。
- `dist/keynav.js`：購入ポップアップ表示中はキー入力を消費して背後に伝えないようにした。
