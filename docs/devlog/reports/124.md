# 指示書124 実施記録

2026-11-21、`hold/124` に盗賊・忍者の戦闘コマンド「隠れる／奇襲」を実装した。[指示書124](../specs/124-hide-ambush.md)

## 経緯

前回の着手前確認では、防御に本人の行動順で発動する処理がなく、「実行時点で解除」という記述からは潜伏が解ける時点を決められず停止した。オーナーがA案「ターン開始時に解除」を選び、第1節の決定事項5と第4節を改訂した。今回の実装では、コマンドを選び直す間は潜伏を保ち、ターン開始時に解除して最初の敵行動から標的候補に戻す。

## 変更

- `dist/game.js` で隠れる判定を本人のAGI行動順に行い、通常物理攻撃の候補除外・発見と、奇襲の射程・通常攻撃への切替を実装した。命中・武器効果・旗補正の既存処理を共用し、奇襲では確定ダメージを2倍にしてMP吸収にも反映する。
- `dist/combatui.js` に職業・潜伏状態に応じたコマンド、対象列選択、行動確認を追加した。パーティー欄の潜伏タグはログに記録したメンバーIDに従って表示する。
- `dist/monsters.js` と戦闘処理で、行動不能、戦闘終了、逃走失敗などによる解除を扱う。`dist/recruits.js` のセーブに戦闘入力位置を加え、既存のコマンド・対象列とともに復元する。潜伏は戦闘内の永続メンバーIDで追跡する。
- `docs/SPECIFICATION.md` 第5節を更新し、`docs/devlog/TIMELINE.md` に124を追記した。
