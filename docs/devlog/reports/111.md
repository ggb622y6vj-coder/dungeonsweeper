## 実装内容

2. アイテムウィンドウの配置（dist/game.js の renderInventory、dist/index.html の CSS）：各行を `.slotmain`（名前を見出し、その下に説明を左寄せの段落 `<p>`）＋右端のボタン群に組み替えた。ボタンは flex-shrink:0 / nowrap で潰れない。

4. 売却の個数選択：行の個数が複数なら同じダイアログで個数を選ばせ、合計金額（単価×個数）を表示する。個数1の行は従来どおり即売却。
