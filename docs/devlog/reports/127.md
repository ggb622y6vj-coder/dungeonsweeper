# 127　モンスターの呪文使用と戦闘中の魔力低下

2026-11-22 · ブランチ `hold/127` · コミット —

[指示書127](../specs/127-enemy-spellcasting.md)

## 実装と照合

- 術者22種は指示書の2系統Lv・詠唱率と全件一致し、残る86種はすべて0/0/0。CSVとNotionスナップショットは、従来版と行順・呪文以外の全項目が一致した。
- 敵は使用可能な21呪文から系統・習得Lv帯・対象の状態に応じて選ぶ。対象消滅時は無効になった候補を除いて再抽選し、候補が尽きた場合に通常攻撃を1回分実行する。
- 低下するのは唱えた系統だけ。列の安定IDで仲間と共有し、同種の別列には伝播しない。反呪文の結界内でも消耗し、ログは打ち消しと実際に起きた低下だけを表示する。
- 回復は生成時の最大HPを上限とし、旧戦闘セーブでは読み込み時のHPを上限にする。旧セーブの欠落Lvは補完し、消耗済みの0は保持する。セーブキーは `ash-v1`。
- 敵の防御とパーティーへの減退は独立して計算し、味方ACのログ再生にもその時点の補正を反映する。図書館は識別済みの術者だけに初期Lvと詠唱率を表示する。

## 固定呪文との戦闘比較

固定呪文版（`1d20999` のゲーム本体とsim）と127の作業ツリーで、各条件1,000戦ずつ実施。4Fは術者を含む通常編成、5Fは屍術師、10Fは迷宮の主を含む守護者戦。随伴・頭数・先制判定は各階の通常ルールを使う。パーティーは戦士・戦士・僧侶・盗賊・魔法使い・僧侶の6人、初期装備。各戦の開始時に全快させ、4FはLv6、5FはLv8、10FはLv20とした。

パーティー生成seedは127、試行番号を0始まりとして各戦のseedは127000＋試行番号。両版とも標準simの行動選択と決着判定を使い、中間ログの再描画を省いた。戦闘に入った時点の位置・先制・敵個体とHP・味方HP/MP・習得呪文を試行順にハッシュ化し、条件ごとに両版を照合し、3条件とも一致した。

### 再現手順

リポジトリ直下で実行する。比較スクリプトの第1引数は読み込むゲーム本体とsimのルート、第2引数は各条件の試行数。

```sh
baseline127=$(mktemp -d)
git archive 1d20999 dist scripts/sim | tar -x -C "$baseline127"
node scripts/sim/compare-enemy-spells.cjs "$baseline127" 1000
node scripts/sim/compare-enemy-spells.cjs . 1000
```
