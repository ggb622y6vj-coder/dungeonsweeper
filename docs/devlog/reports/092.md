仕様書: docs/devlog/specs/092-agi-action-order.md

## 実装（Codex、gpt-6-astra／推論 high、1回、99,693トークン、切り替えなし）

モデル選択の理由：戦闘ターン処理の書き換え＋能力値の追加（生成・成長・旧セーブ移行・表示）にまたがるため、新ルール（2026-11-09）により上位モデル＋高推論を指定した。実行ヘッダーで model: gpt-6-astra、reasoning effort: high を確認。

### AGI の導入

- 味方：メンバーに agi／baseAgi を追加し、STR と同じ作りにそろえた。新規作成（dist/recruits.js）は能力値を4つに拡張し、AGI 基礎値は職業順（戦士・魔法使い・僧侶・盗賊）に [10, 9, 9, 14]、ボーナス配分の重みにも AGI を追加。成長は agilityFor()（基礎値＋⌊(Lv-1)/5⌋、上限18）で、levelUp() と lowerMemberLevel()（dist/monsters.js）の両方で STR と同じ形に再計算する。レベルアップ報告にも「AGI +N」を追加。
- 旧セーブ移行：migrateAgility() を migrateStrength() の隣に置き、ensureProfile() で本隊・控えの両方に適用。取得は memberAgility(i) に集約し、agi が無いメンバーでも agilityFor で代替する。セーブキー ash-v1 は不変。
- 表示：ステータス画面の能力値と訓練所（ラベル一覧・募集プレビュー）に AGI を追加。
- 敵：enemyAgility(e) = min(18, 6 + ⌊(レベル-1)/2⌋)（Lv1→6、Lv10→10、Lv25→18）。データ追加なし。敵の能力値は画面・ログに出さない。

### 行動順の共通処理（dist/game.js）

- agilityInitiativeBonus(agi)：AGI 3以下 -2、4〜5 -1、6〜8 0、9〜12 +1、13〜15 +2、16以上 +3。
- combatActionOrder()：味方全員（id 参照）と生存している敵全ユニット（uid 参照）について、順序キー = 1〜10 の出目 − 俊敏修正 を計算し、キーの小さい順、同点は AGI の高い順、それも同じなら味方→敵、最後は元の並び順で並べる。出目とキーはログに出さない。
- enemyAction(e, commandsById)：enemyTurn() の1体分（睡眠経過、monsterAction か通常攻撃、並び替え）を切り出した共通処理。enemyTurn() は従来の入口として残り（遭遇時の奇襲・逃走失敗時が従来どおり）、内部でこれを使う。
- attack()：前処理は従来どおり。その後は combatActionOrder() の順に、味方は id から index を引き直して partyAction()、敵は uid から引き直して enemyAction() を実行する。initiative 'party' のターンでは敵の番を飛ばし（先制の意味は従来どおり）、終端処理（全滅で finishMonsterBattle、全滅で defeat、'party'→'normal'、沈黙・恐怖の経過、コマンド初期化）も従来の意味を保つ。
- 変えていないもの：rollInitiative の確率と意味、逃走、敵 AI の選択、ダメージ計算、quickAttack。
