# モンスターの「命中補正」とは？

おっしゃるとおり、原作のモンスターには「命中補正」という項目はありません。ただ、本作の命中補正は、**原作で「モンスターのレベル」が担っていた役割を、レベルとは別の数値として独立させたもの**です。名前は新しいですが、仕組みは原作とほぼ同じです。
（ゲームは 2026-11-03 時点の最新版 eb7c9cb で確認しました。Notionのモンスター表では「命中補正」、ゲームのデータでは「命中補正」列です。）

## 何に使われているか
**モンスターが味方を殴ったとき（物理攻撃）に当たるかどうか、だけ**に使われています。
- **判定のしかた：** 20面のサイコロを振り、「出目＋命中補正＋レベル差の補正＋味方のAC」が20以上なら命中です。
  - 出目20は必ず命中、出目1は必ず外れなので、命中率はいつも5〜95%の間に収まります。
- **味方のACとの関係：**
  - 本作のACは、原作と同じく「数字が小さいほど硬い」です。
  - ACが1下がると、命中率は5%下がります。命中補正が1上がると、命中率は5%上がります。つまり、この2つはちょうど打ち消し合う関係です。
  - 目安は「命中率 ≒ (命中補正＋AC＋1)×5%」です。
- **レベル差の補正（本作独自）：**
  - モンスターのレベルと、殴られる味方のレベルの差を3で割った分を足します（最大で±3）。
  - 強いモンスターほど少し当たりやすく、レベルの高い味方ほど少し避けやすくなります。
- **ほかへの影響はありません。**
  - ブレス、呪文、状態異常の確率（「命中時15%」などは、当たった後の別の抽選です）、ダメージ量には関係しません。
  - 図鑑にも表示されません。
  - 味方の攻撃の命中には、別の計算式を使っています。

### 例（味方と同じレベルの場合）
- 洞窟スライム（1F・命中補正1）が、AC6の戦士を殴る → 約40%
- 迷宮の守護者（1F・命中補正6）が、同じ戦士を殴る → 約65%
- 迷宮の主（10F・命中補正16）が、AC0まで固めた戦士を殴る → 約85%（レベル差が大きいと最大の95%）

### 数値の幅
階が深いほど高くなります。
| 階 | 命中補正の範囲 |
|---|---|
| 1F | 1〜6 |
| 2F | 2〜4 |
| 3F | 3〜5 |
| 4F | 3〜8 |
| 5F | 4〜8 |
| 6F | 5〜10 |
| 7F | 7〜12 |
| 8F | 8〜13 |
| 9F | 10〜14 |
| 10F | 10〜16 |

いちばん低いのは洞窟スライムの1、いちばん高いのは迷宮の主の16です。

## 原作（初代『狂王の試練場』）との比較
- 原作では、モンスターの攻撃が当たる確率は「**(モンスターのレベル＋味方のAC)×5%**」で、5〜95%の範囲に収められます（Data Driven Gamer の解析記事より）。モンスター側に命中専用の数値はなく、レベルがそのまま「当たりやすさ」になります。
- 本作の式は「(命中補正＋AC＋1)×5%」なので、**原作の「レベル」の位置に「命中補正」を置いたもの**です。形はほぼ同じで、違いは「＋1」とレベル差の補正だけです。
- 本作の仕様書（docs/SPECIFICATION.md、docs/042-MONSTER-LEVEL-HIT.md）にも、「レベル差の補正は本作独自の調整で、原作の『敵レベルを直接使う式』の再現ではない」と書かれています。

## 推測
- **推測：** 本作のモンスターは、命中補正がレベルより低めです（例：死神はLv20で命中補正14、迷宮の主はLv25で16）。原作の式のままレベルを使うと、深い階の敵がほぼ必ず当ててくるので、「強さ（レベル）」と「当たりやすさ」を分けて調整できるように独立させたと考えられます。
- **推測：** Notionで命中補正を変えれば、HPや経験値は変えずに「その敵の攻撃がどれくらい痛いか（当たる頻度）」だけを調整できます。目安は、1上げるごとに命中率が5%上がることです。
