# 139 敵グループの列移動

実施日 2026-11-25。対象ブランチ `hold/139`。[指示書139](../specs/139-enemy-group-advance.md)

## 実装

- 通常戦・守護者戦で、戦闘が続くラウンドの末尾に各列の強さを集計し、最後尾のペアから順に前進を判定する。行動可能数と強さの集計は同じ状態判定を使う。前進するたびに左上の一覧と同じ名前で「○○が前に出た。」を記録する。
- 前進した列の個体を、召喚個体も含めて前の列の最初の未精算個体の直前に移す。列内の相対順、個体の列ID、列別の現在呪文Lv、予約先IDを保持する。遭遇時の先頭種を保存していない旧セーブでも、宝物グループは元の先頭個体のUIDから決まる。
- 新規Nodeテストで強さ・確率境界、単独列、遭遇直後、3列での連続前進、安定ID、近接射程、保存と再読込を検証。ログ再生時の一覧とアイコンも1行ずつ確認した。既存の奇襲・解呪・クイック攻撃テストは、前進後の表示列や対象IDに合わせた。
