# 指示書104 実施報告：訓練所メニューの整理

## 依頼

訓練所の順番変更を削除し、「新規作成」「転職・編集」のタブ化、パーティーから外す操作の酒場への移行、ステータス画面の「前職：」表示の削除、転職の職種ボタンの簡素化（職業名のみ＋転職可能なボタンを光らせる）を行う。実装は Grok Build で行う。

仕様： docs/devlog/specs/104-training-menu-reorganization.md

## 実装（Grok Build：grok-4.7、reasoning high、費用 $6.96）

- 訓練所から順番変更を削除：「順番変更」ボタンと順番変更ダイアログ一式、登録メンバー行の「前へ」「後ろへ」ボタンを削除（dist/index.html、dist/training.js、dist/keynav.js）。ステータス画面の順番変更は現行どおり。
- 訓練所ダイアログに「新規作成」「転職・編集」の2タブを導入（既存のタブ様式に倣い、キーボード操作に対応）。
  - 新規作成タブ：従来の新規作成UI。
  - 転職・編集タブ：登録メンバー一覧。行の操作は「転職」「名前の変更」「登録抹消」のみ。
- 加入・離脱は酒場の編成に一本化：登録メンバー行の「加入」「離脱」ボタンを削除。酒場のボタン文言（「登録・転職・編集」へ）、訓練所の件数表示、パーティ0人時の案内文、SPECIFICATION.md の該当記述を追随。
- 名前の変更を新設：dist/recruits.js に renameRecruit(id, name) を追加し、転職・編集タブの各行から専用ダイアログで変更できる。検証は1〜20文字、禁止文字は101のセーブ検証と同一（`<>&"'` と制御文字）。変更は保存され、各画面へ即時反映される。
- ステータス画面の「前職：」表示を削除（dist/game.js の renderStats）。careerHistory のデータは保持。
- 転職の職種ボタンは職業名のみにし、CLASS_FEATURES を削除。転職可能なボタンには .job-ready クラス（金色の枠・明るい背景・発光する影）を付け、選択時はさらに強調する。転職不可は disabled のままで、理由は title に残した。プレビュー（比較表・装備・注意書き）は現行どおり。
- SPECIFICATION.md の訓練所・酒場・転職まわりの記述を新構成に更新。
