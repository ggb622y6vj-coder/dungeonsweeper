# 148　5Fの象限ゾーンと命の泉

2026-11-26、`hold/148` に実装。使用モデルは gpt-6.2-astra、推論強度は high。作業ツリーは未コミット。[仕様148・Amendment 1](../specs/148-floor5-quadrant-zones-and-fountain.md)

## 実施内容

- 新規5Fでは北西・北東・南西・南東の各象限を独立に抽選する。地図が反応しない確率は25%、反呪文の結界は25%、通常は50%。透視中は状態の異なる象限の境界に、その象限の効果に対応する枠を表示する。3F・4Fは従来の判定と描画を使う。
- 罠のない通常の0マスから1つを選んで命の泉を置く。候補がなければ配置しない。歩いて入ると遭遇判定を省き、HP全回復・MP全回復・「使わない」から選べる。回復対象は状態が `ok` の全員で、状態異常は保持する。使用後は泉が消え、見送った場合は再訪できる。
- 階層の往復とセーブでゾーンと泉の使用状態を保持する。泉の選択中に再読込するとダイアログが再び開く。生成済みの旧5Fは全象限通常・泉なしとして復元する。
