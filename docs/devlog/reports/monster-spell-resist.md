# モンスターの呪文抵抗率：今の実装と原作の比較

調べた版：origin/main eb7c9cb（data/monsters.csv、dist/spells.js、dist/game.js）

## 結論
**今のゲームには「呪文抵抗率」という数値はありません。** モンスターの CSV にも、そういう列はありません（列は 確定名〜即死・耐性 だけです）。
原作では「魔法無効化率（%）に当たると呪文がまるごと無効」になりますが、その仕組みもありません。
今あるのは次の3つです。どれも、呪文ごとに専用のルールとして書かれています。

1. 炎や冷気の**属性耐性**（ダメージ半分）
2. 睡眠と沈黙の**レベル差による成功率**
3. 即死呪文の**レベルと種族による判定**

## 今の実装の詳細

### 1. ダメージ呪文と属性耐性（CSV の「耐性」列）
- 対象の呪文と属性：
  - ハリトとマハリトは「炎」
  - 説明文に「冷気」とあるダルトは「氷」
  - ティルトウェイト・ロルト・マリクトは無属性で、軽減されません
- モンスターの耐性に「炎半減」や「氷半減」があると、ダメージを**半分（切り捨て）**にします。完全に防ぐことはありません。
- 耐性が複数あるときは「・」でつなぎます（例：ダイダラボチ「炎半減・氷半減」）。
- 耐性の数（全90体）：
  - なし：60体
  - 毒無効：21体（不死・構造体など）
  - 炎半減：8体（火蜻蛉2F、炎竜3F、火蜥蜴5F、キメラ6F、地獄の犬7F、赤竜・魔界の猟犬・古竜9F）
  - 炎半減・氷半減：1体（ダイダラボチ10F）
  - 「毒無効」は呪文には関係ありません（モンスターの攻撃による状態異常のほうに関係します・推測）。
- ダメージ呪文には、抵抗によって失敗する判定は一切ありません。必ず当たります。

### 2. 睡眠（カティノ）と沈黙（モンティノ）
- 成功率は **49 ＋ 5×(術者Lv − 敵Lv)%** で、0〜94% の範囲に収まります。判定は1体ずつです。
- 守護者・ボスには必ず効きません。
- 例（術者 Lv5 の場合）：
  - 大鼠（1F・Lv1）：69%
  - オーク戦士（2F・Lv4）：54%
  - トロル（5F・Lv10）：24%
  - Lv15 以上の敵：0%

### 3. 即死呪文
- マカニト：Lv7 以下の敵には**確実に**効きます。それより上のレベルの敵、不死・構造体・守護者には無効です。
- ラカニト：成功率は **100 − 敵Lv×6%** です。Lv17 以上の敵、不死・構造体・守護者には無効です。
  - 例：Lv10 なら 40%、Lv15 なら 10%

### 階ごとの目安
- 敵のレベルは、1F が Lv1〜4、5F が Lv9〜13、10F が Lv10〜25（迷宮の主は Lv25）です。
- 階が深いほど、睡眠・沈黙・即死は効きにくくなります。一方、ダメージ呪文は深い階でも必ず当たります。

## 原作（Wizardry #1 Proving Grounds）との比較

| | 原作 | 今のゲーム |
|---|---|---|
| 呪文そのものへの抵抗 | 各モンスターが「魔法抵抗率 %」を持ち、当たると**その呪文は完全に無効** | なし |
| 抵抗の判定がある呪文 | 攻撃呪文の全部（ハリト・マハリト・ダルト・ラハリト・マダルト・ティルトウェイト、僧侶のバディオス・ロルト・マリクトなど）〔Data Driven Gamer〕 | なし |
| 属性耐性 | 炎・冷気・毒などの耐性フラグがあり、ダメージを軽減する | 炎半減・氷半減（半分） |
| 睡眠 | 敵Lv×20% で抵抗（Wizardry Archives「Game Code Calculations」）。毎ターン目を覚ます判定もある | 49＋5×(術者Lv−敵Lv)% で成功。2回分の行動を止める |
| ラカニト | 敵Lv×6% で抵抗 | 100−敵Lv×6% で成功（原作と同じ） |
| マカニト | Lv8 以上と不死には無効 | Lv7 以下に確実に効く。不死・構造体・守護者には無効（ほぼ原作どおり） |
| ハマン（魔法抵抗を消す） | 効果の1つとして、魔法抵抗の判定をなくせる | 呪文自体がない |

- 原作の魔法抵抗率は、ほとんどのモンスターが低い値です。深い階の悪魔や竜など一部の強敵だけが高い、という作りです（zimlab「Proving Grounds v3.2 Additional Players Guide」。具体的な数値は未確認です）。
- 今のゲームで原作との一番大きな違いは、「深い階の強敵に、ティルトウェイトなどが必ず全部当たる」ことです。この影響で、後半は攻撃呪文が原作より強い・推測。
