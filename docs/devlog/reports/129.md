# 129 床罠「浮上穴」の追加

実施日 2026-11-23

## 実施内容

- 床罠の転移を10%から5%に変更し、抽選の末尾に浮上穴5%を追加した。
- 浮上穴は1つ上の階を生成または復元し、落とし穴と同じ条件で到着先を選ぶ。1Fではその場で不発になる。どちらの場合も踏んだ罠を消費する。
