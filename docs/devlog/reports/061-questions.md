# 061〜063 確認したいこと

Q1. 呪文抵抗率の初期値はどう決めますか？
 - A（おすすめ）：階ごとの基本値（1〜2F 0% → 9〜10F 30%）に、種族の補正（悪魔+20 など）を足す。あとで Notion で個別に調整する
 - B：原作のように、ほとんどの敵は 0% にして、一部の強敵（悪魔・竜・守護者）だけに値を付ける
 - C：全部 0% で入れて、数値はユーザーが Notion で決める

Q2. 敵の AC を下げる呪文（ディルト・モーリス・マモーリス）にも、抵抗の判定をしますか？
 - A（おすすめ）：する（敵に向ける呪文は全部対象）
 - B：しない（ダメージ・睡眠・沈黙・即死だけ）

Q3. 抵抗率を図書館に表示しますか？
 - A（おすすめ）：表示しない（原作どおり、隠れた数値にする）
 - B：識別したモンスターだけ表示する

Q4. 火車髑髏（9F・10F、Lv23、炎ブレス 15d8）は、Notion の値どおりでよいですか？
 - A（おすすめ）：Notion の値どおりにする（不死だが毒無効なし）
 - B：不死なので、「毒無効」を追加する
