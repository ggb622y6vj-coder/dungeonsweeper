# ほとんどの呪文が「決まったレベルで必ず覚える」なのは、呪文の数が少ないせいか

結論：**理由はどこにも書き残されていませんでした。** 呪文の数が少ないことは理由の「一部」としては説明がつきますが、それだけでは説明しきれません。（確認したのは 2026-11-03 時点の最新版 eb7c9cb です。）

## 記録から分かった事実
- **最初の版から、いまの形でした。**
  - ゲームのファイルを最初にまとめて登録した記録（bf2a63c、2026-11-01「Add files via upload」）の時点で、すでに25個の呪文があり、19個が「確定習得」、6個が「確率習得」でした。
  - それより前の作業の記録はリポジトリに残っていません。なぜこう決めたのかを書いたメッセージやコメントもありません。
- **その後に追加された呪文は、すべて「確定習得」です。**
  - マカニト（c1034bb）、ミルワピック（eb7c9cb）。モンティノも確定習得で追加されています。
  - 確率習得の6つ（ダルト、ティルトウェイト、カルフォ、ディアルコ、ラツモフィス、マディ）は、最初の版から変わっていません。
- **仕様書には「どう動くか」だけが書かれていて、「なぜか」は書かれていません。**
  - docs/SPECIFICATION.md と SPELLS.md には「確定習得は指定レベルで必ず習得、それ以外は IQ/30・PIE/30 で抽選し、外れたら次のレベルアップで再抽選」とあります。
  - モンティノの項には「数式・習得レベル・MPは本作の仕様で、原作の計算式との一致は保証しない」とあり、原作どおりにするつもりがないことは明記されています。
- 作業指示書の置き場（/workspace/dsw-queue）にも、理由を決めた記録はありません。古い指示書（codex-tasks-v1.md）には、仕様書の「確率習得の15固定＝50%」が古い記述だという注意があるだけです。

## 呪文の数で説明できるか（数の比較）
- **原作**（初代）：魔法使い・僧侶とも7段階で、1段階に2〜6個、合わせて約50個です。
  - 1つの段階に呪文が多いので、「各段階の最初の1つは必ず覚え、残りは抽選」にしても、ゲームとして成り立ちます。
- **本作**：魔法使い13個、僧侶15個の、合わせて28個です。習得レベルごとの数は次のとおりです。
  - 魔法使い：Lv1 に4個、Lv3・5・11 に各1個、Lv7・9・13 に各2個
  - 僧侶：Lv1 に2個、Lv3 に4個、Lv5 に3個、Lv7 に2個、Lv9 に1個、Lv11 に2個、Lv13 に1個
- **原作のルール（各段階の最初の1つは必ず覚える）を本作に当てはめた場合：**
  - 呪文が1つしかないレベル（魔法使いの Lv3・5・11、僧侶の Lv9・13）は、原作のルールでも必ず覚えることになります。
  - その場合、必ず覚える呪文は最低でも魔法使い7個・僧侶7個、合わせて14個です。本作は22個が確定習得なので、残りの8個は呪文の数では説明できません。
- **数だけでは説明できない例：**
  - 魔法使い Lv1 のカティノ、Lv9 のマモーリスとマカニト（2個とも確定習得）
  - 僧侶 Lv3 のモンティノ・マツ・警戒結界（3個が確定習得）

## 推測
- **推測：** 確率習得の6つは、どれも「同じレベルに確定習得の呪文がある」上位版や、状態異常の治療など、なくても先に進める呪文です。主要な攻撃・回復・探索の呪文は必ず手に入るように、意図して分けた可能性があります。
- **推測：** 本作は魔法使い・僧侶しか呪文を使えず、転職もなく、MPもひとつの共通の数値です。原作のように「運が悪いと大事な呪文を覚えられない」ことを後から取り返す手段（転職、回数の保証）がないため、確定習得を多くしたとも考えられます。
- 呪文の数が少ないことは、理由の一部としては当てはまります（呪文が1つしかないレベルは、どちらにしても必ず覚えるため）。ただ、それだけでは「22個が確定習得」には届きません。最終的には作者が設計として選んだもの、と考えるのが妥当です。正確な理由は、作成した本人（または最初の版を作ったときの指示）にしか分かりません。
