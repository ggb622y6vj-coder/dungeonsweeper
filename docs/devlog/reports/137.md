# 137 呪文の消費MP調整と僧侶呪文3種の追加

実施日 2026-11-25。対象ブランチ `hold/137`。[指示書137](../specs/137-spells-update.md)

## 実装

- 既存呪文14件の基本MPを指示書§2の値に引き下げ、ゲームとNotionスナップショットを全45件で同期した。
- 治癒の旗（Lv2・MP1）は2d8、大治癒の旗（Lv10・MP4）は8d3で味方1人を回復する。探索・戦闘ともに周囲8マスに旗付き罠があれば、セル番号が最も小さい1つを解除して探索済みにする。旗付き罠がない場合も回復する。
- 示現（Lv13・MP10）は探索時に、守護者の撃破前後を通して下り階段がある象限を知らせる。10FでもMPを消費し、「この階に下り階段はない。」と表示する。連続詠唱しても基本MPは10で、判別の使用回数を保持する。
