# 086 実施報告：呪文リストを習得済みのみにし、戦闘専用をグレーアウト

## 実装（Codex、gpt-6.1-sol、アカウント既定、48,970トークン、1回）

- `dist/spells.js` の `renderMagic()` を変更。リストの母集合を「そのメンバーの職業かつ習得済み（known に含まれる）」に絞った。戦闘中の誘惑除外は維持。
- 戦闘中でないとき、使用場面が戦闘のみ（where='battle'）の呪文行を disabled にした。グレー表示は既存の `.spellrow:disabled{opacity:.4}` が担う。行内の理由表示（戦闘専用）は残した。
- 習得済みが無いメンバーでは「習得済みの呪文がありません」の空状態を1行表示する。
- 行の小テキストは「習得済み · Lv · 確定習得/習得率50% · 理由」に整理（未解禁・未習得分岐は不要になり削除）。
- 新規テスト `tests/spell-list.cjs`（game.cjs から require）：習得済みのみの並び、探索・閲覧・宝箱対峙での戦闘専用の無効化、戦闘中で選べること、誘惑の戦闘除外の維持、空状態を検証。

## 実施者による追随（Amendment 1）

- `tests/silence-browser.py` が沈黙時の無効化確認に未習得の真回復（madi、Lv11）行を使っていたため、新仕様では行自体が存在せず失敗した。意図（沈黙中は習得済み呪文も選べない）は習得済みの2呪文で担保できるため、対象から madi を外した（1280px/390px とも合格）。

## 検証（実施者）

- node テスト 41/41、ブラウザテスト 37/37（silence 追随後）、compile-monsters --check（100種）、sim selftest、MANIFEST 照合（差分は再生成後に確認）すべて合格。
- 実経路（ブラウザ実操作）：探索中の魔法使いのリストは習得済み4呪文のみで、火炎は disabled＋opacity .4＋「戦闘専用」表示。僧侶は治療・防御のみ（真回復など未習得は非表示）で治療は有効。戦闘中は火炎が有効になり、選ぶと行動予約（呪文・火炎）が入ることを確認した。
- 呪文データ・習得判定・セーブ形式には変更なし。図書館のカタログは対象外で不変。
