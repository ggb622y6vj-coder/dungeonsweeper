## 変更内容

- dist/game.js: RACE_SPRITES（種族→ファイル名の固定表）と MONSTER_SPRITES（固有画像の一覧、空）を追加。enemySpritePath() が優先順（確定＋固有画像 → 種族の画像 → なし）を返す。drawEnemies() は画像があるグループを #scene に重ねる img.enemy-sprite として返し、画像がない・読み込み失敗のグループは従来の枠＋icon文字で描く。読み込み失敗は #scene の error 監視で記録し、再描画でフォールバックする。enemySpriteSize() が目標サイズ（壁の高さ95%と横150単位の小さい方）と条件付きの丸め（48の整数倍、±15%以内）を計算し、ResizeObserver と resize で CSS 変数を更新する。テーマごとの色付けフィルタ（feComponentTransfer、SCENE_PALETTES の中間色から生成）を #enemy-sprite-filters へ定義した。scene() は戦闘中に正面の記号をすべて消し（左・右は数字のみ従来どおり）、遠見へ hideSymbols を渡す。
- dist/index.html: フィルタ定義用の SVG（.sprite-filter-defs）を追加。.enemy-sprite の CSS（bottom:25%＝壁の下端 y=300、translateX(-50%)、image-rendering:pixelated、pointer-events:none）。 .scene-enemies は画像と重ならないよう最大幅を制限する形に変更。
- dist/spells.js: distantSight(hideSymbols) で戦闘中の斜め前の記号だけを消す（壁の描画は残す）。
- docs/ARCHITECTURE.md・docs/SPECIFICATION.md: 「外部画像なし」の記述を、dist 内のモンスターのドット絵を使う形に改めた。
- tests/monster-sprites.cjs（新規）: 全モンスターの race が対応表にあり、画像ファイルが存在し、48×48・グレー4値のみであることを検証。tests/game.cjs に登録。
