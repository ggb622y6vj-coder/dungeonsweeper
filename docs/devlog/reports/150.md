# 150　モンスターの固有ドット絵

`monster-sprites-v3` ブランチに実装（26e551e の原画追加の続き）。作業は Claude Code（claude-opus-5-5）。[仕様150](../specs/150-monster-unique-sprites.md)

## 実施内容

- art-src/monster-sprites-v3/ の114枚を dist/assets/monsters/<ID>.png へコピーした（原画とバイト一致）。種族画像10枚（dist/assets/monsters/unknown/）は変更していない。
- dist/game.js の MONSTER_SPRITES に、ENEMIES の全114 ID を固定一覧として登録した。ENEMIES から自動構築しないのは、画像のないモンスターを追加したときに読み込み失敗（枠＋icon文字）ではなく種族画像になるようにするため。登録漏れ・画像漏れはテストで検出する。
- 表示の優先順（確定かつ登録済み→固有画像、それ以外→種族画像、読み込み失敗→枠＋icon文字）と failedEnemySprites は144のまま。未確定の間は固有画像のIDを画面に出さない。
- data/README.md の種類数を114に直し、モンスター追加時の画像登録手順を追記した。SPECIFICATION・ARCHITECTURE・art-src の README の画像の記述を現状に合わせた。
