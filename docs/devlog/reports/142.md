# 142　アイテムの最浅階と敵からの直接ドロップの廃止

2026-11-26、`hold/142` の作業ツリーに実装。未コミット。[指示書142](../specs/142-remove-minfloor-and-direct-drops.md)

## 実装

- 通常戦の勝利報酬を経験値・金貨とし、撃破ごとの装備抽選を削除した。宝箱戦の金貨は従来どおり開封時に配布する。旧戦闘データに `pendingDrops` が残っていても装備が増えないことを回帰テストに追加した。
- 装備87品・薬5品の最浅階を廃止。旧形式の宝箱では、対象装備を階ごとの価格上限以下から等確率で選び、候補が空なら最安の1品を使う。薬は独立した30%抽選で、全階で5種それぞれの重みを使う。
- 図書館の入手先は「店売り・迷宮」「迷宮限定」の2表記。sim の `drop` 装備では1階でも聖剣を選べることを確認した。
- アイテムデータを変更前と照合し、全92品で `minFloor` 以外のフィールドが一致した。NotionのDB・スナップショットとセーブ形式 `ash-v1` は変更していない。
