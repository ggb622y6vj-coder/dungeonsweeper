# 138 パーティー欄から開く呪文ダイアログの戻り先

実施日 2026-11-25。対象ブランチ `hold/138`。[指示書138](../specs/138-stats-magic-return.md)

## 実装

- パーティー欄の呪文ボタンは、パーティー欄の上に呪文ダイアログを開く。×・Esc・背景クリックでパーティー欄に戻る。ダイアログから直接発動する探索呪文は、既存の再描画でログの進行に合わせてパーティー欄のMPなどを更新する。
- 味方の対象選択では両ダイアログを閉じる。キャンセルするとパーティー欄を再描画して開き、その上に直前の選択を保持した呪文ダイアログを開く。対象を決定して発動するとメイン画面に戻る。
- 新規ブラウザテストは1280px・390pxで、ダイアログの開閉、探索呪文のMP表示、味方対象選択のキャンセルと発動、アイテムを閉じたときの戻り先を検証する。対象選択・転職・上級職・石化の既存テストも戻り先に合わせて更新した。
