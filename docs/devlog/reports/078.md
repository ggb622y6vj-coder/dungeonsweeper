# 078 実装報告：マス数が多い階で地図のアイコンが下にずれる不具合の修正

日付：2026-11-06（JST）
仕様：[specs/078-bugfix-map-cell-icon-alignment.md](../specs/078-bugfix-map-cell-icon-alignment.md)
対象バージョン（基準 main）：0a92c29（077 統合・検証記録済み）
状態: ローカルの hold/078 のみで未push（push はユーザーの確認後）。main への統合は行っていない。

## 不具合と再現（実施者の実測）

- ユーザー報告：3F でマス数が多くなると、地図のアイコン（数字・旗など）が各マスの下寄りにずれる（iPhone Safari の実機スクリーンショット付き）。
- ローカル Chromium（390px幅、地図ダイアログ）で再現し、`.cell-number` の中心とマス中心の縦ずれを実測した：
  - 修正前：1F（8×8、マス高さ約36px）で平均 +2.6px、3F（12×12、マス高さ約23px）で平均 +6.2px・最大 +10.2px。
  - マスが小さいほどずれが大きく、深い階とモバイル幅で目立つ。PC幅ではマスが大きく目立たなかった。
- 仕組み：`.cell`（button）が中身を通常フローの行ボックスで配置していたため、マス高さが行ボックスより小さくなると文字が下にはみ出して見えた。

## 実施内容

- `dist/index.html` の CSS のみ変更した。`.cell` をフレックスコンテナ（`display:flex; align-items:center; justify-content:center`）にして中身を明示的に中央配置し、`.cell-number` に `line-height:1` を追加した。
- フォントサイズ、色（077 のテーマ帯の上書きを含む）、マスの大きさ・間隔、方向マーカー（絶対配置）の見え方は変更していない。
- 回帰テスト `tests/map-cell-alignment-browser.py` を新規追加した：390px幅と1280px幅で 12×12 と 8×8 の地図（ダイアログ／ドック）を開き、数字のある全マスについてアイコンの中心ずれが縦横 ±2px 以内であることを確認する。

## 検証結果（実施者）

- 修正後の実測：1F・3F ともずれは平均 0.00px（最大でも 0.01px）になり、全マスで中央に一致した。
- `tests/*.cjs` 全33本：PASS。
- ブラウザテスト全35本（map-cell-alignment-browser.py を新規追加）：PASS（1280px／390px）。
- `python3 scripts/compile-monsters.py --check`：PASS（95種）。シミュレーション自己テスト：PASS。
- 画面確認（`docs/devlog/reports/078-shots/`）：3F・390px幅の地図ダイアログで、数字・旗・現在地マスが中央に表示されることを確認した。1F の同画面も保存している。
- `MANIFEST.sha256`：全ファイル照合 OK（この記録のコミットで再生成）。
