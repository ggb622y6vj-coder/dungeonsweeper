# 指示書117: 4F の反呪文ゾーン（魔法が使えないマス）

## 目的
地下4階の中心部に、呪文が一切使えない「反呪文の結界」ゾーンを設ける（オーナー指示、2026-11-18）。指示書115/116 の 3F ゾーンと同じ幾何を使う、階ごとに異なる効果のゾーンの2つ目。

## ゾーン定義
- 対象は 4F のみ。範囲は 3F ゾーンと同一：中心 ((size-1)/2, (size-1)/2) からユークリッド距離3以下、32マス（外周16マス）。116 で切り出した inMapBlindZone(x, y, n) と同じ計算を共用すること。
- 判定はプレイヤーの現在地（s.pos）がゾーン内かどうかで行う（戦闘もそのマスで発生するため、敵の呪文も同じ判定でよい）。
- 4F では地図は隠れない（ブラインドは 3F のみ）。セーブ形式は変更しない（階と座標から導出）。

## 効果1：発動中の魔法の解除
- ゾーン内では、発動中の魔法欄（activeSpellEffects）に載る持続効果がすべて解除され、維持されない。対象は既存の4種に対応する状態：透視・大透視（s.milwaSteps、s.light）、警戒結界（s.watchful）、旗視（s.flagSight）、鉄壁（s.teppeki）。
- 解除は入った時点で起き、どの経路で入っても（通常移動・階段・昇降機・落とし穴・階生成時の開始位置）漏れないこと。単一の冪等な箇所で同期するのが望ましい（例：render() 内でゾーン内なら毎回クリアする）。
- 解除は無言（ログを出さない）。ゾーンを出ても効果は戻らない（再び唱え直す必要がある）。
- 状態異常（麻痺・沈黙・睡眠・石化など）や使用回数カウンタ（dumapicUses 等）は解除対象ではない。

## 効果2：発動中の魔法欄への表示
- ゾーン内にいる間、activeSpellEffects() の一覧に「反呪文の結界」を含める。説明文は「この範囲では呪文が打ち消され、発動中の魔法も解除される」、残りは「このマスにいる間」とする。
- ゾーン内では上記の持続効果は解除済みなので、一覧に出るのは原則この1件のみになる。

## 効果3：呪文の打ち消し
- 味方の呪文：すべての発動経路（探索中の呪文ダイアログ、宝箱の calfo、戦闘中の呪文コマンド実行）が通る castMagic で打ち消す。通常の使用可否チェック（spellReason 等）を通過した後、コスト消費より前に判定し、次を行う：
  - ログに「反呪文の結界に打ち消された！」を出す（この文言を正確に）。
  - MP を消費しない。血の代償による HP 消費もしない。使用回数カウンタ（dumapic/floodfill の倍増カウンタ）も増やさない。
  - 呪文の効果は一切発生しない。戻り値は失敗（false）として、既存の失敗時の流れ（ダイアログを閉じる等）に従う。
  - 戦闘中は、そのメンバーのそのターンの行動として消費される（実行時点で打ち消される）。
- 敵の呪文：monsterAction の呪文分岐で、敵が実際に唱えようとした時点（沈黙チェックを通過した後）で同じログ「反呪文の結界に打ち消された！」を出し、効果を発生させず、その敵の行動を消費する（return true）。「〜を唱えた。」のログは出さない。
- 対象は呪文のみ。敵のブレス・仲間呼び、アイテム・薬の使用は対象外で従来どおり。

## 効果4：透視中の枠表示（3F とは別の枠）
- 4F で透視状態（s.milwaSteps > 0 || s.light、116 と同じ定義）の間、ゾーン外周16マスに枠を表示する。116 の zoneframe（紫・実線）とは異なる枠にすること：新しいクラス（例：antiframe-top/right/bottom/left）と CSS 規則で、--red-75 の2px破線とする。
- 付けるのはゾーン外に面した辺のみ（116 と同じ方式）。通常描画にのみ現れる（4F にブラインド描画はない）。
- 透視自体も解除対象なので、ゾーン内に入ると透視が切れて枠も消える。枠が見えるのはゾーンの外からが原則で、それでよい。
- 3F の zoneframe は従来どおり（紫・実線）で、4F で zoneframe が付くことはない。逆も同様。

## 変えないこと
- 3F ゾーンの挙動（ブラインド、通知、枠）、ゾーン出入り・解除のいずれでもログを出さないこと（打ち消し時の1行だけが例外）。
- 呪文の選択可否（spellReason）にゾーンを理由とするブロックを足さない。唱えようとして初めて打ち消されるのが仕様。
- セーブ形式、呪文データ、敵データ。

## テスト
- 新規ブラウザテスト tests/117-antimagic-zone-browser.py を追加する。最低限：
  1. 4F で持続効果を付けた状態でゾーン外→内へ移ると、4種すべて解除され、s.logs に変化がない（無言）。activeSpellEffects に「反呪文の結界」が含まれる。
  2. ゾーン内で探索呪文を唱えると、打ち消しログが出て MP が減らず、効果が発生しない。ゾーン外では通常どおり唱えられる（対照）。
  3. ゾーン内の戦闘で味方が呪文コマンドを実行すると、打ち消しログが出て MP が減らない。
  4. 敵の呪文：呪文を使う敵について、乱数を固定して呪文分岐に入る条件で monsterAction を呼び、ゾーン内では打ち消しログのみで味方に被害がないこと、ゾーン外では通常どおり唱えること（対照）。
  5. 枠：4F＋透視で antiframe が16マスに付く（破線・赤を computed style で確認）。透視なしでは0。3F では antiframe が付かず zoneframe のみ。5F の中心ではゾーン効果が一切ない（解除・打ち消し・枠すべてなし）。
- 既存テストが新仕様で壊れる場合は、元の検証意図を弱めない範囲で追従修正してよい（判断したら報告に明記）。特に 4F で呪文を使う戦闘・探索のフィクスチャは、位置がゾーン内だと影響を受ける点に注意。
