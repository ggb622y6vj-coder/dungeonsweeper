# 067 [light] 図書館のモンスター情報から確率（%）表記を消す

## 背景
- ユーザーの要望（原文）：「図書館のモンスターに載る情報ですが、『毒15%』とか出てきますが、15%は取ってください」
- 今の実装（origin/main 6c4ac79、dist/library.js の `libraryMonsterDetails`）：
  - **状態異常タグ**（060、色付きの `ailment-tag ailment-{type}`）：対象は毒・麻痺・石化・恐怖・睡眠・沈黙です。タグの後ろに、`span.library-chance` で「15%」などが付きます。
  - **その他能力タグ**（灰色の `ailment-other`）：ブレス（「炎のブレス」）、アイテム奪取、レベル吸収、即死、仲間呼び、後衛攻撃、逃走、耐性。どれも名前だけで、数値は付きません。
  - **使用呪文の欄**：沈黙の呪文だけ「{呪文名}（沈黙・全体 N%）」と % が付きます。そのほかは呪文名だけです。
  - **数値の項目**（タグではありません）：HP・物理ダメージ（ダイス式）、攻撃回数、経験値、撃破数。
- 実装の順番：065・066 の後に入れます。066 も library.js に触る可能性があるので、main を取り込み直してから作業してください。

## 仕様（基本方針は「確率だけ消す」）
1. 状態異常タグの `span.library-chance` を作らないようにします。タグは「毒」「麻痺」などの名前と色だけにします。
   - `ability.chance` の生成と、使われなくなった CSS `.library-chance` は削除します。
2. 使用呪文の欄の「（沈黙・全体 N%）」は「（沈黙・全体）」にします（質問1を参照）。
3. 図書館のモンスター表示の中に、「数字＋%」の形の文字列が 1 つも出ないようにします。
4. 次のものは変えません：
   - 内部データ（ENEMIES・CSV）、戦闘の計算、Notion
   - HP・ダメージなどのダイス式と回数の項目（確率ではないため）
5. % 以外の数値の扱い：
   - 仲間呼びの「上限n」、ブレスのダメージ式、即死などの確率は、今の図書館にもともと表示されていません。このため、今回は何もしません。

## OKの判定方法
- **tests/library.cjs**：
  - slime などの `libraryMonsterDetails` の期待値から「%」を取り除く。
  - すべてのモンスター（92 体）の details を文字列にしたとき、`/\d+%/` に一致しないことを確認するテストを追加する。
- **tests/library-fields-browser.py**：
  - 59 行目の `'30%' in` という確認を、「毒」のタグがあり、かつ `%` を含まない、という確認に置き換える。
  - 1280 と 390 の幅で、図書館に登録済みの全エントリの `inner_text()` に `%` が無いこと、および `.library-chance` の要素が 0 個であることを確認する。
- 既存のテストがすべて通ること（library、library-identify、identifyfoe など）。
- ライブ版での目視確認：390 と 1280 の幅で、図書館の邪眼のエントリのスクリーンショットを添付する。

## 質問（括弧内がおすすめ）
1. 使用呪文の「（沈黙・全体 N%）」の % も消しますか？（**おすすめ：消す**。そして「（沈黙・全体）」にします。要望の趣旨は「確率を見せない」ことだと読みました）
2. いま図書館に出ていない数値（仲間呼びの上限、ブレスのダメージ式）は、これからも出さないままでよいですか？（**おすすめ：出さないまま**）
