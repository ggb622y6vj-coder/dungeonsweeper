# 073 [light][bugfix] ログで「解毒剤」の一部が呪文色になる

対象コード: origin/main 2aa8e8d（読み取りのみ）

## ユーザーの要望（原文）
> 呪文の名前を変更しました。毒を治療する呪文を、解毒という呪文の名前にしました。すると、「解毒剤」というアイテムの一部が呪文の色になっていますので直してください。

## 背景（現状）
- 072 で毒を治す呪文の名前が「ラツモフィス」→「解毒」に変更された（dist/spells.js の `MAGIC`、id は `latumofis` のまま）。
- ログの色付けは dist/game.js の `coloredLog(text)` が担当する。敵名・味方名・呪文名・旗名を正規表現の選択肢として部分一致で探し、`<span class="log-...">` で包む。
- アイテム名は色付けの対象一覧に入っていないため、「解毒剤」という文字列の中の「解毒」の部分だけが呪文名に一致し、`log-spell` 色で表示されてしまう。
- 影響範囲はログ表示のみ。解毒剤の効果・所持・使用処理に問題はない。

## 仕様
1. アイテム名（武器・防具・薬の全名称）は分割できない1語として扱う。ログにアイテム名が現れた場合、その文字列のどの部分にも呪文・敵・味方などの色付けを適用せず、通常色のまま表示する。
   - 対象データは実行コードの正本（`WEAPONS`・`ARMOR`・`MEDICINES`）から取る。名前をベタ書きで複製しない。
2. 独立した呪文名「解毒」は、これまでどおり `log-spell` 色で表示する（例：「僧侶は解毒を唱えた。」）。
3. 既存の色付け（味方・敵・旗・ダメージ数値・回復数値）と HTML エスケープの挙動は変えない。
4. 呪文・アイテムのデータ、名前、効果、セーブキー `ash-v1` は変更しない。変更は色付け処理とテストに限る。

## 変更するファイル
- dist/game.js（`coloredLog`）
- tests/game.cjs（回帰テスト追加）
- MANIFEST.sha256（再生成）
- 必要に応じて新規ブラウザテスト tests/*-browser.py

## OKの判定方法
- 回帰テスト: `coloredLog('○○は解毒剤を使った。')` の出力に `log-spell` が含まれず、「解毒剤」が通常色のまま連続して残る。`coloredLog('○○は解毒を唱えた。')` の出力には `class="log-spell">解毒</span>` が含まれる。
- 上記の回帰テストが修正前のコードでは失敗することを確認する。
- `node tests/game.cjs` を含む全 `tests/*.cjs` が合格し、`python3 scripts/compile-monsters.py --check` が通る。
- ブラウザテスト（1280px / 390px）: 解毒剤の使用ログと解毒の詠唱ログを表示し、解毒剤が通常色・解毒が呪文色であることをスクリーンショットで目視確認する。スクリーンショットは docs/devlog/reports/073-shots/ に置く。
- MANIFEST.sha256 を再生成し、`sha256sum -c MANIFEST.sha256` が OK になる。
