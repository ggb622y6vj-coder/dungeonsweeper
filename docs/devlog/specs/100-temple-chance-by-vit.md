# 指示書100：寺院の蘇生成功率を VIT 依存にする（原作式への差し替え・上限は維持）

## 依頼（ユーザーの言葉）

「原作のように、VITを寺院での蘇生成功率にも影響するようにしてください。」（2026-11-11）

上限の扱いはユーザーが選択肢から決定した（2026-11-11）：**「上限を維持：成功率は死亡95%・灰90%まで（失敗の余地を残す）」**。

## 背景（実測）

- 現行 `templeChance(m)`（dist/game.js:272）は原作の式と同じ形で、変数だけがレベルになっている。本作の仕様書でも「本作の暫定式」と明記されている。
  - 現行：死亡 `clamp(50＋3×Lv, 50, 95)`%、灰 `clamp(40＋3×Lv, 40, 90)`%、石化 100%。
- 原作（Wizardry #1、Temple of Cant。コード解析資料 Zimlab "Wizardry #1-2-3 Game Code Calculations" Section 1）：
  - 寺院の蘇生成功率は **死亡 `(50＋3×VIT)`%、灰 `(40＋3×VIT)`%**。
  - 「成功で VIT −1」「VIT 3 の対象はロスト」は蘇生**呪文**（DI／KADORTO、成功率 `4×VIT`%）の仕様であり、寺院の仕様ではない。本作に蘇生呪文はないため、今回は対象外とする（下記「変更しないこと」）。
- 099 で導入した VIT は現行 3〜18、生成時 10〜13、旧セーブは 10 で補完される。099 の仕様書追記には「VITは寺院の成功率・費用には影響しない」と書かれており、本指示でその一文を更新する。

## 変更内容

### 1. templeChance の変数を Lv から VIT へ（dist/game.js）

- 死亡：`clamp(50 ＋ 3×VIT, 50, 95)`%
- 灰：`clamp(40 ＋ 3×VIT, 40, 90)`%
- 石化：100% のまま。
- VIT は `m.vit ?? 10` で読む（099 の補完方針と同じフォールバック。通常のロスターは ensureProfile で補完済みだが、関数単体でも安全に評価できるようにする）。
- レベルは成功率に影響しなくなる。費用 `templeCost` は現行のレベル依存のまま変更しない。
- 寺院一覧の「成功率 X%」表示は `templeChance(m)` をそのまま使うため、自動的に新しい数値になる。表示形式は変えない。

参考値：VIT 3 → 死亡59%・灰49%、VIT 10 → 80%・70%、VIT 13 → 89%・79%、VIT 15 → 95%（上限到達）・85%、VIT 16 → 95%・88%、VIT 17 → 95%・90%（上限到達）、VIT 18 → 95%・90%。

### 2. 仕様書（docs/SPECIFICATION.md）

- 寺院の段落（費用と成功率の「本作の暫定式」の箇所）：成功率の式を VIT 依存に書き換え、上限・下限と「レベルは成功率に影響しない」旨を明記する。費用の記述は変えない。
- 099 で追加した「VITは寺院の成功率・費用には影響しない。」の一文を、成功率への影響を述べる形に更新する（費用には影響しない点は維持）。

### 3. テスト

- `tests/temple.cjs` の式テストを VIT 基準に書き換える：
  - コスト表は現行のまま（レベル依存で不変）。
  - 成功率は VIT を固定した行で検証する：境界として VIT 3（死亡59・灰49）、VIT 10（80・70）、VIT 15（死亡が上限95に到達）、VIT 16（灰88）、VIT 17（灰が上限90に到達）、VIT 18（95・90）を含める。成功／失敗の閾値判定（ちょうどの値で失敗、わずかに下で成功）の既存パターンは維持する。
  - レベルが成功率に影響しないこと（同じ VIT・異なるレベルで同値）を追加する。
  - VIT 未設定レコードのフォールバック（`vit` なし → 10 として死亡80・灰70）を確認する。既存の `level:0` フォールバック行はこの形に置き換える。
  - 4結果（成功・灰化・ロスト・石化解除）の統合テストは、乱数の極端値（0／0.999 相当）で制御している範囲では変更不要のはずだが、新しい成功率でも成立することを確認し、必要なら成功率に依存しない形に直す。
- `tests/petrify.cjs` の石化解除成功率 100 の確認は不変で通るはず（確認のみ）。

## 変更しないこと

- 費用（`templeCost`）、失敗時の状態遷移（死亡→灰、灰→ロスト）、成功時の HP・MP 全快、費用は成否にかかわらず消費、金貨不足時は実行不可、対象外ステータスの扱い。
- 蘇生で VIT を下げない。蘇生呪文は追加しない。
- 寺院の UI のレイアウト・文言（成功率の数値だけが変わる）。
- セーブ形式（`ash-v1`、rosterVersion:1）。新しいフィールドは追加しない。
- Notion は変更しない。
