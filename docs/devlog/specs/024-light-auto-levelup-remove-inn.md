# 024 [light] 帰還時に自動レベルアップし、宿屋（馬小屋）を廃止する

## 目的
本人の判断です。レベルアップを先延ばしにする理由がないので、町に戻った時点でレベルアップさせます。宿屋は不要になります。

## 変更
- 迷宮から町へ帰還したとき（全快処理と同じタイミング）に、status が ok のメンバーだけ levelUp を実行する。死亡・灰・ロストのメンバーは XP を保持したまま据え置く（023a と同じ扱い）。
- レベルアップした人がいるときだけ、既存の showLevelReport でレベルアップ報告を表示する。
- 町メニューから宿屋を削除する（#innopen、#inndialog、stayAtInn、#stable）。関連のテスト・シミュ・ドキュメント・ブラウザテストも追従させる。
- セーブデータの互換性を保つ（ash-v1 の既存データで落ちないこと）。

## OKの判定方法
- 経験値が足りている ok メンバーは、帰還直後にレベルが上がり、報告が出る。HP と MP は新しい最大値で満タン。
- 死者が混じっていても、死者は上がらず、XP も消えない。
- 町に宿屋のボタンやダイアログが残っていない。
- `node tests/*.cjs`、`compile-monsters --check`、`sim selftest`、`training-browser.py`（1280px/390px）がすべて PASS。
