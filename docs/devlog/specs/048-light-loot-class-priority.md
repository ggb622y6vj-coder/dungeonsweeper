# 048 [light] 拾ったアイテムは使える職業のメンバーを優先して受け取る

## 背景
宝箱（items.js:16）は職業を見ず、空きのある先頭メンバーが受け取るため、実質前衛先頭に集中する。敵ドロップ（game.js:143 dropWeapon）は使える職業を見るが、該当者が満杯だと捨ててしまう。

## 仕様（宝箱・ドロップ共通の受取者決定関数に統一）
1. そのアイテムを使える職業（w.classes に jobOf(i) が含まれる）で、持ち物10個未満のメンバーのうち、パーティー順で最初の人。
2. 1がいなければ、職業を問わず持ち物10個未満でパーティー順最初の人。
3. 全員満杯なら従来どおり「〜を見つけたが、アイテムがいっぱいだ。」。
- 薬など classes が全職業のものは、結果的に従来どおり先頭から。
- 受取者は生存・非石化など行動可能かを問わず従来の扱いを維持（変更しない）。
- ログ文言「〜を入手。〇〇が受け取った。」は変更しない。

## OKの判定方法
- 魔法使い専用装備を宝箱で入手 → 先頭の戦士ではなく魔法使いが受け取る。
- 使える職業のメンバーが満杯 → 空きのある別メンバーが受け取る（ドロップでも捨てない）。
- 全員満杯 → いっぱいログ。
- 既存テスト全通過＋上記テスト追加。
