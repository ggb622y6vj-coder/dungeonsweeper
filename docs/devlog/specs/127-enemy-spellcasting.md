## 0. 決定事項（試案9節の未決定事項への回答）

- 抽選の重みは試案の暫定値を採用する：両系統に候補があれば系統選択は 50:50、系統内は最高習得Lv帯 60%・それ未満 40%（下位候補がなければ最高帯 100%）。

- 即死呪文（窒息 makanito・大窒息 lakanito）と抵抗操作呪文（抵抗減少 nofice・抵抗無効化 mahaman）は今回の敵使用候補に入れない（将来の別指示で検討）。

## 2. 敵使用可の呪文（適格集合）

正本は dist/spells.js の MAGIC。敵使用可は次の ID のみとし、系統・習得Lv・使用場面（where が battle または both）・対象・効果は MAGIC の定義に従う。敵専用の適格判定をコード内に明示的な集合として持つこと。

- 魔法使い系：halito（火炎 Lv1）、katino（誘睡 Lv1）、dilto（減退 Lv3）、mahalito（大火炎 Lv5）、morlis（大減退 Lv7）、dalto（吹雪 Lv7）、mamahalito（超火炎 Lv8）、madalto（大吹雪 Lv8）、mamorlis（超減退 Lv9）、tiltowait（魔弾 Lv13）
- 僧侶系：dios（回復 Lv1）、kalki（防御 Lv1）、montino（沈黙 Lv3）、matu（大防御 Lv3）、dialko（強壮 Lv5）、dial（大回復 Lv7）、latumofis（解毒 Lv7）、dialma（超回復 Lv9）、lorto（聖化 Lv11）、madi（真回復 Lv11）、malikto（大聖化 Lv13）

上記以外の呪文（探索・宝箱・旗消費・識別・誘惑・鉄壁・抵抗操作・即死・転移など）は敵候補に入れない。

敵用ダイスの上書き（現行維持。これ以外は MAGIC のダイスを使う）：dalto [5,6,0]、madalto [6,8,0]、tiltowait [8,8,0]。

## 3. 詠唱の選択（dist/monsters.js の monsterAction）

- 行動分岐の順序（逃走→仲間呼び→ブレス→呪文→通常攻撃）と各確率は現行を維持する。呪文分岐は使用率（spell）で判定する。
- 沈黙中の個体は現行どおり詠唱しない（呪文分岐に入らず通常攻撃。消耗もしない）。反呪文の結界では現行どおり唱えた時点で打ち消され行動を消費する（その場合も5節の消耗判定は行う）。
- 候補の構築：所属グループの現在の戦闘中Lv（5節）以下で、適格集合に含まれる呪文。さらに「使う意味のないもの」を除外する：
  - 回復（heal）・真回復（restore）：負傷した生存モンスターがいない場合は除外。真回復は状態異常のみの対象にも使える（負傷または治せる状態異常のある個体がいる場合のみ候補）。
  - 強壮（cure）：治せる状態異常（睡眠・沈黙・麻痺・恐怖など、味方側 dialko が治す対象と同種で、敵個体に実際に付いているもの）を持つ生存モンスターがいない場合は除外。
  - 解毒（antidote）：毒状態の生存モンスターがいない場合は除外。
  - 防御系バフ（buff）：すでに同等以上の味方側AC補正が戦闘に適用済みの場合は除外（4節の最強のみルール）。
  - 減退系デバフ（debuff）：すでに同等以上の敵側AC補正（パーティーへの弱体）が適用済みの場合は除外。
  - 誘睡（sleep）：眠っていない生存メンバーがいない場合は除外。
  - 沈黙（silence）：沈黙していない生存メンバーがいない場合は除外。
  - ダメージ呪文は常時候補。
- 両系統に候補があれば 50% で系統を選ぶ。片方のみならその系統。系統内では、候補のうち最高の習得Lvを持つものを最高帯とし、60% で最高帯から均等抽選、40% で残り全体から均等抽選する。下位候補がなければ最高帯から 100% 抽選。
- 候補が両系統とも空なら通常攻撃へフォールバックする（行動を無駄にしない）。対象が実行時に消滅した場合は候補を再評価し、なければ通常攻撃。1行動で2回攻撃しない。

## 4. 対象変換と効果の実行

対象は MAGIC の target を次のとおり変換する（生存対象のみ）：

| MAGIC の target | 敵が唱える場合 |
| --- | --- |
| enemy（敵1体） | 生存メンバー1人を均等抽選（後衛も含む） |
| group（敵1列） | 生存メンバーのいる列（前衛／後衛）から1列を均等抽選し、その列の生存メンバー全員 |
| all（敵全体） | 生存メンバー全員 |
| ally（味方1人） | 生存モンスター1体。回復・真回復は最も負傷した個体を優先、強壮・解毒は該当する状態異常のある個体を優先 |
| party（味方全員） | 生存モンスター全員（バフ用） |

効果の実行は既存の仕組みに整合させる：

- ダメージ：既存の monsterHurt を使う（旗・生贄・潜伏解除・死亡処理は既存どおり）。味方メンバーには元素半減・呪文抵抗の仕組みがないため、敵のダメージ呪文に半減・抵抗判定は適用しない（現行どおり）。
- 誘睡：既存の敵詠唱時の処理（眠り2回）を維持する。
- 沈黙：既存の成功率式（50＋5×（敵Lv−対象Lv）、5〜94% に制限）を維持する。
- 減退系（dilto・morlis・mamorlis）：オーナー決定により対象変換の例外とし、MAGIC の target によらずパーティー全員を対象とする。味方の防御補正（既存の s.enemy.partyAC。鉄壁との最大値で実効化される）とは別に、敵の減退補正を独立した値として保持し、それぞれ最強の補正のみを有効として、実効ACでは両者を差し引く（例：防御側の補正2と減退3が重なれば最終補正は AC＋1）。旧セーブの partyAC は従来どおり防御補正として読む。3節の候補除外判定は、減退補正の現在値との比較で行う。
- 防御系（モンスター側のAC改善）：生存モンスター全員への戦闘中AC補正として適用し、重ねがけは最強の補正のみ。
- 回復・真回復：最大HPを超えない。蘇生はしない。真回復は状態異常も全回復する（madi の味方側定義どおり）。敵個体の最大HPは生成時（makeEnemy）に初期HPとして記録する。旧セーブの戦闘個体で最大HPが欠落している場合は、現在HPを上限とする（回復で増えない）。「最も負傷した個体」は HP割合（現在HP÷最大HP）が最小の個体とし、同率なら欠損HPが大きい方を優先する。
- 強壮・解毒：対象個体の該当状態異常を解除する（敵個体に付いた睡眠・沈黙・毒など、既存の敵側状態異常の表現に合わせる）。
- 詠唱ログは既存どおり「○○は△△を唱えた。」（○○は不確定名を含む表示名、△△は呪文名）。ダイスの内部計算や低下率の数値はログに出さない。ただし反呪文の結界内で打ち消された場合は現行どおり「反呪文の結界に打ち消された！」のみを表示し、「唱えた」の行は出さない（その場合も低下したときは5節の低下ログを追加する）。

## 5. 戦闘中の魔力低下（グループ共有）

- 戦闘開始時、敵グループ（rowKey で識別される列）ごとに、そのモンスターの mageSpellLevel・priestSpellLevel を戦闘中の現在Lvとして初期化し、グループで共有する。同じモンスターでも別グループなら独立。
- 状態は s.enemy 内に保存し、戦闘中のセーブ／ロードで低下後の値を維持する。旧セーブ（戦闘中Lvを持たない戦闘グループ）はマスターから初期化する。現在Lv 0 は消耗済みの有効値であり、欠落と区別すること。
- 詠唱を実行するたび（抵抗された場合・反呪文の結界で打ち消された場合を含む）、唱えた系統について 1÷（所属グループの現在の生存数＋2）で低下判定を1回だけ行う。生存数は詠唱時点の値（死亡・逃走・退散した個体は含めない。睡眠・沈黙など生存中の行動不能個体は含める）。
- 低下したら、その系統の現在Lvを「適格集合に存在する次の低い習得Lv帯」へ下げる。帯は魔法使い系 {1,3,5,7,8,9,13}、僧侶系 {1,3,5,7,9,11,13}。Lv1 の次は 0。もう一方の系統・他グループには影響しない。
- 低下した場合はログ「○○の魔力が衰えた。」を出す（○○は詠唱した個体の表示名。不確定名の実名を出さない）。
- 通常攻撃・ブレス・仲間呼び・逃走では低下しない。沈黙・行動不能で詠唱自体をしなかった場合も低下しない。
- 仲間呼びで加わった個体は所属グループの現在Lvを共有し、魔力は回復しない（生存数が増えた分、以後の低下率は下がる）。
- 戦闘終了・逃走成功・全滅・新しい遭遇で状態は破棄される（s.enemy の破棄に追従）。ボス（守護者含む）にも同じルールを適用する。敵マスター（生成データ）は戦闘で変化しない。

## 6. 図書館表示

- dist/library.js のモンスター詳細（識別済みの場合のみ）に、術者の場合だけ次を追加する：呪文Lv（魔／僧）を「mage／priest」の形で、詠唱率を % で。両Lvとも 0 のモンスターには表示しない。表示するのは初期値（マスター値）であり、戦闘中の現在Lvは表示しない。

## 7. 対象外

- 味方側の詠唱・習得・MP の仕組みは変更しない。敵に MP は導入しない。
- 二系統術者の追加割当はしない（0節）。即死・抵抗操作呪文は敵候補に入れない。
- 敵のHP・能力値をプレイ画面に出す表示は追加しない（図書館の識別済み詳細は6節の範囲で可）。
