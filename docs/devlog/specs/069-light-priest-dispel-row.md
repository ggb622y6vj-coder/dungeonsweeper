# 069 [light] 僧侶の「呪いを解く」を、選んだ敵 1 列だけにする

## 背景
- ユーザーの要望（原文）：「僧侶の『呪いを解く』を原作に近づけます。対象を敵の選んだ1列のみにし、成功率が1体ごとに判定されていないのならそうなるようにしてください。」
- 今の実装（dd3952c で確認）：
  - **コマンド**：僧侶のコマンド欄にある「呪いを解く」（combatui.js の `data-command-choice="dispel"`）。列の選択はありません。
  - **処理**：monsters.js の `dispelUndead(i)`。
    - **対象**：**全部の列**の、生きている `race==='不死'` の敵。不死がいなければ「効果はなかった。」とログに出します。
    - **判定**：**1 体ごとにすでに判定しています**。`dispelChance(術者Lv, monsterLevel(e))` で、確率は 0.5+0.05×術者Lv−0.10×敵Lv+0.6 を、5〜95% の範囲に収めた値です。
    - **成功したとき**：hp=0、`rewarded`、`escaped` を立てます（経験値は入らず、図書館の撃破にも数えません）。ログは「{名前}は消え去った。」です。
    - **失敗したとき**：「{名前}には効かなかった。」とログに出します。
    - MP は消費しません。
  - **063 の呪文抵抗**：`resistsEnemySpell` は呪文の処理でだけ使われています。「呪いを解く」は呪文ではないので、**抵抗は使っていません**。
  - **シミュレーター**：scripts/sim/combat.cjs の planTurn は、「呪いを解く」を選びません。影響はありません。
- **原作（Wizardry #1）の DISPEL**：僧侶などの戦闘コマンドで、**敵の 1 グループを選びます**。そのグループの中の不死のモンスターを、**1 体ずつ判定**して消します。経験値は入りません。（推測：細かい確率の式は機種によって違います。今の式は 0.05 刻みの係数を原作に合わせたもので、テストでも固定されています。）

## 仕様
1. **変える点**：対象を「選んだ 1 列の、生きている不死」だけにします。
   - コマンド欄で「呪いを解く」を押したら、「戦う」と同じように**列の選択**を出します（「戦う」の列選択の UI と、キーボード操作を再利用します）。
   - 選べる列は、生きている敵がいるすべての列です（射程の制限はありません）。不死がいない列も、原作どおり選べます。その列を選んだ場合の結果は「効果はなかった。」になります。
   - 選んだ列は `s.dispelRows[i]` に保存します（`attackRows` と同じ形）。
   - 確認画面の表示は「呪いを解く → n列」にします（commandSummary）。
2. **そのままの点（すでに原作に近い部分）**：
   - 1 体ごとの判定と `dispelChance` の式
   - 対象が不死だけであること
   - 成功・失敗のログの文言
   - 経験値なし・撃破に数えないこと
   - MP を消費しないこと
   - 063 の呪文抵抗を使わないこと
3. **実行時に列がなくなっていた場合**（その列の敵がターン中に全滅したとき）：「戦う」の再ターゲット（attack-retarget）と同じように、残っている列の中で一番前の列を対象にします。生きている敵がいなければ何もしません。
4. 敵の列番号が付け直される場合は、「戦う」の rowKey と同じ方法で対応します。

## OKの判定方法
- **ロジック**：tests/game.cjs の dispel のテストを更新し、tests/dispel-row.cjs を新しく作る。
  - 不死が 2 列にいるとき、1 列目を選ぶと、1 列目だけが判定される（`Math.random` を固定する）。2 列目は hp がそのまま。
  - 同じ列の 3 体が、1 体ずつ判定される。乱数を [0, 0.99, 0] にすると、1 体目と 3 体目だけ消える。
  - 不死がいない列を選ぶと「効果はなかった。」になる。
  - 選んだ列が全滅していた場合は、再ターゲットされる。
  - `dispelChance` の係数のテストは、今のまま通る。
- **ブラウザテスト**：tests/dispel-row-browser.py を 1280 と 390（タッチあり）の幅で実行する。
  - 「呪いを解く」から列を選ぶ画面が出る。マウス・タップでもキーボードでも選べる。確認画面に「呪いを解く → n列」と出る。
  - 実行すると、選んだ列だけが消える。
- 既存のテスト（keynav、battle-keys、target-select、library など）と sim の selftest がすべて通ること。sim の数値は変わらない見込みです（「呪いを解く」を使わないため）。
- ライブ版で目視確認し、スクリーンショットを添付する。

## 質問（括弧内がおすすめ）
1. 不死がいない列も選べるようにしますか？（**おすすめ：選べる（原作どおり）**。もう一つの案は、不死がいる列だけ選べるようにして、無駄打ちを防ぐ形です）

## Amendment (ユーザー回答 2026-11-04 12:11)
- 列選択で選べるのは「生存する不死がいる列」のみ（不死のいない列は選択肢に出さない／選べない）。
- 生存する不死がどの列にもいない場合、「呪いを解く」は選択できない（既存の選択不可表示に準ずる）。
- 実行時に選んだ列の不死が全滅していたら、不死が残る最前列へ切替。どこにも残っていなければ「効果はなかった。」。
- テストに「不死のいない列は選べない」「不死が全くいない時はコマンド不可」を追加。
