# 071 クイック攻撃ボタンを見出し横の小ボタンに（main 30ff726 から）

## ユーザー要望（2026-11-04 14:37 原文）
「やっぱり、「クイック攻撃」は、「戦士:行動1/6」とか出てる見出しの横に小さく出してもらえますか。「全員1列目に攻撃」というサブテキストは無くしてください。ブラウザで見るとちょっと縦長になってしまいました」

## 変更
- 「⚡ クイック攻撃」を、コマンド画面の見出し（例「戦士:行動1/6」）と同じ行の右側に、小さめのボタンとして置く。見出しの行の高さは増やさない（1行のまま）。
- サブテキスト「全員1列目へ攻撃」は削除する。
- 金色の枠など、他のボタンと見分けがつく見た目は残す（小さくしてよい）。
- 出す条件（最初に行動できるメンバーの行動選択画面だけ）、動き（攻撃できる人は先頭列、ほかは守る、行動確認なし）、攻撃できる人がいないときのグレー表示は070のまま。
- 「戻る」の下は「逃げる」だけになる。「戻る」の位置固定は070のまま。コマンド欄全体の縦の長さが070より短くなること。
- キーボード: 最初の選択は「戦う」のまま。クイック攻撃にもキーボードで移れるようにする（例: 見出し行へは コマンド欄の最上段から W）。1280と390で同じ動き。
- 390幅で見出しとボタンが1行に収まり、はみ出さないこと。

## テスト

- 1280/390 で: ボタンが見出し行にあり見出し行が1行、サブテキストがない、070比でコマンド欄の高さが減る、「戻る」のy座標が全員同じ、キーボードでクイック攻撃に移れる。
