# 025 [heavy] 町に「図書館」を追加する（モンスター図鑑・アイテム図鑑）

## 目的
本人の要望です。倒したモンスターと、手に入れたアイテムのデータを町で見返せるようにします。

## 変更
- 記録：モンスターは「倒した（勝利時に敵だった）」ときに、id ごとに撃破数と初撃破階を記録する。アイテムは「入手した（宝箱・ドロップ・購入）」ときに id を記録する。ロスターと同じ ash-v1 のセーブに保存し、パーティ全滅やキャラ抹消では消えないアカウント単位のデータにする。既存セーブは空の図鑑で始める。
- 町メニューに「図書館」を追加する。ダイアログにはモンスターとアイテムの2タブを置く。
  - モンスター：全88種を階順に並べる。未撃破は「？？？」と表示し、撃破済みは名前、出現階、HP の目安（ダイス式または平均）、攻撃回数、使う呪文、特殊能力（ブレス・毒など、データにあるもの）、撃破数を表示する。守護者や迷宮の主には印を付ける。
  - アイテム：全52品を種類別に並べる。未入手は「？？？」と表示し、入手済みは名前、種類、装備できる職業、性能（攻撃・AC・hitBonus など）、価格、店売りか迷宮限定かを表示する。
  - 上部に収集率を表示する（例：モンスター 12/88）。
- 名前の表示は textContent を使う（既存方針）。スマホ幅（390px）でスクロールして読めること。
- 戦闘中の数字非表示（007）の方針は、図書館では「撃破済みのみ表示」として例外にしてよい。

## OKの判定方法
- 新規ゲームでは、図書館が 0/88、0/52 で、すべて「？？？」になっている。
- 1階で戦闘に勝つと、倒した種類が表示され、撃破数が増える。宝箱で手に入れたアイテムと、店で買ったアイテムも表示される。
- リロードしても記録が残っている。全滅しても、キャラを抹消しても消えない。
- 1280px と 390px で、図書館の開閉と両タブが使える。ブラウザテストに図書館の開閉チェックを1つ追加する。
- 既存テスト一式がすべて PASS。
