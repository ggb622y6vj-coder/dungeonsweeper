# 060 [light] 図書館のモンスター情報の項目・表記の変更と状態異常タグ

## 背景
（origin/main eb7c9cb 時点）
- `libraryMonsterDetails` の表示項目は、出現階（地下n階）・HPの目安・攻撃（ダイス）・攻撃回数・使う呪文・特殊能力（「・」でつないだ文字列。耐性も含む）・撃破数・初撃破階です。
- パーティーのステータス画面の状態異常タグは、`ailmentTags()` が出力する `<span class="ailment-tag ailment-{poison|paralysis|stone|dead|fear|silence|sleep}">` で、色は dist/index.html の CSS で決まっています。

依存：059（識別済みの項目にこの表示を使うため）。

## 仕様
- 識別済みの項目の表示を、次の順番にします。
  1. 確定名
  2. 不確定名
  3. 種族
  4. 出現階
  5. HP
  6. 物理ダメージ
  7. 攻撃回数
  8. 特殊能力
  9. 使用呪文
  10. 経験値
  11. 撃破数
- 各項目の書き方：
  - 出現階は「**nF**」（例：4F）にします。図書館内の階の見出しも「nF」にそろえます。
  - HP はダイス表記（例：3d8+2）です。
  - 物理ダメージは【Q7】既定「1d8」（攻撃回数は別項目なので、ダイスだけを書きます）。
  - 経験値は CSV の値（例：3000）です。
  - 撃破数は「n体」です。
- 「初撃破階」は削除します。記録の `firstFloor` はセーブ互換のため残しますが、表示はしません。
- 特殊能力の中の状態異常（毒・麻痺・石化・恐怖・睡眠・沈黙）は、パーティー画面と同じ `ailment-tag ailment-{kind}` のタグで表示し、確率を添えます（例：[毒] 15%）。CSS は共通のものを使います。
- 状態異常以外の特殊能力（ブレス・アイテム奪取・レベル吸収・即死・仲間呼び・後衛攻撃・逃走）は【Q8】既定「中立色の同じ形のタグ（新しいクラス `ailment-other`）」で表示します。
- 「命中補正・AC・耐性」はリストにないため、表示しません【Q9】。ただし既定では、耐性だけは特殊能力のタグ「炎半減」などとして残します。
- 未識別の項目（059）には、この一覧を出しません。

## OKの判定方法
1. ライブの 1280 と 390 の幅で確認：識別済みの項目が上の11項目の順で並び、出現階が「4F」形式で、初撃破階がないこと。390 の幅でタグが折り返しても崩れないこと。
2. 毒・麻痺・石化・恐怖のタグの色が、パーティー画面のタグと同じこと（例：髑髏蜘蛛以外の毒持ちのモンスター、邪眼の麻痺・石化）。
3. 経験値・HP・物理ダメージが CSV の値と一致すること（3体以上をスポットチェック：大鼠、邪眼、ダイダラボチ）。
4. 古いセーブ（`firstFloor` あり）がエラーなく表示されること。
5. 全テストが通ること：tests/*.cjs すべて、ブラウザテスト（実行しなかったものは明記）、compile --check、selftest。tests/silence.cjs などにある図鑑の文言の比較は、新しい表記に合わせて更新します。
