# 039 [light] 探索のキー割り当てと旗（F）

## 共通ルール
- 作業ツリーは担当者自身のもの。push はオーナー指示があるまでしない。既存テストのチェックは削除・緩和しない。
- タッチ／マウス操作と 390px レイアウトを壊さない（既存ブラウザテスト全件PASS）。
- テキスト入力（#recruitname など INPUT/TEXTAREA/SELECT）にフォーカスがある間は、Esc 以外のキーをゲームが奪わない。
- Ctrl/Alt/Meta 付きのキーは無視する（ブラウザのショートカットを妨げない）。
- 完了条件: node tests 全件・compile-monsters --check・selftest・ブラウザテスト全件（1280/390）PASS、JSエラーなし。新規テストはキーボードだけで操作する Playwright（page.keyboard のみ、click・evaluate での直接操作は禁止。evaluate は状態の確認だけに使う）。
- 038 完了後に着手。

## 目的
オーナー指定の移動キーに合わせ、クリックしにくい旗の設置をキーでできるようにする。

## 変更内容
- 探索中（dialog・戦闘・宝箱・階段確認が無いとき）の割り当て:

| キー | 動作 |
|---|---|
| W / ↑ | 前進 |
| S / ↓ | 後退 |
| A / ← | 左回転 |
| D / → | 右回転 |
| Q | 左にカニ歩き |
| E | 右にカニ歩き（R は割り当てない） |
| F | 正面のマスに旗を立てる／外す（#frontflag と同じ処理） |
| G | 旗の種類を切り替え（#flagopen） |
| M | 地図を開く／閉じる（#maptoggle） |
| C | ステータス（#statsopen。装備・持ち物もここから） |

- 変更点: 現在 A/D がカニ歩きなのを、A/D=回転、Q/E=カニ歩きに変える（仕様書・ヘルプの記載も更新）。
- 長押しのリピートは今までどおり無視（e.repeat）。
- 宝箱・階段・ボス確認が出ているときは 041 の選択肢操作になり、移動キーは効かない（今の move() のガードを維持）。
- 地図 dialog 内でも F／G は使えない（地図は閲覧専用）。Esc／M で閉じる。

## OKの判定方法
1. Playwright（tests/explore-keys-browser.py、1280）: キーだけで迷宮に入る（038 の町操作）。
   - W/S/A/D/Q/E と矢印でそれぞれ s.pos・s.dir が期待どおり変わる。
   - R では何も変わらない。
2. 正面が未開放のマスで F → 旗が立つ。もう一度 F → 外れる。G で種類が変わり、次の F で新しい種類になる。正面が壁や範囲外のときは何もしない。
3. M で地図が開閉、C でステータスが開き Esc で閉じる。
4. 戦闘中・宝箱表示中・dialog 表示中に W/F を押しても s.pos と旗は変わらない。
5. 390 のタッチでの移動ボタンと旗ボタンは今までどおり動く（既存テストPASS）。

## 改訂（ユーザー決定 2026-11-02 20:24）
- T キーの割り当ては**しない**。「町へ戻る」（#backtown／#cleartown）は専用キーを持たず、038 のフォーカス移動で選び Space（または Enter）で決定する。
- OK判定に追加: 探索中に T を押しても何も起きない。「町へ戻る」表示中に W/S/A/D でフォーカスを当て Space で町へ戻れる（キーボードのみの Playwright テスト）。
