# 033 heavy: 石化（stone）の実装

## 共通ルール
- 既存テストを弱めない。dist・data/monsters.csv・MANIFEST を更新し、全テストを通してから push。
- 032（自動後退）の後に実装する。石化者も自動後退の対象にする。オーナー依頼 pt76u。

## 現状（6501fd7 で調査）
- 石化は未実装。「stone」は monster id の「石の番人」（2F）と「石巨人」（6F）だけで、状態異常は持っていない。
- 既存の状態:
  - 毒: 戦闘ターン・歩行ごとに2ダメージ。持続し、ラツモフィス／毒消しで治る。
  - 麻痺: 4ティックで自然回復。ディアルコ／気付け薬で治る。行動不能。
  - 睡眠: 味方の構造とディアルコ・マディの治療はあるが、味方に睡眠を与える手段は無い。
  - 死亡・灰・ロストは member.status で持つ。寺院の費用は死亡 min(100L,25L²)、灰 min(250L,60L²)。
- 状態を与えるのは monsterOnHit の statuses（CSV「状態異常」の 毒/麻痺/命中時N%、compile-monsters.py の正規表現）と罠（毒霧・麻痺の針）。
- 麻痺はすでにあるので追加しない（Wizardry の永続麻痺化も今回は扱わない）。

## 目的
Wizardry に近い石化を追加し、戦闘・探索・町・寺院を一貫して扱う。

## 変更内容
- 状態は `member.status='stone'` で持つ。HP は保持し、ailments は解除する（毒の tick も止まる）。
  - 表示ラベルは「石化」（visibleAilments、ailment-stone タグ、酒場・訓練場の（石化））。
- 戦闘・探索:
  - 行動不能にする（commandMembers・canChooseMedicine・thiefMember・呪文の使い手から外す）。
  - 敵の攻撃対象からも外す。
  - 方針は「標的にならない」を採る。ダメージ無効は採らない。理由:
    - 032 で後列に下がるので、前衛判定とあわせて対象を絞るだけで済み、実装が単純になる。
    - 無効化方式だと「〇〇の攻撃は効かない」のような無駄な行動ログが増える。
    - Wizardry でも石化者は事実上攻撃を受けない。
  - 範囲呪文やブレスがある場合も対象外にする。
  - 生存者全員が死亡・灰・ロスト・石化になった場合は全滅扱いにする（030 の遺体フロー。石化者も遺体として残す）。
- 町:
  - enterTown では回復もレベルアップもしない（XP は保持）。
  - 029/029b の自動搬送で寺院（控え）へ運ぶ。搬送ダイアログには「（石化）」と表示する。
  - 酒場・訓練場からは加入不可（029a と同じ）。
- 寺院:
  - 「石化解除」を追加する。費用は min(150L, 40L²)。死亡より高く、灰より安い。
  - 成功率は100%で、HP 満タンの ok に戻す（Wizardry の石化治療も失敗が無い）。
  - templeCost と renderTemple の表示を追加する。
- 治療手段は既存データに合うものだけにする。
  - マディ（effect restore「状態異常を全回復。蘇生不可」）は石化も治す。対象は「生存する味方」の判定を stone 込みに広げる。
  - 新しいアイテムや呪文は追加しない。
- 石化を与える敵:
  - CSV と compile-monsters.py の正規表現に「石化/命中時N%」を追加する。type は 'stone'。
  - 付与先:
    - ガーゴイル（4F）: 石化 5%
    - 石巨人（6F）: 石化 8%
    - 邪眼（8F）: 石化 10%。既存の麻痺30%は残す。
    - 混沌の落とし子（10F）: 石化 5%
  - 図鑑（library.js）の能力表示に「石化」を追加する。
  - sim（scripts/sim）が状態の type を扱っている場合は stone に対応し、selftest を通す。
- 付与時のログは「{名前}は石になった。」。そのあと 032 の自動後退が走る。

## OKの判定方法
- node で乱数を固定し、邪眼の命中で石化させる。
  - status='stone'、ログ「…は石になった。」、続けて「…が後列に下がった。」が出る。
  - 以後その人物はコマンド選択できず、敵の攻撃対象にもならない（攻撃を多数回試行して対象にならない）。
- 石化者以外が全員倒れると全滅フローになり、030/031 のテストは不変。
- マディで石化が解ける。ディアルコ・気付け薬・毒消しでは解けず、適切なログが出る。
- 町への帰還:
  - 石化者は回復もレベルアップもせず、XP を保持したまま控えへ運ばれる。
  - 搬送ダイアログに（石化）と出る。
  - 寺院に費用 min(150L,40L²) で並び、解除すると ok・HP 満タンでパーティに加入できる。
- 酒場・訓練場では（石化）表示で加入不可。ash-v1 のリロード後も状態を保持する。
- compile-monsters.py --check が通る。4体の statuses に stone が入り、図鑑に「石化」が出る。
- 1280/390 の browser テスト（石化付与→後退→帰還→寺院解除）で JSエラーと横スクロールが無い。
- tests/petrify.cjs と browser テストを追加し、既存全テスト PASS。
