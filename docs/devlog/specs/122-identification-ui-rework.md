# 指示書122：未鑑定品の表示と鑑定導線の見直し

2026-11-21、ユーザーの要望5件。121（アイテム鑑定と呪いの装備）の表示名・導線・画面構成だけを見直す。鑑定・拘束・料金・確率・セーブ形式のルールは一切変えない。担当は Codex（ユーザーが指定）。

## 1. アイテム欄上部の常時警告を全部削除

- `renderInventory()`（dist/game.js）が `#inventorynotice` に出す常時表示を両方とも削除する：拘束品があるときの `CURSE_LOCK`（「呪いで拘束されています。鍛冶屋で呪いを解除してください。」）と、未鑑定品があるときの「未鑑定品は、呪いがあると装備後に外せなくなります。」。アイテム欄を開いた直後の通知行は常に空になる。
- `#inventorynotice` の要素自体は残す。操作時のフィードバック（装備できない理由の表示など、dist/game.js の既存の書き込み）と、本指示書 3・4 の結果表示に引き続き使う。消すのは常時表示だけ。

## 2. 未鑑定の表示名を「謎の武器」「謎の防具」へ

- dist/items.js の `visibleItem()` が作る未鑑定名を変更する。武器は「謎の武器」、防具は部位（head/body/feet）を問わず一律「謎の防具」。
- 表示名は `visibleItem()`／`itemName()` 経由の全表示（入手ログ、所持品、譲渡欄、売却・捨てる確認、サービスリスト等）に自動で追従する。内部ID・トークン・売却額などの数値は変えない。
- 敵の表示名 `UNKNOWN_NAMES`（「正体不明」）は対象外で変えない。

## 3. 司教鑑定をアイテム欄へ移設

- ステータス画面の「鑑定」ボタン（`data-stat-identify`、dist/game.js の renderStats とクリック処理）を削除する。
- アイテム欄（所持品ダイアログ）で、表示中のメンバー i について `canBishopIdentify(i)` が真のとき、未鑑定の行に「鑑定」ボタンを追加する。司教鑑定は自分の所持品のみが対象なので、このボタンは表示中メンバーが鑑定可能な司教のときにだけ出る。
- 実行は従来どおり：確認ダイアログ（`#itemchoicedialog`、「○○を鑑定しますか？ 呪いに触れることがあります。」）を経て `performItemService('bishop', target)`。成功率（10＋5×Lv%）・呪い接触率（35−3×Lv%）・拘束・図書館登録・ログ出力は121のまま変えない。
- 実行後はアイテム欄を再描画し、結果文を `#inventorynotice` にも表示する（ログには従来どおり残る）。
- `openItemChoice()` の `itemService` 前提条件は、アイテム欄からの呼び出しで満たせるよう適宜調整してよい。鍛冶屋側（5）の確認・実行の挙動は変えない。
