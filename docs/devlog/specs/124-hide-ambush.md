# 指示書124：盗賊・忍者の「隠れる／奇襲」追加

出典：Notion 実装予定DBの試案「盗賊・忍者の『隠れる／奇襲』追加（Muse向け試案／未承認）」。オーナーは試案の推奨案をすべて採用すると決定した（2026-11-21）。本仕様書が実装の正本であり、試案との差分は本書が優先する。実装担当は Codex（gpt-6.2-astra）。

## 1. 決定事項（試案セクション9のオーナー確認への回答）

1. 奇襲のダメージ倍率は2倍を採用する。命中ボーナスは付けない。
2. 「隠れる」の成功率は90%固定（Lv・AGI・敵Lvによる成長式は入れない）。
3. 潜伏中に防御を選ぶと潜伏は解除される（原作Vの「防御で維持」は採用しない）。敵の独立した発見判定は入れない（発見は第4節の全候補潜伏時のみ）。
4. 前衛近接の奇襲射程は敵3列目まで延長する。奇襲が失敗扱いになった場合は、通常射程内なら通常攻撃に切り替える。
5. 防御による潜伏解除のタイミングはターン開始時点とする（着手前確認で Codex が「実行時点では防御について一意に決まらない」と検出し、オーナーが A 案「ターン開始時に解除」を選択。B 案「本人の行動順が来た時に解除」は不採用）。

## 2. 基本仕様

- 使用可能職：盗賊（job 3）・忍者（job 6）のみ。現職で判定する（`jobOf(i)`）。Lv1から使用可。前衛・後衛とも可。
- 使用場面：戦闘中のみ。戦闘外では使えず、潜伏状態を探索や次の戦闘へ持ち越さない。
- 消費：MP・金貨・アイテムの消費なし。呪文ではないため、反呪文の結界内・沈黙中でも「隠れる」「奇襲」は使える（沈黙は潜伏を解除しない）。

### 隠れる

- 戦闘コマンドに盗賊・忍者専用の選択肢「隠れる」を追加する。潜伏中のメンバーには「隠れる」を出さない（非表示または無効化）。
- 「隠れる」は1行動を消費する。成否判定はコマンド選択時ではなく、本人の行動が AGI 混合順に実行される時点で1回だけ行う。成功率90%（両職共通・固定）。
- 成功すると潜伏状態になる。そのターン、その時点より後に行動する敵から潜伏の効果を受ける。本人の行動前に敵の攻撃を受けることはある（従来どおり）。
- 失敗した場合は通常状態のまま（潜伏しない）。どちらの場合もその行動で攻撃はしない。
- 本人の実行順が来る前に行動不能になった場合は、既存の行動無効化の扱いに従う（隠れるは実行されない）。

### 奇襲

- 潜伏しているメンバーだけが選択できる。潜伏したターンと同じターンには実行できない（次ターン以降の行動としてのみ）。
- 攻撃内容は通常攻撃と同じ武器・攻撃回数・命中判定を使い、確定した物理ダメージの合計を2倍にする（第5節）。
- 奇襲を実行すると、命中・空振りを問わず潜伏は解除される。
- 後衛の近接武器で通常の「戦う」が選べないメンバーでも、潜伏していれば「奇襲」は選べる。

## 3. 射程（奇襲時）

射程は敵の生存列に対して既存の並び順（行 key を維持）で数える。通常攻撃の射程は変更しない。

| 武器・隊列 | 通常時 | 奇襲時 |
| --- | --- | --- |
| 近接・前衛 | 敵1〜2列 | 敵1〜3列 |
| 近接・後衛 | 攻撃不可 | 敵1〜2列 |
| 遠距離（弓）・前衛 | 敵全列 | 敵全列 |
| 遠距離（弓）・後衛 | 敵全列 | 敵全列 |

- 対象選択後に敵列が全滅した場合は、奇襲の射程内で既存の対象再選択ルールを適用する。射程内に再選択先がなければ空振り（「届かなかった」）として処理し、射程外への通常攻撃を強制実行しない。
- 実行直前に、潜伏の有無・職業・武器・隊列（前衛／後衛）を再検証し、射程は実行時点の隊列で判定する（コマンド選択後の自動隊列変更に追従する）。

## 4. 潜伏の効果と解除

### 効果

- 敵の通常物理攻撃の標的候補（既存の規則で決まる候補集合）から、潜伏中のメンバーを除外する。露出している候補が1人以上いる限り、残りの候補内で従来の抽選を行う。敵の射程そのものは拡張しない（露出者が後衛にしかいない場合も、既存の敵射程のまま）。
- 敵の呪文・ブレス・全体攻撃、毒の tick、状態異常の付与には影響しない。単体呪文への回避も追加しない。被ダメージや毒だけでは解除されない。

### 発見（全候補が潜伏中のとき）

- 標的候補が全員潜伏中で候補集合が空になった場合に限り、通常の候補プールに戻して従来どおり抽選する。選ばれた潜伏メンバーは攻撃の処理前に発見され、潜伏が解除される（ログ：「△△に○○の潜伏が見破られた。」△△は攻撃する敵の表示名、○○はメンバーの表示名）。そのうえで通常攻撃を処理する。戦闘が停止しないこと。

### 解除条件

次のいずれかで潜伏は解除される。解除は原則として「実行時点」で効く（コマンドの選択し直しだけでは状態を変えない）。ただし防御は例外で、現行の防御がターン開始時に発効する（「身を守る」の表示とダメージ軽減の開始がターン開始時点）ことに合わせ、ターン開始時点で解除する（オーナー決定・下記経緯）。

- 奇襲を実行した（命中・空振りを問わない）。
- 奇襲以外の行動を実行した（通常攻撃・呪文・薬・解呪など）。防御を選んだ場合はターン開始時点で解除される（そのターンは最初から敵の通常攻撃の標的候補に戻る）。
- 行動不能になった（睡眠・麻痺・恐怖・死亡・石化）。沈黙だけでは解除しない。
- 第4節の発見を受けた。
- 戦闘が終了した（勝利・全滅・逃走成功・敵の退散・町への帰還・新しい遭遇の開始）。逃走が失敗してターンが消費される場合も、その時点で全員の潜伏を解除する。

### 奇襲の失敗扱い

- 奇襲の実行時点で潜伏が解除されていた場合（発見を受けた等）は「奇襲に失敗した」として扱い、失敗を伝えるログを出す。そのうえで、対象が通常攻撃の射程内なら通常攻撃として処理する（倍率は付けない）。通常射程外なら空振りとして処理する（攻撃は発生しない）。

## 5. ダメージ計算

- 奇襲のダメージは、通常の物理攻撃（`physicalAttack`）の処理を再利用し、命中した攻撃の確定物理ダメージの合計に2倍を適用する。旗による倍率など既存の補正は通常攻撃の中で一度だけ適用され、二重適用しない。
- 命中ゼロなら0ダメージ。攻撃回数は増やさない。命中判定への補正は付けない。
- 武器の追加効果（毒など）の判定回数は従来どおり。MP吸収は、2倍後の確定ダメージを入力として既存の上限式で処理する。
- ダイスの内部計算をログに出さない（リポジトリの既存ルール）。

## 6. 状態管理と保存

- 潜伏状態は戦闘コンテキスト内に、メンバーの永続 ID にひも付けて保持する。配列添字に固定しない。隊列変更（自動並び替えを含む）や他メンバーの死亡で、潜伏が他人へ移ったり消えたりしない。複数人の潜伏は独立に管理する。
- ログ再生と表示の同期：パーティー表示の「潜伏」タグは、戦闘ログの再生（displayVitals / displayCombat のスナップショット機構）と同期させる。コマンド入力中は、まだ実行されていない「隠れる」の結果（潜伏）を表示しない。
- 戦闘中セーブ・ロード：潜伏状態と予約済みコマンド・対象列が正しく復元される。保存・ロードで「隠れる」の成否を再抽選しない。
- 旧セーブ互換：潜伏情報が欠落したセーブは「誰も潜伏していない」として扱う。戦闘外のセーブ、無効な職業・ID の潜伏情報は復元しない。セーブキー `ash-v1` と既存の移行処理は維持する。JSON の書き出し・読み込みでも同じ扱いとする。
- 121との整合：未鑑定・呪いの装備の情報（本当の名前や性能）を、新しい UI やログから漏らさない。実際の装備武器の性能で攻撃する。呪いの拘束などの既存制約は変更しない。

## 7. UI・ログ

- 戦闘のコマンド選択に「隠れる」を追加（盗賊・忍者のみ）。潜伏中は「奇襲」を追加し、「隠れる」は出さない。対象列の選択 UI は既存のものを再利用し、奇襲の到達範囲を候補に反映する。対象が1列のときの自動選択は既存どおり。行動確認の表示には「奇襲（敵○列）」のように奇襲であることを示す。
- パーティー表示に「潜伏」タグを付ける（第6節の同期条件に従う）。
- ログ文の例（表示名はいずれも既存の表示規則に従う）：
  - 「○○は身を隠した。」
  - 「○○は身を隠せなかった。」
  - 奇襲の攻撃は既存の物理攻撃ログの形式に倣い、奇襲であることと2倍後のダメージが分かる形にする（例：「○○の奇襲！ △△に24ダメージ。」）。
  - 「△△に○○の潜伏が見破られた。」
  - 「○○の奇襲は届かなかった。」（射程内に届かず空振りの場合）
  - 奇襲の失敗扱いの場合は、失敗を伝えるログを出してから通常攻撃または空振りを処理する。
- 既存のキーボード操作・戻る操作・行動確認・モバイル表示を維持する。

## 8. スコープ外（今回は実装しない）

- 忍者の即死攻撃、素手の強化、裸 AC の成長。
- 防御による潜伏維持、敵の独立した発見確率、命中ボーナス、成功率の成長式。
- 図書館・指南書への説明追加。
- sim ハーネスの自動行動への「隠れる／奇襲」の組み込み（初期は従来どおりでよい）。

## 9. テスト・検証

試案セクション8の受け入れテストを、乱数を固定した決定論的なテストとして実装する。

- node テストに次を追加する（新規ファイルは `tests/game.cjs` の require リストへ登録）：
  (a) 「隠れる」を選べるのは盗賊・忍者だけ（前衛・後衛とも）。他職・戦闘外・行動不能では選べない。
  (b) 乱数固定で潜伏の成功・失敗を検証。成功したときだけ次ターンに「奇襲」が選べ、同ターンに攻撃しない。AGI 順で、隠れる前と後で敵の標的判定が変わる。味方先制・敵先制でも行動数が増えない。
  (c) 射程：後衛近接の奇襲が敵1・2列に届く、前衛近接の奇襲が敵3列に届く、弓は全列。通常攻撃の到達範囲が従来どおり維持される。
  (d) ダメージ：命中時に2倍、空振りで0、攻撃回数・旗倍率・毒などの追加効果・MP吸収が二重処理されない。
  (e) 潜伏中でも敵の呪文・ブレス・毒・状態異常を受ける。標的候補が全員潜伏でも敵の行動が止まらず、発見と解除が起きる。
  (f) 奇襲前の発見・行動不能・隊列変更・対象列の消滅・別コマンドの実行・奇襲失敗時の後衛近接の空振り（通常射程外）と通常攻撃への切替（通常射程内）。
  (g) 複数人の潜伏が独立すること。セーブ／JSON 入出力／旧セーブ（潜伏情報なし）／戦闘終了／逃走失敗／全滅で潜伏状態が適切に扱われること。
- ブラウザテストを1件追加し、コマンド選択に「隠れる」「奇襲」が出ること、潜伏タグの表示、後衛盗賊の奇襲の実行までを通す。
