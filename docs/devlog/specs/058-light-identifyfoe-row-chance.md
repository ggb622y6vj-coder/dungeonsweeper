# 058 [light] 「識別」を列指定・確率成功にする

## 背景
（origin/main eb7c9cb 時点）
- 識別（`identifyfoe`）は魔法使いの Lv1 で確定習得、MP3、戦闘専用です。対象は `'all'` で、`castMagic` の `identifyEnemies(true)` で**全部の列を必ず**識別し、「敵の正体を見破った。」と表示します。
- このほかに、毎ターン開始時と遭遇時に自動の識別があります（`identifyEnemies()`）。生存メンバーの最大IQ×3%で、列ごとに抽選されます。これは本作の既存仕様で、今回は変更しません。
- ユーザーの意見：「唱えた途端に全部の敵を識別できるのは強すぎる」。

依存：なし。059 より先に行います。

## 仕様
- 識別の対象を `'group'`（攻撃呪文と同じ「列を選ぶ」）に変更します。列の選び方・表示・キー操作は、カティノなど既存の `group` 呪文と共通の処理を使います。
- 成功判定は**選んだ列全体で1回**の抽選です。成功すると、その列の全個体が `identified=true` になります。【判断待ち：Q1 成功率の式】既定は「おすすめ」の案で実装します。
- 失敗した場合も MP は消費します（ほかの呪文と同じ）。ログは「{列の不確定名}の正体は見破れなかった。」です。成功時のログは「{不確定名}の正体を見破った。（→確定名）」とし、既存のログ色付けが効くようにします。
- すでに識別済みの列も選べます。その場合は判定せず、「すでに正体は判明している。」と表示して MP を消費します。【Q2 で変更の可能性あり】
- 呪文の説明文を「選択した列の敵の正体を確率で見破る」に変更し、SPELLS.md・docs も更新します。
- 「この呪文で識別した」という印（`e.identifiedBySpell=true`）を個体に付けます。059 がこれを使います。自動識別では付けません。
- 戦闘画面の表示（確定名・不確定名の切り替え）は、自動識別でも呪文でも今と同じです。

## OKの判定方法
1. ライブの 1280 と 390 の幅で確認：識別を選ぶと列の選択になり、選んだ列だけが識別されます。ほかの列は不確定名のままです。
2. `Math.random` を固定したテスト（tests/identifyfoe.cjs）で、成功時・失敗時のログ、MP の消費、`identified` と `identifiedBySpell` の付き方を確認します。
3. 自動識別（IQ×3%）が今までどおり動き、`identifiedBySpell` が付かないこと。
4. 戦闘中にセーブ・再読み込みしても、識別状態が保たれること。
5. 全テストが通ること：tests/*.cjs すべて、ブラウザテスト（実行しなかったものは明記）、`python3 scripts/compile-monsters.py --check`、scripts/sim/selftest.cjs。sim の数値が変わる場合は報告のみとし、NG扱いにはしません。
