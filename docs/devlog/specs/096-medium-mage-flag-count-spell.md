# 指示書 096：周囲の旗の数を探索者マスの左下に表示する魔法使い呪文

対象コード: origin/main `d24d574`（095 live verification まで取り込み済み。hold/073〜095 はすべて main にマージ済みで、未マージの Muse 作業はない）。
Notion 呪文DB・本体リポジトリへの書き込みは、この指示書ドラフトの段階では行わない（ユーザー確認後）。

## ユーザーの要望（原文）

> 周囲8マスに存在する旗の数を探索者の境界の左下に表示するようにする魔法使いの呪文を実装してください。MPは5、町に戻るまで続く、習得レベル5、習得確率を設定します

## 背景（現行コードの事実）

### 旗
- 各マス `s.cells[i].flag` は `false`、または旗種文字列（`power` / `guard` / `magic`）。`flag(i)` / 旗モード移動で、**未探索マスにだけ**立て外しできる（探索済みには立てられない）。
- `around(i)`（dist/game.js 先頭）は自分を除く周囲最大8マス。`num(i)` は周囲の**罠**数で、旗数ではない。
- 旗関連の既存呪文（079/083 由来）: 生贄の旗・壊滅の旗・減退の旗・大減退の旗・一掃 は「周囲の旗＋その下の罠を消費して効果」であり、持続表示ではない。

### 探索者マスの描画
- 現在地セルは `class="cell here"`（金色アウトライン＝境界）＋中央の `.cell-number` に `num(s.pos)`（周囲の罠数）＋背面に向きの `.direction-marker` SVG。
- CSS に `.cell em { right:2px; bottom:1px }` が残っているが、現行の board HTML では `<em>` は使っていない。**左下は空いている**。
- `#board` は `render()` のたびに作り直す。旗の立て外しも `render()` するので、描画時に数えれば自動で追従する。

### 魔法使いの呪文定義
- 正本は `dist/spells.js` の `MAGIC`（id, 名前, job, level, mp, guaranteed, where, target, effect, value, description）。
- 習得: `guaranteed===true` なら確定。`false` なら魔法使いは `intelligence/30`、僧侶は `piety/30`（`learnMagic`）。ユーザー文言の「習得確率を設定します」は、確定ではなくこの抽選に載せる、という意味と読むのが自然（→質問2）。
- 探索専用は `where:'field'`。戦闘中は `spellReason` が「探索専用」で拒否する（例: 判別・警戒結界）。`both` は戦闘でも使える（例: 鉄壁・誘惑）。
- 表示名は日本語が多い。魔法使いの探索呪文の例: 判別(dumapic)、再抽選(reload)、誘惑(tempt)、転移(malor)。旗系は「〇〇の旗」。ID はラテン／英語のままが多い。

### 町まで続く持続効果（091 で整理済み）
| 状態 | 置き場 | 解除 | 重複唱和 |
|---|---|---|---|
| 透視（大） | `s.light` | `enterTown`（全滅後の町帰還含む） | `spellReason` →「発動中」 |
| 警戒結界 | `s.watchful` | 同上 | 同上 |
| 鉄壁 | `s.teppeki` | 同上 | 同上 |
- 透視（短）だけ `s.milwaSteps` で歩数制。階移動で `travelFloor` が `milwaSteps=0` にするが、`light` / `watchful` / `teppeki` は階を跨いでも残る。
- `activeSpellEffects()` がパーティ画面の「発動中の呪文」に出す。新持続効果もここに足す。
- `fresh(floor)` の profile 引き回しと `ensureProfile()` の `??=` に新フラグを足さないと、階生成や旧セーブで消える。

## 仕様（回答待ちの箇所は「質問」の推奨で仮置き）

### 1. 新呪文を MAGIC に追加する
- 系統: 魔法使い（job 1）
- 習得Lv: 5
- MP: 5
- 確定習得: なし（`guaranteed:false` → 知力/30）※質問2
- 使用場面: 探索（`where:'field'`）※質問6
- 対象: 味方全員（`target:'party'`、実態はパーティー状態）
- 効果種別: 新規（例: `flagcount`）。Notion の select にも後で同じ値を足す。
- 数値: 空
- id / 表示名: 質問1で決定（仮: id `mapis`、名前「マピス」）
- 説明文の骨子: 「町へ戻るまで、探索者マスの境界左下に周囲8マスの旗の数を表示する。」

### 2. 持続状態
- `s.flagSight`（仮名。boolean）。唱えたら `true`。`enterTown` で `false`（全滅からの町帰還と同じ経路）。
- 階移動では消さない（鉄壁・警戒結界と同じ）。
- `ensureProfile` で `s.flagSight??=false`。`fresh` の profile にも載せる。
- `spellReason`: 発動中なら「発動中」で拒否（091 と同じ）。
- `activeSpellEffects`: `{name:表示名, description:'周囲8マスの旗の数を探索者マスの左下に表示する', remaining:'町へ戻るまで'}` を追加。

### 3. 旗の数え方と表示
- 数: `around(s.pos).filter(j => !!s.cells[j].flag).length`（現在地は含まない。旗種は問わない。プレイヤーが立てた旗のみで、コード上それ以外の旗はない）。
- 表示: 現在地セル（`.cell.here`）の**境界の左下**に、中央の罠数（`.cell-number`）と重ならない小さな数字。例: `<span class="flag-sight-count">N</span>` を absolute で `left:2px; bottom:1px; font-size:9px`（既存の右下 `em` ルールと対称）。地図ダイアログの同一ボードにも出る。
- 0 のときも「0」を出す（発動中だと分かる。非発動時は要素自体なし）※質問7
- 旗の立て外し・移動のたびに `render()` 経由で更新（別タイマーは不要）。

### 4. 詠唱ログ
- 既存どおり「〇〇は〔名前〕を唱えた。」に続けて、短い効果ログ（例:「周囲の旗が見えるようになった。」）。

### 5. セーブ・全滅
- `s.flagSight` は通常セーブに含まれる（`s` 全体を書く現行方式）。
- 全滅（`defeat`）では即解除しない。町に戻った `enterTown` で他の持続効果と一緒に消す（鉄壁と同じ）。

- `SPELLS.md`、必要なら `docs/SPECIFICATION.md` / `docs/DATA_CATALOG.md`

## OKの判定方法
- ロジック（新規 `tests/flag-sight.cjs` など）:
  - 未習得→知力/30 で習得しうる。Lv5 未満では出ない。
  - 詠唱で MP−5、`s.flagSight===true`。再詠唱は「発動中」。
  - 周囲0〜8でカウントが合う（現在地に旗が立てられないことも確認）。
  - 旗を立て外すと次の render で数が変わる。
  - 階移動後も `flagSight` が残る。`enterTown` 後は消える。
  - 戦闘中は唱えない（探索専用）。
- ブラウザ（1280 と 390）:
  - 発動中、現在地セル左下に数字が見え、中央の罠数・向きマーカーと重ならない。
  - 地図ダイアログでも同じ。
  - 「発動中の呪文」に本効果が載る。ボタンは効果なしのとき隠れたまま。
  - スクリーンショットで目視。
- 既存テストすべて通過。

## 質問（ユーザー決定が必要）

1. **呪文の名前（表示名）と id は？**
   - A: マピス / `mapis`（Wizardry 風カタカナ。地図・感知の語感）
   - B: ラトマピ / `latumapi`（ラト系の接頭＋マピ）
   - C: 旗視 / `flagview`（既存の旗呪文と同じ日本語方針）
   - D: 察旗 / `flagcount`
   - **おすすめ: A（マピス / mapis）**。探索系の判別・透視と並ぶカタカナ短名で、旗消費系の「〇〇の旗」とも区別しやすい。

2. **「習得確率を設定します」の意味は？**
   - A: 確定習得にしない（`guaranteed:false`）。魔法使いの通常どおり知力÷30
   - B: 固定％（例: 常に 50%）を特別実装する
   - C: 確定習得（`guaranteed:true`）
   - **おすすめ: A**。既存の非確定呪文と同じで、特別な百分率ロジックを増やさない。同 Lv 帯の大火炎・誘惑も非確定。

3. **数える旗の範囲は？**
   - A: 周囲8マスのプレイヤー旗のみ（現在地除外。現行 `around` どおり）
   - B: 周囲8＋現在地（現在地には旗を立てられないので A と同じ結果）
   - C: 未探索マスの旗だけ数える（探索済みに旗は無いので A と同じ）
   - **おすすめ: A**（明示的に周囲8・現在地除外と仕様に書く）

4. **旗を立て外したとき、表示はすぐ変わる？**
   - A: すぐ変わる（render 時に再計算）
   - B: 詠唱時点の数を固定
   - **おすすめ: A**（マインスイーパー補助として自然。実装も単純）

5. **再詠唱は？**
   - A: 発動中は唱えない（091 の透視・警戒・鉄壁と同じ「発動中」）
   - B: 再詠唱可（MP だけ再消費、効果は延長というより現状維持）
   - **おすすめ: A**

6. **戦闘中に使える？**
   - A: 探索専用（`field`）
   - B: 戦闘でも可（`both`）。戦闘中は地図が隠れるので数字は見えないが、戦闘後に残る
   - **おすすめ: A**。地図表示が本体の効果なので探索専用が素直。

7. **周囲の旗が0のとき？**
   - A: 「0」を左下に出す
   - B: 数字は出さず、発動中の呪文ウィンドウだけで分かるようにする
   - **おすすめ: A**（効いているかどうかがマス上で一目で分かる）
