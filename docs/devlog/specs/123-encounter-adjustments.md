# 指示書123：反呪文の結界の説明文、探索済みマスのエンカウント率、撃破後の守護者の通常エンカウント追加

対象は次の3件。いずれもオーナー決定済み。関係しない挙動は変更しない。

## 1. 反呪文の結界の説明文を変更

- 対象：`dist/spells.js` の `activeSpellEffects()` が反呪文の結界について返す項目。
- 現在：`{name:'反呪文の結界', description:'この範囲では呪文が打ち消され、発動中の魔法も解除される', remaining:'このマスにいる間'}`
- 変更後：`description` を `'全ての呪文が打ち消された！'` にし、`remaining` は空文字 `''` にする。`name` は `'反呪文の結界'` のまま。
- 表示側（`renderActiveSpells`）は変更しない。
- 呪文が打ち消されたときのログ「反呪文の結界に打ち消された！」は別の文であり、変更しない。結界の挙動（打ち消し・持続魔法の解除・枠表示）も変更しない。

## 2. 探索済みマスのエンカウント率を下げる

- 対象：`dist/game.js` の `encounterRate(i, wasOpen, action)`。
- 現在：探索済み（wasOpen）は `.10 + num(i) * .005`、未探索は `.16`、横移動（strafeLeft / strafeRight）は `+.01`。
- 変更：探索済みの基礎値だけを `.10` → `.095` にする。未探索の `.16`、周囲の罠数による加算 `num(i) * .005`、横移動の `+.01` は変更しない。
- 変更後の値：探索済み・罠0個で `.095`、罠2個で `.105`、横移動（罠0個）で `.105`。

## 3. 倒した守護者をその階の通常エンカウントに追加

- 対象：`dist/monsters.js` の `monsterFormation(boss)` の通常戦闘（boss=false）経路のみ。守護者戦（boss=true）の編成は変更しない。
- 出現条件：その階の守護者を倒した後であること。判定は「`s.guardiansDefeated` に現在の階が含まれる」ことのみ（全階で統一）。`guardianKilledThisRun` は出現条件に使わない（帰還時の文言・秘宝表示専用のまま）。
- 記録の変更（オーナー決定・案A）：`dist/monsters.js` の `finishMonsterBattle` の守護者勝利分岐で、現在は最下層未満の階だけが `guardiansDefeated` に記録されるが、最下層を含む全階を記録するよう変更する（push の `s.floor<MAX_FLOOR` ガードを外す）。最下層のクリア分岐（ボスマスを空にする、`s.cleared=true` 等）と最下層未満の分岐（ボスマスを下り階段にする等）は変更しない。階段・秘宝・階層移動の各処理は「最下層未満」の条件で守られているため、10が記録されてもそれらの挙動は変わらないことをテストで確認する。
- 経緯：当初案の `guardianKilledThisRun` 併用は、古いセーブの階スナップショットに同項目が無い場合に階復元で前階の値が漏れ、未撃破の最下層守護者が出現条件を満たす欠陥が着手前確認で判明したため、オーナーが案A（記録の統一）を選択した。
- 編成方法：通常プール（その階の非ボス敵）にその階の守護者を1種加えたプールから、従来どおり1〜3グループを抽選する。守護者のグループが2つ以上抽選された場合は最初の1つだけを残し、余りは通常プールの敵に置き換える（1戦闘に守護者は最大1グループ。各守護者の集団数は [1,1] で1体）。
- 戦闘の扱いは通常戦闘のまま：`encounter()` が決める `s.enemy.boss` はマスの種別由来であり、通常マスでの守護者戦闘は boss=false（逃走可・先制／奇襲あり）。`encounter()` 自体は変更しない。
- 撃破時の扱いも通常戦闘のまま：秘宝・階段・`guardiansDefeated` への再記録などの守護者戦専用の処理は走らない（`finishMonsterBattle` の守護者分岐は combat.boss 前提のため自動的に不発。テストで確認する）。経験値・金・宝箱は通常どおり。守護者のグループが編成の先頭なら、宝箱は守護者の宝物グループから出る（既存の `lootMonsterId = formation[0]` の仕組みそのまま）。
- 守護者本人の逃走は、敵データの boss フラグにより従来どおり発生しない（変更しない）。
- セーブ形式・敵データ（monsters.csv）は変更しない。

## テスト・検証

- node テストに次を追加・更新する（既存の期待値が旧仕様を固定している場合は、新仕様への追従として更新し、検証の強さは落とさない）：
  (a) 反呪文の結界の効果項目が `{name:'反呪文の結界', description:'全ての呪文が打ち消された！', remaining:''}` であること。
  (b) `encounterRate` の新値：探索済み・罠0個で .095、罠2個で .105、未探索は .16 のまま、横移動の加算が残ること。
  (c) `monsterFormation(false)`：撃破前は守護者が決して出ないこと、撃破後は守護者が出現しうること（Math.random を固定した決定論的な検証）、守護者が2グループ以上にならないこと、守護者戦（boss=true）の編成が不変であること、別階の守護者撃破では出現しないこと。あわせて、最下層の守護者を倒すと `guardiansDefeated` に最下層が記録され、その記録で最下層でも守護者が出現すること、および最下層のクリア処理（ボスマス・`s.cleared`）が従来どおりであること。
  (d) 通常マスで守護者を含むエンカウントが boss=false として始まり、逃走率が0でないこと。また、その戦闘に勝利しても秘宝・階段・撃破記録の状態が変わらないこと。
