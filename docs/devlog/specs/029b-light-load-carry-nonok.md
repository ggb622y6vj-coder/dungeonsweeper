# 029b light: 町でロードした時、パーティ内の死亡/灰/ロストを寺院へ自動搬送

## 共通ルール
- 既存テストを弱めない。dist と MANIFEST を更新し、全テストを通してから push。

## 目的
029 以前の旧セーブでは、町でパーティに死亡者が残ったままになる。この状態で酒場を開くと、ok メンバー同士の入れ替えでも「死亡したメンバーは加入できません。」と拒否され、案内が分かりにくい。

## 変更内容
- ロード時に s.area==='town' で、パーティに status!=='ok' のメンバーがいれば、029 と同じ removeFromParty を使って控えへ移す。s.templeReport を設定し、#templecarrydialog で知らせる（レベル報告は出さない）。そのあと保存する。
- 迷宮内のロードは対象外（従来通り）。
- 酒場では、既に在籍している非ok者が残っている場合の文言を「死亡したメンバーを外してください。」に分ける（保険）。

## OKの判定方法
- 町で非okが在籍している旧セーブをリロードすると、搬送ダイアログが出る。パーティ配列は整合し、該当者は控え/寺院に入り、酒場の保存・迷宮入場が通る (1280/390)。
- 非okなしのロードと迷宮内のロードではダイアログが出ない。
- tests に旧セーブのケースを追加し、全テスト PASS、JSエラー無し。
