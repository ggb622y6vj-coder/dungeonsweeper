# 指示書147: 昇降機の階層選択ダイアログに画像を表示する

日付: 2026-11-26
担当: Codex（gpt-6.2-sol・low）

## 背景

オーナー提供の昇降機のドット絵（48×48・4色・透過背景）を、昇降機の階層選択ウィンドウに表示する。大きな原画（1254×1254）もあったが、軽さ（1.3KB）と画風の統一から48×48版をオーナーが選んだ。

画像は `dist/assets/elevator.png` に配置済み（この仕様書と同じコミット）。バイト単位でそのまま使うこと。

## 変更内容

- 階層選択ダイアログ `#elevatorpick`（dist/index.html）の中、見出しの下・階層ボタン（`#elevatorchoices`）の上に、昇降機の画像を1枚表示する。
- 表示サイズは幅240px（48の5倍。ドットが崩れない整数倍）を基本とし、ダイアログより狭い画面では `max-width:100%` で収める。中央寄せ。`image-rendering:pixelated` でドット絵のまま拡大する。
- CSSは既存の運用に合わせる（1行1規則、色は必要なら :root トークン）。
- alt は装飾として空にするか、「昇降機」など短い代替テキストにする（周囲に見出し「昇降機」があるため空 alt が妥当）。

## 変えないこと

- 解放通知のダイアログ（`#elevatordialog`、OKボタンだけの方）には画像を入れない。
- 階層ボタンの内容・並び・動作、昇降機の解放や移動のロジック。
- ゲームのデータ、セーブ形式。

## テスト

- tests/elevator-browser.py に、階層選択ダイアログを開いたときに画像が表示され、読み込みが成功している（naturalWidth が48）ことと、画像が階層ボタンより上にあることの検証を追加する。検証の強さは落とさない。
- tests/css-structure.cjs など構造を固定するテストが新しいCSS規則で失敗する場合は、その固定内容を新しい形に合わせて更新する。
- `node tests/game.cjs` を実行し全 PASS を確認する。
