## 目的
宝箱の装備品が「パーティの誰も装備できない品」だったときも「アイテムがいっぱいで装備品を持ち帰れなかった。」と表示され、原因が誤って伝わるバグを直す（例：全員戦士で盗賊専用の dagger が出た）。

## 変更内容
- dist/game.js `rewardChest(c)`：受け取り手が見つからなかった場合を2つに分ける。
  - 装備できる職業のメンバーがいない → 「${w.name}を見つけたが、誰も扱えないので置いていった。」
  - 装備できるメンバーはいるが全員の所持が10個で満杯 → 従来の「アイテムがいっぱいで装備品を持ち帰れなかった。」（品名を入れて「${w.name}を見つけたが、持ち物がいっぱいで持ち帰れなかった。」でも可）
- 抽選・受け取り手の選び方・確率は変えない。

## OKの判定方法
1. テスト：`node tests/game.cjs && node tests/training.cjs && python3 scripts/compile-monsters.py --check` が全PASS。
- 回帰テスト：乱数を固定し、(a) 全員戦士＋盗賊専用品 → 「誰も扱えない」ログ1回、所持品変化なし。(b) 装備可能者の所持が満杯 → 「持ち帰れなかった」ログ1回。(c) 通常 → 従来どおり入手ログ。
- 手動：不要（ログ文言のみ）。
