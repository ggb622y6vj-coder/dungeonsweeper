# 指示書078：マス数が多い階で地図のアイコン（数字・記号）が下にずれる不具合の修正

- 種別：バグ修正（light）
- 対象バージョン（基準 main）：0a92c29（077 統合・検証記録済み）
- 作業ブランチ：`hold/078`

## ユーザーの要望（原文）

> 3Fでマス数が多くなると、地図のアイコンがずれていますので直してもらえますか
> （実機スクリーンショット添付：iPhone Safari、3F の地図ダイアログ。数字・旗などのアイコンが各マスの下寄りに表示されている）

## 再現と原因（実施者が実測）

- ローカル Chromium（390px幅）で再現した。地図ダイアログで、マスの中の `.cell-number`（数字・記号・旗・絵文字を含む span）の中心とマス中心の縦ずれを測ると：
  - 1F（8×8、マス高さ約36px）：平均 +2.6px（下ずれ）
  - 3F（12×12、マス高さ約23px）：平均 +6.2px、最大 +10.2px（マス高さの約4割）
- マスが小さいほどずれが大きくなるため、深い階・モバイル幅で目立つ。デスクトップ幅ではマスが大きく、ずれが小さいため目立たなかった。
- 仕組み：`.cell`（button）は中身を通常フローで配置しており、行ボックス（line-height）とボタンの内容配置に任せているため、マス高さが行ボックスより小さくなると文字が下へはみ出して見える。

## 修正方針

- マスの中身を明示的に中央へ配置する。例：`.cell` をフレックスコンテナにして（`display:flex; align-items:center; justify-content:center`）、`.cell-number` の行高を詰める（`line-height:1`）。現在の方向マーカー（`.direction-marker`、絶対配置）の見え方は変えない。
- 対象は盤面のマス表示のみ。フォントサイズ、色、テーマ（077 の帯別上書きを含む）、マスの大きさや間隔は変更しない。
- 地図ダイアログでもドック表示（PC幅）でも、全ての階（8×8〜12×12）でアイコンがマスの中央に来ること。

## 非変更範囲

- ゲームの仕様・バランス・データ、セーブ形式（キー `ash-v1`）。
- マスの色やハイライト（現在地・視界内・ボス等）の意味づけ。

## 検証（実装後に実施者が行う）

- 回帰テストを追加する：ブラウザテストで 12×12（3F相当）・390px幅の地図ダイアログと 8×8 を開き、数字のあるマスについて `.cell-number` の中心とマス中心の縦・横ずれが許容範囲（目安として ±2px 以内）に収まることを確認する。
- 既存テスト全種：`tests/*.cjs`、`tests/*-browser.py`、`scripts/compile-monsters.py --check`、シミュレーション自己テスト、`MANIFEST.sha256` 照合。
- 画面確認：3F・390px幅の地図ダイアログと、PC幅のドック地図で、数字・旗・現在地マーカーが中央に表示されることをスクリーンショットで確認する。戦闘中・ボスマス等の表示が崩れていないことも見る。
