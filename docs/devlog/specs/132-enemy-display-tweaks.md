# 指示書132：敵表示の微調整（列ラベルの短縮とアイコンの左右配置）

- 日付：2026-11-23
- 基準 main：6c0ee50（指示書131 統合・ライブ検証記録まで完了）

- 発端：ユーザーの2点の依頼（2026-11-23）。(1) 左上の列表示の「1列：」を「1：」にする。(2) 戦闘中のアイコンは、1列目を左・2列目を右に出す。敵が1列だけのときは真ん中に出す。
- 番号の付け替え：随伴表の全面設計は本指示書の次（133）へ回す。

## 1. 列ラベルの短縮（dist/game.js の sceneEnemyRow）

- 各列の表示を「○：名前 ×総数（行動可能数）」の形式にする（現行の「○列：…」から「列」の字を除く）。例：「1：ゴブリン ×3(2)」。
- 総数・行動可能数の定義と数え方は131のまま変更しない。

## 2. アイコンの左右配置（dist/game.js の drawEnemies）

- 描くアイコンが2つのとき（表示列が2列あるとき）：2つを同じ高さに横並びにする。1列目のアイコンは左（中心 x=160）、2列目のアイコンは右（中心 x=480）。y と大きさは現行の1段目と同じ（y=62、幅108、高さは現行の height−9）。
- 描くアイコンが1つのとき（表示列が1列だけのとき）：現行どおり中央（中心 x=320）に置く。
- アイコン内の絵文字と Zzz のテキストは、各アイコンの中心に合わせる。
- 代表個体の選び方（各列の表示対象の先頭1体）、data-enemy-uid、visibleCombat のスナップショット基準は131のまま変更しない。縦に積む現行レイアウト（2つ目を y=192 に置く）は廃止する。

## 3. テストの追従

- tests/enemy-display-browser.py：列表示の期待文字列を新形式（「1：…」）へ、アイコンの矩形の期待を新しい配置（2つは [106, 62, 108, 121] と [426, 62, 108, 121]、1つは [266, 62, 108, 121]）へ書き換える。検証項目そのもの（代表UID、Zzz、総数と行動可能数、先頭列消滅時の繰り上がり、PC幅・スマートフォン幅）は変えない。
- 「列：」の表記や旧配置に依存する他のテストがあれば、同様に追従する（.scene-enemies の文言を緩く確認しているだけのテストは対象外）。

## 4. 対象外
