# 059 [light] 図書館のモンスター情報は「識別」の呪文で識別したものだけ開示する

## 背景
（origin/main eb7c9cb 時点）
- 図書館のモンスタータブ（dist/library.js `renderLibrary`）は、`s.library.monsters[id].count>0`（1体でも倒した）なら確定名と詳細をすべて表示し、それ以外は「？？？」と表示します。
- 記録は `recordLibraryVictory` が戦闘後に `{count, firstFloor}` を加算します。データはセーブ `ash-v1` の `s.library` に入ります。
- ユーザーの要望：「識別」の呪文で識別したモンスターだけ確定名と情報を開示する。戦闘中の自動識別で確定名に変わっただけのものは、不確定名だけを表示する。

依存：058（`identifiedBySpell` を使うため）。

## 仕様
- 記録に `identified: true` を追加します。058 の呪文識別が成功した時点で、その列のモンスター種別に付けます（倒したかどうかは関係ありません）。記録がまだなければ `{count:0, identified:true}` を作ります。
- 「遭遇した」記録も追加します（`seen:true`。遭遇時に付けます）。
- 図書館の表示は3段階にします。
  - 識別済み → 確定名と全情報（060 の項目）
  - 遭遇・撃破したが未識別 → **不確定名**だけ。ほかの項目は【Q5】の答えに従います（既定：不確定名と撃破数のみ）。
  - 未遭遇 → 「？？？」
- 自動識別（IQ×3%）や撃破では `identified` は付きません。
- 不確定名は複数の種別で同じになることがあります（例：「悪魔」が3種）。未識別の項目は種別ごとに別の行として、出現階の見出しの下に並べます（同じ名前の行が並ぶことを許します）。
- 既存セーブの移行：【Q6】既定は「`count>0` の既存記録は識別済みとして引き継ぐ」です。`s.library.monsterIdentifyVersion=1` を付けて、移行は1回だけ行います。`ash-v1` の読み込みは壊さないようにします。

## OKの判定方法
1. ライブの 1280 と 390 の幅で確認：自動識別だけで倒したモンスターは、図書館で不確定名だけが表示されます。呪文で識別した後は、確定名と情報が表示されます。
2. 呪文で識別して逃げた（倒していない）場合も、確定名が開示されます（撃破数 0）。
3. 未遭遇のモンスターは「？？？」のままです。
4. セーブ・ロード：識別の記録が再読み込み後も残ること。移行前の古いセーブ（`count` だけ）は、Q6 の方針どおりに表示され、エラーが出ないこと。
5. テストを追加します（tests/library-identify.cjs）：識別・撃破・移行の各パターン。
6. 全テストが通ること：tests/*.cjs すべて、ブラウザテスト（実行しなかったものは明記）、compile --check、selftest。

## Amendment（ユーザー決定 2026-11-03）
ユーザー原文：「９つともおすすめの通りにお願いします。不確定名は確定名のサブテキストのような形で表示し、「確定名」とか「不確定名」などのラベルはつけなくていいです。」
- Q1〜Q9はすべて「おすすめ」(A)で確定。
- 図書館：識別済みモンスターは確定名を見出しにし、不確定名はその下に小さめのサブテキストで表示する。「確定名」「不確定名」のラベルは付けない。未識別のモンスターは不確定名のみ表示する（ラベルなし）。
