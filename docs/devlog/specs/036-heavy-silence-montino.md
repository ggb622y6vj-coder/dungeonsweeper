## 目的
Wizardry の MONTINO に倣い、呪文を封じる状態異常「沈黙」と呪文「モンティノ」を敵味方双方に実装する。

## 変更内容
### 状態
- `ailments[i].silence`（残りターン数）。かかると **3**。戦闘ターン終了ごとに −1、0で「〇〇の沈黙が解けた。」。**戦闘終了時に全員0**（Wizardry同様、戦闘中だけの異常）。重ね掛けは3に戻すだけ。
- 効果: 呪文選択不可（spellReason が「沈黙している」を返す。コマンドの「呪文」はグレーアウト）。攻撃・防御・アイテムは可。
- 自然回復以外の治療: **ディアルコ**（説明文を「麻痺・睡眠・沈黙を治す」に）、**マディ**、**気付け薬**（ディアルコ相当なので新アイテムは作らない。価格・宝箱表は変更なし）。沈黙中の本人は呪文で自分を治せない。
- 032 自動並び替え: **対象外**（partyIncapacitated に含めない）。理由: 攻撃・防御ができ前衛の役目は果たせる。Wizardry でも沈黙で隊列は変わらない。
- 帰還（enterTown）: freshAilments で解除。寺院対象にしない。
### 味方の呪文
- MAGIC に追加: id `montino`、名前 モンティノ、**僧侶(job 2) Lv3、MP 4**、戦闘中のみ、対象=敵1グループ。Wizardry では僧侶2レベル→本作の僧侶Lv3帯（マツ・カルフォと同帯）。
- 成功率はカティノと同式: 各個体 `clamp(49+5*(術者Lv−敵Lv), 0, 94)`%。ボス・守護者には無効。
- 敵側: `e.silence=true`（戦闘終了まで）。沈黙中の敵は行動抽選で「呪文」が当たったら通常攻撃に置き換える（ブレス・召喚・逃走は影響なし）。
### 敵の呪文
- monster-data の spellInfo に `effect`（'damage'|'silence'）を追加。silence は対象=全体、各生存メンバーに `clamp(50+5*(敵Lv−メンバーLv), 5, 94)`%。ログ「〇〇はモンティノを唱えた。」「〇〇は沈黙した。」/「〇〇には効かなかった。」
- 使用モンスター（CSV 呪文列を変更）:
  - 闇の司祭 4F: `ハリト/単体/40%` → `モンティノ/全体/30%`
  - 魔女 8F: `ダルト/全体/25%` → `モンティノ/全体/25%`
  - （僧侶系の敵だけに絞り、低層の負担を抑える。他の術者は変更なし）
- compile-monsters.py: MONSTER_SPELLS に `'モンティノ':('montino','全体',None,'silence')`。既存の flee+summon+spell+breath≤1 チェックは維持。
### 表示・図鑑・sim
- 状態タグ: visibleAilments に `[a.silence>0,'silence','沈黙']`、CSS `.ailment-silence`。
- 図鑑: 呪文欄に「モンティノ（沈黙・全体 30%）」と表示。呪文一覧にモンティノ。
- sim (scripts/sim): 沈黙メンバーは呪文方針をスキップし攻撃。僧侶AIは 敵に術者グループ（spellInfo持ち）が2体以上いれば montino を検討。敵のモンティノを harness で再現。

## OKの判定方法
1. node: 闇の司祭のモンティノ 10000回試行で、Lv同等メンバーへの命中率が 50%±2%。沈黙中は spellReason が非空、攻撃は可能。
2. silence=3 → 3ターン後に0。戦闘終了で0。帰還で0。ディアルコ・マディ・気付け薬で0。
3. 味方モンティノ: 敵Lv=術者Lvで約49%、ボスに0%。沈黙した敵は戦闘中に一度も呪文を唱えない（10000回）。
4. 沈黙メンバーは自動並び替えで動かない（032 のテスト継続PASS）。
5. compile-monsters --check PASS、図鑑・状態タグ表示をブラウザ（1280/390）で確認。tests/silence.cjs と silence-browser.py を新規追加。
