# 041 [heavy] 戦闘・確認・各種ダイアログのキーボード操作

## 共通ルール
- 作業ツリーは担当者自身のもの。push はオーナー指示があるまでしない。既存テストのチェックは削除・緩和しない。
- タッチ／マウス操作と 390px レイアウトを壊さない（既存ブラウザテスト全件PASS）。
- テキスト入力（#recruitname など INPUT/TEXTAREA/SELECT）にフォーカスがある間は、Esc 以外のキーをゲームが奪わない。
- Ctrl/Alt/Meta 付きのキーは無視する（ブラウザのショートカットを妨げない）。
- 完了条件: node tests 全件・compile-monsters --check・selftest・ブラウザテスト全件（1280/390）PASS、JSエラーなし。新規テストはキーボードだけで操作する Playwright（page.keyboard のみ、click・evaluate での直接操作は禁止。evaluate は状態の確認だけに使う）。
- 038 完了後に着手（040 と独立）。

## 目的
戦闘と、迷宮で出るすべての確認・報告をキーだけで操作できるようにする。

## 変更内容
- 戦闘コマンド欄（#commandentry）:
  - 戦う・呪文・防御・アイテム・解呪・逃げるの間を W/A/S/D で移動し、Space で決定。
  - disabled（恐怖で戦えない、沈黙で呪文不可 等）にはフォーカスできるが決定は無効。理由はキーヒント欄に表示する。
  - Esc は既存の「戻る」（data-command-back）。前のメンバー、または呪文・列の選択の取り消し。
  - 「この行動で戦う」が既定。
- 列の選択（data-row-choice）、呪文の一覧（magicdialog）、アイテムの一覧（medicinedialog）: リストとして W/S、2列なら A/D でも移動、Space で決定。
- 味方の対象選択（027c の対象バー、allyTargetPick）:
  - パーティ欄の6人を、表示どおりの 2×3 または 3×2 の並びで W/A/S/D 移動する。
  - 選べないメンバー（死亡・石化 等）は飛ばす。Space で決定、Esc で取り消し（今の Esc 処理を 038 に統合）。
  - 探索中の対象選択（#allytargetfieldcancel）も同じ動き。
- はい／いいえ（ボス #bossyes/#bossno、階段、宝箱の開ける・調べる・カルフォ・放棄）:
  - A/D（または W/S）で移動、Space で決定。
  - 既定: ボスは「いいえ」、階段は「はい」、宝箱は「調べる（盗賊）」があればそれ、なければ「開ける」。
  - Esc = 「いいえ」。宝箱では「放棄」ではなく何もしない（誤って放棄しないため）。
- 報告ダイアログ（レベルアップ #leveldialog、寺院運び込み #templecarrydialog、クリア）: Space／Enter／Esc で閉じる。
- ステータス・持ち物（statsdialog／inventorydialog）: メンバーカードを W/A/S/D で移動し、装備変更などのボタンも Space で押せる。
- 戦闘ログ再生中（logBusy）は決定を受け付けない（今のクリック動作と同じ）。

## OKの判定方法
Playwright（tests/battle-keys-browser.py、1280）。キーだけで以下ができること。
1. 6人全員に戦う・呪文（列対象のモンティノ、味方対象のディオスを 2×3 の対象バーで選ぶ）・防御・アイテム（傷薬を味方に）を入力して1ターン進める。
   - Esc で1人前に戻り、別のコマンドに入れ直せる。
2. 恐怖中のメンバーで「戦う」にフォーカスして Space → 何も起きず、ヒントに理由が出る。
3. ボス確認で Space（既定いいえ）→ 戦わない。D→Space → 戦闘開始。階段で Space → 移動。宝箱で Esc → 何も起きない。
4. 戦闘に勝ってレベルアップ → Space でレベル報告を閉じる。全滅しかけて帰還 → 運び込み報告を Esc で閉じる。
5. 対象選択で、死亡や石化のメンバーにはフォーカスが止まらない。
6. 390 のタッチ戦闘テスト（target-select-browser 等）は今までどおりPASS。
