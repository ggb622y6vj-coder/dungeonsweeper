## 1. ログウィンドウ

ユーザーの要望: 「ログの部分をタップするとログだけが載っているウィンドウが立ち上がり、
ウィンドウ以外の部分をタップすると閉じる」。

### 仕様
- 迷宮画面のログ表示部分（#log）をクリック／タップすると、ログ専用のダイアログ
  （例: `<dialog id="logdialog">`）が開く。他のダイアログと同じ流儀で、
  見出し（「ログ」）と × ボタン（data-key-back 等、既存の作法に合わせる）を持つ。
- ダイアログの中身は #log と同じログ行を表示する。開いた時点の内容を写すだけでなく、
  開いている間に #log へ行が増えたらダイアログ側にも同じ行が表示されること
  （同期の仕組みは実装側で選んでよいが、二重管理で内容が食い違わないこと）。
- 開いたときは最新の行が見える位置（末尾）までスクロールする。ダイアログ側は
  #log より縦に大きく取り、スクロール可能にする。
- 閉じ方: × ボタン、Esc（dialog の標準動作）、そしてダイアログの外側
  （背景部分）のクリック／タップで閉じる。背景クリックで閉じるのは
  このダイアログの要件なので、クリック位置がダイアログ自身（背景）である
  場合にだけ閉じること。
- 戦闘中・ログ再生中でも開いてよい（閲覧専用で、ゲームの状態は変えない）。
- #log にはクリック可能であることが分かる見た目（cursor:pointer）を与える。
  キーボード操作の既存の仕組み（data-key-* 属性によるキー割り当て）と
  衝突しないこと。
- ログの内容そのもの、ログの再生・表示ロジック（logQueue、visibleCombat 等）は
  変更しない。セーブ形式も変更しない。

## 2. 「前衛・後衛」ラベルの削除と間隔の調整

ユーザーの要望: 「探索中のステータス画面に小さく左に『前衛・後衛』って書いて
ありますが削除してください。その分、十字キーとステータス画面を少しだけ
離してください」。

### 仕様
- 対象は迷宮メイン画面のパーティー表示（#party）の中で各3人の先頭に出る
  区切りラベル `<div class="party-rank">前衛／後衛</div>`（dist/game.js の
  render() 内）。この出力を削除する。
- CSS の .party-rank 規則（dist/index.html:203）と、フォントサイズの
  グループ規則（同:399）に含まれる .party-rank セレクタも取り除く。
  tests/css-structure.cjs の固定（規則数など）は実態に合わせて追従させる。
- 対象外（変更しない）: ステータス画面（#statsdialog）のカード内の
  「Lv.○ · 前衛／後衛」表記、酒場・並び替え画面の前衛／後衛ラベル。
- 間隔: パーティー表示（.party-wrap）と十字キー（.controls）の間を少し広げる。
  具体的には .controls に margin-top:8px を追加する（現行は余白なし、
  .controls 自体の padding 7px のみ）。他の余白は変更しない。
