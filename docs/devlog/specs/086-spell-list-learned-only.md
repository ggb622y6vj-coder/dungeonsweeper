# 086 ステータス画面の呪文リストを習得済みのみにし、戦闘専用をグレーアウトする

## ユーザーの要望（原文）

> 魔法使いと僧侶の呪文ですが、各人のステータスから確認できる呪文は、解放されているものだけをリストアップするようにしてください。また、戦闘でしか使えないものはグレーアウトしてください。

## 解釈（ユーザー確認済み）

- 「解放されているもの」は **習得済み** の意味で確定（2026-11-08、ユーザーが「習得済みの呪文だけ表示する」を選択）。レベル解禁済みでも未習得の呪文は表示しない。
- 対象はステータス画面の「呪文」ボタンから開く呪文ダイアログ（`openMagic` / `renderMagic`）。このダイアログは戦闘中の呪文選択と共用なので、戦闘側のリストも同じく習得済みのみになる（戦闘で唱えられない呪文が消えるのは整合的）。
- 「戦闘でしか使えないもの」は使用場面が戦闘のみの呪文（`where === 'battle'`）。グレーアウトは **戦闘中でないとき**（探索中・宝箱対峙中）に適用する。戦闘中は通常どおり選べる。
- 図書館の呪文カタログ（全呪文を載せる資料）は対象外で、従来どおり全呪文を表示する。

## 実装

`dist/spells.js` の `renderMagic()` を変更する。

1. リストの母集合を「そのメンバーの職業の呪文のうち、習得済み（`m.known` に含まれる）のもの」に絞る。既存の戦闘中の誘惑除外（`s.enemy && x.id==='tempt'`）は維持する。
2. 戦闘中でないとき、`where === 'battle'` の呪文行をグレーアウトする。行を `disabled` にし、見た目がグレーになるようにする（既存の `.spellrow:not(.learned)` の減光表現に倣うか、専用の見た目を用意する）。行内の理由表示（戦闘専用）は残し、なぜ使えないかは読めるようにする。
3. 習得済みの呪文が1つもないメンバーでは、空のリストにせず「習得済みの呪文がありません」等の空状態を1行表示する。
4. 行の小テキストから、不要になる未解禁・未習得の分岐表示は整理してよいが、習得済み・Lv・習得方式（確定習得／習得率50%）と使用不可理由の表示は維持する。

## 対象外

- 呪文データ（`MAGIC` の内容・使用場面・対象・効果）、習得判定、セーブ形式には触らない。
- 図書館（`dist/library.js`）の呪文一覧は変更しない。
- 戦闘中の呪文選択の挙動（理由がある行は選択不可）は変えない。

## 検証

- node テスト全件、ブラウザテスト全件（1280px / 390px）、`scripts/compile-monsters.py --check`、sim selftest、MANIFEST 照合。
- 実経路の確認：探索中にステータス画面から呪文ダイアログを開き、(a) 未習得・未解禁の呪文が並ばないこと、(b) 習得済みの戦闘専用呪文（例：火炎）がグレーアウトされ選択できないこと、(c) 習得済みの探索呪文（例：治療・強壮）は従来どおり対象を選んで唱えられること、(d) 戦闘中は戦闘専用呪文がグレーアウトされず選べること。
- 既存テストに未解禁・未習得の表示を前提とするものがあれば、本仕様に合わせて追随させる。
