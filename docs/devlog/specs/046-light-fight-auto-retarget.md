# 046 [light] 「戦う」の対象列が全滅していたら自動で別の列へ切り替える

## 背景
現状、戦うで指定した敵グループが行動時に全滅していると「〇〇の攻撃対象の列は全滅している。」と出てターンが無駄になる。呪文はすでに無言で切り替わる。

## 仕様
- partyAction() / selectedEnemy() の `!e` 分岐で、reachableEnemyGroups(i) のうち最も前の生存グループへ自動で対象を切り替えて攻撃する。
- 新しいログは出さない（切替は無言）。「攻撃対象の列は全滅している。」ログは、到達可能な生存グループが1つもない場合のみ残す（通常は戦闘終了しているはず）。
- 近接は前2列、射程武器は全列という到達ルールは変更しない。
- 呪文の既存の自動切替挙動は変更しない（ログも追加しない）。

## OKの判定方法
- 前列グループを狙う「戦う」を2人で入力し、1人目で全滅させる → 2人目は次の到達可能グループを攻撃し、ターンが無駄にならない。
- その際「全滅している」ログも新しい切替ログも出ない。
- 近接キャラが3列目以降へ切り替わらないこと。射程武器は全列から選ばれること。
- 既存テスト全通過＋上記ケースのテスト追加。
