# 023c-light-town-full-heal（023b は取り下げ・ユーザー決定）

## 目的
ユーザーの意図：「町に戻ったら全回復」は原作の馬小屋→回復魔法の往復を避けるための意図的な仕様。023 で外した帰還時の全回復を戻す。

## 変更
1. enterTown（迷宮から帰還）で status==='ok' のメンバーの HP/MP を全快に戻す（023 以前の挙動）。dead/ash/lost は回復しない（020 の仕様維持）。
2. レベルアップは宿屋で行う仕様を維持。馬小屋（無料）でレベルアップ＋レベル報告。
3. 「普通の部屋」（有料全快）は帰還で全快するため不要。削除し、宿屋は馬小屋だけにする（UI文言も「宿屋：馬小屋に泊まってレベルアップ」等に調整）。
4. 023b（馬小屋でHP25%回復）は実装しない。
5. tests を新仕様に更新：帰還で ok は HP/MP 全快・dead は HP0 のまま、馬小屋で ok 全員がレベルアップ（全員分の Lv を検証）、部屋ボタンが存在しない。既存アサーションは仕様変更に必要な分以外弱めない。
6. BALANCE.md / SPECIFICATION.md 更新。

## OKの判定方法
- tests/*.cjs, compile-monsters --check, sim selftest 全PASS。
- ライブで：迷宮でHPを減らす→帰還→ok全員HP/MP全快、死亡者はHP0のまま→宿屋で馬小屋→レベルアップ報告、部屋ボタンなし。PC/モバイルでエラー0。
