## 目的
既存の即死呪文はラカニト（spells.js:12、魔術師Lv11、MP16、列対象）。成功率 100−敵Lv×6 % は、Wizardry の LAKANITO「各モンスターが (6×Lv)% で抵抗」と同じなので、数値は変えない。ただし、無効な敵（不死・守護者）と抵抗した敵がどちらも「効かなかった」になっていて、プレイヤーには敵Lvが効いたのか分からない。043 と判定を共通化し、Lvの影響が見えるようにする。

## 変更内容
- ラカニトの判定を 043 の `killByMagic(e)` 経由にする。成功率は `max(0, 100 − monsterLevel(e)×6)` のまま（Lv17以上には効かない）。
- 対象外の種族：今は 不死 と boss。マカニトと揃えて 構造体 を加える（窒息呪文なので）。
- ログを分ける。
  - 無効なとき：「〇〇には効かない！」
  - 抵抗されたとき：「〇〇は耐えた。」
- 呪文説明：「選択した列の敵に即死判定（100−敵Lv×6 %、Lv17以上は無効）。不死・構造体・守護者には無効」。

## OKの判定方法
1. node テスト：乱数を固定する。
   - Lv10 の敵は乱数 39.9 で死に、40.0 で耐える。
   - Lv17 の敵は必ず耐える。
   - 不死・構造体・守護者は「効かない」と表示される。
2. 不死・守護者以外の挙動（成功率）は 68b57d8 と同じ。同じシードで、構造体以外の結果が一致する。
3. シムで全階の差が 042 と同じ許容範囲に収まる。
4. 全テストが通る。
