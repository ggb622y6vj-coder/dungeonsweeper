# 074 [light] 図書館の呪文を「魔法使い」「僧侶」タブに分ける

対象コード: origin/main 78d47d6（読み取りのみ）

## ユーザーの要望（原文）
> 町の「図書館」ですが、「呪文」のページは魔法使いの呪文と僧侶の呪文が混在しています。これを「魔法使い」と「僧侶」の呪文でそれぞれタブを分けてこの中に実装してみてください。

## 背景（現状）
- 図書館の上位タブは「モンスター」「アイテム」「呪文」の3つ。
- 「呪文」では `MAGIC` の全呪文を職業の区別なく同じ一覧へ表示している。
- 呪文データには `job` があり、`CLASSES[spell.job].name` で「魔法使い」「僧侶」を判別できる。

## 仕様
1. 図書館の上位「呪文」タブを開いた内容の中に、下位タブ「魔法使い」と「僧侶」を設ける。
2. 「魔法使い」には魔法使い呪文だけ、「僧侶」には僧侶呪文だけを表示する。分類には既存の呪文データの `job` を用い、呪文名のベタ書き一覧を新設しない。
3. 上位「呪文」を開いた直後の既定は「魔法使い」とする。下位タブを切り替えた際は同じ図書館ダイアログ内で一覧だけを即時更新し、先頭までスクロールする。
4. 既存の発見状態を維持する。発見済みは名前・詳細を表示し、未発見は「？？？」だけを表示する。呪文の記録、並び順、詳細ダイアログ、セーブ形式 `ash-v1` は変更しない。
5. 上位タブ（モンスター／アイテム／呪文）の外観と機能は維持する。下位タブは上位タブと視覚的に区別でき、PC・スマートフォン幅の双方で横にはみ出さない。
6. 下位タブはクリック／タップに加えてキーボードで操作できる。選択状態を `aria-selected` で示し、Space／Enterで切り替えられる。既存の図書館のキー操作やEscによる詳細・図書館ダイアログの閉じ方を壊さない。
7. ゲームバランス、呪文データ、Notion同期データ、モンスター／アイテム表示には変更を加えない。

## 変更対象の目安
- `dist/library.js`
- 図書館ダイアログを定義するHTMLファイル
- 図書館タブのスタイルを定義するCSSファイル
- `tests/library.cjs` および必要なブラウザテスト
- `docs/SPECIFICATION.md`、`docs/HANDOFF.md`
- `MANIFEST.sha256`

## OKの判定方法
- 町→図書館→呪文で、内容内に「魔法使い」「僧侶」の2タブが表示される。
- 初期状態では「魔法使い」が選択され、一覧に魔法使い呪文だけが含まれる。
- 「僧侶」へ切り替えると僧侶呪文だけになり、魔法使い呪文は表示されない。再度「魔法使い」に戻すと逆になる。
- 発見済み／未発見（「？？？」）と詳細ダイアログが両方のタブで従来どおり動く。
- マウス／タップとSpace／Enterで切り替えられ、選択タブの `aria-selected="true"` が正しい。
- 1280pxと390pxで横スクロールや表示崩れがなく、スクリーンショットを `docs/devlog/reports/074-shots/` に保存する。
- `node tests/game.cjs` を含む全 `tests/*.cjs` が合格する。関連ブラウザテストも合格する。
- `MANIFEST.sha256` を再生成し、整合チェックが合格する。
