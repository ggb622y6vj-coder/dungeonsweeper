## 変更1: 鍛冶屋ダイアログのヘッダー位置を固定する

原因: `#shopdialog` の高さが中身（タブごとの商品数）で決まり、ダイアログが上下中央に置かれるため、商品の少ないタブ（頭3種など）ではダイアログが縮んで見出し（.dialoghead）の位置が上下に動く。

修正（dist/index.html の CSS のみ）:
- `#shopdialog[open]` を `#magicdialog` と同じ縦フレックス構成にし、高さを固定する: `display:flex;flex-direction:column;height:min(640px,calc(100dvh - 32px))`。
- `.dialoghead`・`.shoptoolbar`・タブ列（.library-tabs）は `flex-shrink:0`、商品一覧 `#shopitems` は `flex:1;min-height:0;overflow-y:auto` として、余分な高さは一覧側のスクロールで吸収する。
- ダイアログの幅・余白・配色、タブや購入ポップアップの挙動は変えない。他のダイアログには触れない。
- 回帰テスト（ブラウザ）: 4タブすべてで .dialoghead の上端Y座標とダイアログの高さが一致すること（1280px／390px）。既存の tests/shop-tabs-browser.py への追加でも新規でもよい。

## 変更3: Notion データベース同期（呪文・モンスター）

読み取り: 2026-11-06 22:25 JST、rows モードで全行取得（モンスター95行・呪文32行）し、data/notion-*.json（072の確定スナップショット）と突き合わせた。

### モンスター: 差分なし
95行すべてスナップショットと一致したため、ゲームデータの変更はない（この事実を報告書に明記する）。

### 呪文: 4件の改名と2件の説明変更
| ID | 項目 | 現在 → Notion |
|---|---|---|
| floodfill | 名前 | ミルワピック → 開放 |
| floodfill | 説明 | 「現在地から周囲に罠のないマスを連鎖的に探索済みにする。使用ごとにMP倍増、帰還でリセット」（括弧書きと「敵とは遭遇しない。」が削除） |

| montino | 名前 | モンティノ → 沈黙 |
| montino | 説明 | 「選択した列の敵に沈黙判定。戦闘終了まで呪文を封じる。守護者には無効」（「成功率は術者と敵のレベル差で変動、」が削除） |

反映手順:
- `data/notion-spells.json` は取得した全行で更新済み（実施者＝Muse が rows 結果から url を除いて生成。変更して差分を隠すのではなく、正本の写しとして更新するもの）。
- `dist/spells.js` の該当4呪文の name と、floodfill・montino の text を合わせる。
- montino は敵も使う: `data/monsters.csv` の呪文欄（モンティノ、2行）と `scripts/compile-monsters.py` の MONSTER_SPELLS のキーを「沈黙」に変え、`python3 scripts/compile-monsters.py` で `dist/monster-data.js` を再生成する。生成物の spellInfo.name が「沈黙」になること。※072 では CSV キーを旧名のまま残す判断をしたが、それは表示名とキーが既に別だった呪文（ハリト等）についてのもので、montino はキー＝表示名だったため、表示名の変更に合わせてキーを変える（図書館の「使用呪文」表示が spellInfo.name を使うため、残すと存在しない呪文名が表示される）。
- `dist/library.js` の「使用呪文」表示: 沈黙呪文は `${spellInfo.name}（沈黙・全体）` と組むため、このままだと「沈黙（沈黙・全体）」と重複する。名前が「沈黙」のときは「沈黙（全体）」と表示するよう直す（他の敵呪文の表示は変えない）。
- 旧名への参照を dist/・tests/・docs/SPECIFICATION.md から洗い、表示名として残っているものは新名に追随する（テストのアサーション変更は表示名の追随として扱う。ID・効果・数値は変えない）。呪文名の色付け（coloredLog 等）が MAGIC の名前を動的に参照しているか確認し、直書きがあれば追随する。
- 検証の要: `node tests/notion-sync.cjs` が差分0で合格すること。compile-monsters の --check、全テスト合格。

### アイテム: 保留（DBの所在を確認中）
モンスター・呪文DBは「迷宮スイーパー仕様書」配下で特定できたが、アイテムDBは検索・最近のページ一覧のいずれでも特定できなかった（ゲーム関係ページが Notion の検索索引に出てこない）。ユーザーにDBのリンクを確認中。判明次第、同じ方式（rows取得→スナップショット化→突き合わせ→反映）を Amendment として追加する。
