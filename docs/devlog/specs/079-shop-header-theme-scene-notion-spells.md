## 変更1: 鍛冶屋ダイアログのヘッダー位置を固定する

原因: `#shopdialog` の高さが中身（タブごとの商品数）で決まり、ダイアログが上下中央に置かれるため、商品の少ないタブ（頭3種など）ではダイアログが縮んで見出し（.dialoghead）の位置が上下に動く。

修正（dist/index.html の CSS のみ）:
- `#shopdialog[open]` を `#magicdialog` と同じ縦フレックス構成にし、高さを固定する: `display:flex;flex-direction:column;height:min(640px,calc(100dvh - 32px))`。
- `.dialoghead`・`.shoptoolbar`・タブ列（.library-tabs）は `flex-shrink:0`、商品一覧 `#shopitems` は `flex:1;min-height:0;overflow-y:auto` として、余分な高さは一覧側のスクロールで吸収する。
- ダイアログの幅・余白・配色、タブや購入ポップアップの挙動は変えない。他のダイアログには触れない。
- 回帰テスト（ブラウザ）: 4タブすべてで .dialoghead の上端Y座標とダイアログの高さが一致すること（1280px／390px）。既存の tests/shop-tabs-browser.py への追加でも新規でもよい。

### D. 新武器15種の特殊効果の実装
効果記述子の種類と発動規則（「現在地の数字」は戦闘が発生したマスの数字 num(pos) 、「周囲8マス」は現在地の周囲8マス、「正しい旗」は実際に罠のあるマスに立てられた旗＝種類を問わない）:
- flagDamage（旗印の斧・導きの斧）: 戦闘開始時に周囲8マスの正しい旗の数を数え、その武器の与ダメージに +本数を戦闘中ずっと加える。
- numberDamage（八目の槍）: 戦闘開始時に現在地の数字をその武器の与ダメージに加える（戦闘中ずっと）。
- zeroSwings（無名の剣・零式の剣）: 戦闘開始時に現在地の数字が 0 なら、その武器の通常攻撃回数 +1（戦闘中。同種効果は重複しない）。
- flagMatchAC（旗印の刃・精算の刃）: 攻撃ごと、周囲8マスの旗の総数が現在地の数字と一致するなら、その攻撃では対象の AC を 1 低く扱う（命中しやすくする方向）。
- flagMatchFirstHit（旗印の弓 +10%・不意打ちの弓 +15%）: flagMatchAC と同じ条件が成立する戦闘で、その武器で最初に命中した通常攻撃のダメージを割合増加（端数は切り捨て）。戦闘ごとに1回まで。
- firstHitUnexplored（魔弓 +25%）: 周囲8マスに未探索マスがある戦闘で、その武器で最初に命中した通常攻撃のダメージ +25%（切り捨て）。戦闘ごとに1回まで。
- victoryDisarm（旗印の戦鎚・封印の戦槌、各10%）: 戦闘勝利時に抽選し、当選したら周囲8マスの正しく旗を立てた罠をすべて解除する（disarmed 化し、旗を外す）。結果をログに残す。
- victoryOpen（旗印の短剣 20%・探査の短剣 100%）: 戦闘勝利時に抽選し、当選したら周囲8マスのうち未探索で安全が確定している（safe）マスからランダムに1つを開く。通常の探索と同様に昇降機の解放判定も行う。結果をログに残す。
- surveyor（測量師の杖）: 装備した本人の呪文に適用。現在地の数字が偶数（0を除く）なら呪文ダメージ +10%（切り捨て）。奇数なら呪文ごとに 10% の確率で消費MPが半分になる（切り上げ）。数字が 0 のときは無効。
- 勝利時効果は、その武器を装備したメンバーが戦闘に参加し生存している場合に発動する。戦闘開始時効果も同様に装備本人の武器にだけ効く。
- テスト: 各効果について、条件を満たす／満たさない両ケースを node テストで検証する（旗の正しさは罠位置で判定されること、勝利時効果の抽選と状態変化、surveyor の偶奇・0 の分岐を含む）。
