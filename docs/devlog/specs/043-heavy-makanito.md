## 目的
オーナーの要望「一定のレベル以下のモンスターを即死させる魔法」を入れる。Wizardry #1 の MAKANITO は魔術師5レベルの呪文で、敵全体が対象。Lv8以上の敵と不死には効かず、それ以外は抵抗判定なしで確実に死ぬ。既存の即死呪文ラカニト（魔術師Lv11、列対象、100−敵Lv×6 %）とは役割が重ならない。マカニトは格下の掃除、ラカニトは確率で格上も狙う、という分担にする。

## 変更内容
- dist/spells.js に27個目の呪文を追加する（id は makanito）。
  - 行：`['makanito','マカニト',1,9,12,true,'battle','all','threshold-death',7,'Lv7以下の敵全体を確実に即死させる。不死・構造体・守護者には無効']`
  - 習得は魔術師Lv9、MP12、敵全体が対象。Wizardry の呪文レベル5は、このゲームの魔術師Lv9段（マモーリスと同じ段）にあたる。
  - しきい値は value=7（Wizardry の「Lv8以上は無効」に合わせる）。
  - 階ごとの効き方：
    - 1〜3F の雑魚（Lv2〜8）はほぼ全滅する。
    - 4F（Lv7〜9）は一部に効く。
    - 5F 以降には効かない。
    - 守護者は対象外。
- 効果 'threshold-death'
  - 次の3つをすべて満たす敵の hp を 0 にし、「息絶えた」と表示する。抵抗判定はない。
    - race が 不死・構造体 ではない。
    - boss ではない。
    - monsterLevel(e) ≤ value。
  - 条件を外れた敵には「には効かなかった」と表示する。
  - 倒した敵は killReward を通し、経験値をもらえる（Wizardry でも経験値は出る。ディスペルと違う点）。
- 判定は「死亡処理ヘルパー」`killByMagic(e)` にまとめる。044 のラカニトも同じヘルパーを使う（044 と同じ PR でも、別でもよい）。
- 既存セーブとの互換：習得済み呪文リストは Lv から計算されるか確認する。保存されている場合は、ロード時に Lv9 以上の魔術師へ付与する。
- シム（combat.cjs の planTurn）：敵に Lv7以下・非不死・非守護者の生存数が3体以上いて MP12 以上あれば、マカニトを使う。

## OKの判定方法
1. tests/makanito.cjs を追加する。
   - Lv7 の人型は確実に死ぬ。Lv8 は無効。
   - 不死・構造体・守護者には無効。
   - 経験値が pendingXP に加算される。
   - MP12 が減る。
   - Lv8 の魔術師は覚えていない。Lv9 で覚える。
2. 旧セーブ（Lv9以上の魔術師がいるパーティ）をロードすると、呪文一覧にマカニトがある。
3. ブラウザ（tests/makanito-browser.py、ライブURLを引数に取る）：
   - 1F 戦闘でマカニトを唱えると敵全員が倒れる。
   - ログに「息絶えた」が出る。
4. シム：
   - 1〜4F は死亡・全滅とも基準以下でよい（下がるのが想定どおり）。
   - 5〜10F は全滅率 +1.0 ポイント以内、戦闘あたり死亡 +0.03 以内（MP をマカニトに割いて回復が足りなくなっていないか見る）。
5. 全テストが通る。呪文数 26→27 を前提にしたテストがあれば更新する。
