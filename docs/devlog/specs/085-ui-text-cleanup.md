「実装の依頼です。実装時のCodexのトークン消費を考え、どのモデルでどの順番に実装すればいいか考えてください。全ての変更が完了したら、ブランチにPushしてください。その後、chatgtpにレビューをまとめてもらうようにしてください。

- 階段などが一人称視点だと未探索の状態でもアイコンが見えてしまうので隠す
- 地図のウィンドウで今何階なのかヘッダーに載せる

## 実装計画（トークン消費を考慮した決定）

- モデルはアカウント既定（gpt-6.1-sol）。Codex CLI からアカウントで使えるモデル一覧を確認する手段がなく、未確認のモデル名の指定は失敗リスクがあるため、これまでどおり既定を使う。
- 4件とも小規模で、変更箇所は事前調査で特定済み。Codex の実行ごとにリポジトリ文脈の読み込み（固定費）がかかるため、関心別に分けず **1回の実行にまとめる**。順序は表示系（変更1→2→3）→データ系（変更4）。
- 検証は実施者（Muse）が全テストと実経路で行う。

## 変更1: 一人称ビューで未探索マスの階段アイコンを隠す

現状: dist/game.js の face(i) が一人称ビュー（正面・左・右）のマスの symbol を決めている。昇降機（E）・守護者（☠）・宝箱（▣）は c.open の場合だけ出るが、降り階段（⇩）と上り階段（⇧）だけ open の条件がなく、未探索でも見えてしまう。

修正: ⇩ と ⇧ も c.open の場合だけ出す。未探索の階段マスは、他の未探索マスと同じ表示（？／安全確認済みの✓／旗）に落ちる。aria-label も同じ symbol を使うため追随する。地図（盤面）側の表示は変更しない。

## 変更2: 地図ウィンドウのヘッダーに現在の階

現状: 地図ダイアログ（#mapdialog）のヘッダーは「地図」だけ。盤面パネル内の .maplocation には「地下N階」が出るが、ダイアログ内では CSS で非表示にされている。

修正: ダイアログのヘッダーに現在の階が分かる表示を載せる（例: 「地図（地下3階）」）。表示は render() で .maplocation を更新している箇所と同調させ、階移動・再抽選後も古くならないようにする。盤面ドック側の .maplocation 表示は現状のまま。

## 変更3: 図書館の薬タブの「薬 n/5」を消す

現状: dist/library.js の薬サブタブだけ、先頭に所持数カウントの段落（`薬 ${所持数}/${MEDICINES.length}`）を出している。他のサブタブにはない。

修正: その段落を出さないようにする。他のサブタブの表示は変更しない。

## 変更4: 旧呪文名の整理

### アイテム説明（dist/items.js）

薬5件の description から「〇〇相当：」の前置きを消し、効果文だけにする（文面の他の部分は変えない）:

- 傷薬: 「味方1人のHPを1d8回復」
- 解毒剤: 「味方1人の毒を解除」
- 気付け薬: 「味方1人の麻痺・睡眠・沈黙・恐怖を治す」
- 上傷薬: 「味方1人のHPを4d4回復」
- 霊薬: 「味方1人のHPを8d3回復」

薬の説明は Notion 同期の対象外（notion-items が照合するのは武器の追加効果のみで、ゲーム側の文面が正本）。

### モンスターの使用呪文（data/monsters.csv → コンパイラ → dist/monster-data.js）

呪文欄の旧名を現在の呪文名に置き換える。対象は CSV の呪文欄に現れる4種:

- ハリト → 火炎（halito、6件）
- マハリト → 大火炎（mahalito、6件）
- ダルト → 吹雪（dalto、3件）
- ティルトウェイト → 魔弾（tiltowait、2件）

scripts/compile-monsters.py の MONSTER_SPELLS のキーも現在名に置き換える（対応する id・対象・ダイス・効果は不変）。未使用の マダルト のキーも 大吹雪 に置き換えて表記を揃える。沈黙 は現在名のため変更なし。再生成はコンパイラで行い、生成物を直接編集しない。

表示への効き方: 図書館のモンスター詳細「使用呪文」欄は spellInfo.name を表示するため現在名になる。戦闘ログは従来どおり id から現在名を引くため不変。notion-sync は spellInfo の name を照合対象に含めない（id・対象・ダイスのみ）ため差分は出ない。Notion 側のモンスターDBには旧名が残るが、それは Notion 側の表記であり本件の対象外（必要なら別途）。

## 検証観点

- 一人称ビュー: 未探索の階段・降り階段マスを正面/左右に置いても ⇧/⇩ が出ないこと。探索済みでは従来どおり出ること。
- 地図ダイアログ: ヘッダーに現在の階が出て、階移動後に追随すること。
- 図書館: 薬タブ先頭に「薬 n/5」が出ないこと。他タブ不変。
- 同期: notion-sync / notion-items とも差分0。compile-monsters --check 合格。
- 全 node テスト・全ブラウザテスト合格。
