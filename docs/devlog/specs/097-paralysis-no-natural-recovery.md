# 指示書097 — 麻痺の自然回復を廃止する

## ユーザー要望（原文）

> 麻痺を自然に治らないようにしてください

背景：初代 Wizardry との状態異常仕様の比較調査（2026-11-10、この開発チャット）で、原作の麻痺は自然回復せず、強壮（DIALKO）か寺院で治すまで行動不能であること、本作はカウンタ4の経過で自動回復する点が最大の差分と判明したことを受けての指示。

## 解釈（Muse が選択し、仕様として固定する）

- 「自然に治らない」は、ダンジョン内での時間経過（移動・戦闘ターン・逃走試行）で麻痺が解けないこととする。
- 治療経路は現行のものをすべて残す：強壮（dialko）、気付け薬、真回復（madi）の restore 効果、石化付与時の異常リセット、死亡、そして町帰還時の全異常リセット（`enterTown()` の `freshAilments()`）。町帰還で治る点は、原作で毒が城帰還時に自動で治るのと同じ位置づけとし、本作の帰還リセットの既存設計を変えない。寺院での麻痺治療（有料）のような新フローは作らない。
- 毒・睡眠・沈黙・恐怖・石化の仕様は変更しない。沈黙と恐怖の戦闘ターン経過による減少・戦闘終了時の解除も現行どおり。

## 現行挙動（変更前）

- `dist/game.js` の `afflict(i,'paralysis')` が `s.ailments[i].paralysis=4` を設定する。
- `tickAilments()` が呼ばれるたび（移動時 `cell()`、戦闘ターン実行時、逃走時）に `paralysis` を1減らし、0になると「{名前}の麻痺が解けた。」とログして自然回復する。自然回復はこの1か所だけ。
- `docs/SPECIFICATION.md` 23行目に「麻痺はカウンタ4から同じタイミングで減少し、解除時はログ」と明記されている。

## 変更内容

1. `dist/game.js` の `tickAilments()` から麻痺カウンタの減少と自然回復ログを削除する。毒ダメージの tick、末尾の全滅判定と `autoReorderParty('ailment-tick')` は現行どおり残す（毒で倒れた場合の並び替えは従来どおり必要）。
2. 麻痺の表現は現行の数値カウンタ（>0 で麻痺中）を維持する。`afflict` の設定値（4）は変更しない。セーブ形式・移行処理（`normalizeAilments` 等）は変更しない。旧セーブで麻痺カウンタが残っているメンバーは、読み込み後も麻痺したままとなり、治療するまで解けない（移行不要）。
3. 麻痺中の扱いは現行どおり：行動不能（`partyIncapacitated`）、戦闘コマンド不可、逃走率計算から除外、自動並び替えの対象。変更しない。
4. `docs/SPECIFICATION.md` を新しい挙動に合わせて更新する。少なくとも23行目の麻痺の文を「麻痺は自然回復しない。強壮・気付け薬・真回復、または帰還でのみ解除される」という趣旨に書き換える。28行目・30行目など「麻痺カウンタ」「毒・麻痺tick」に触れる箇所も、現行挙動と矛盾しない表現にそろえる。HANDOFF.md の過去の記述は履歴として書き換えない。

## テスト

- `tests/auto-reorder.cjs` の「natural paralysis expiry」シナリオ（麻痺1を `tickAilments()` で0にして並び替えを確かめる部分）は新仕様と矛盾するため書き換える。tick では麻痺が解けないことを assert し、並び替えの確認は治療経路（探索中の強壮または気付け薬による解除）で行う形にし、検証範囲を減らさない。末尾のサマリ文言も新しい内容に合わせる。
- `tests/ailments.cjs` に回帰テストを追加する：麻痺を付与したあと `tickAilments()` を複数回呼んでも（移動経路でも）麻痺が解けないこと、強壮で解けること、帰還で解けること。
- 既存テストの期待値を新しい挙動に合わせて直す場合も、期待値を緩めたりテストを削除したりしない。麻痺の自然回復に依存する他のテストがあれば、同様に治療経路へ置き換える。
- 新規テストファイルを増やす場合は `tests/game.cjs` への登録を忘れない。

## 検証

- `node tests/game.cjs` 全件合格
- `python3 scripts/compile-monsters.py --check` 合格
- ブラウザテスト全件（`tests/*-browser.py`）合格
- sim selftest 合格
- MANIFEST.sha256 を再生成し `sha256sum -c` で不整合0

## 制約

- セーブキー `ash-v1` を維持する。敵の HP・能力値をプレイ画面に出さない。ダイスの内部計算をログに出さない。
- バランス数値（罠の麻痺確率、敵の麻痺付与率など）は変更しない。
- push と main 統合はユーザーの承認後に別途行う（この指示書の範囲は hold/097 での実装と検証まで）。
