# 指示書120 仕様: 図書館のモンスター情報の拡充と圧縮

## 1. モンスター詳細への項目追加（dist/library.js）

`libraryMonsterDetails` に2項目を追加する。表示は特定済みモンスターのみ（現行どおり。未遭遇・目撃のみの表示は変えない）。

- 「集団数」を「出現階」の直後に追加。データは `d.groupSize`（[最小, 最大]、出現数はその範囲の一様抽選）。ダイス表記へ変換する：
  - 最小＝最大なら、その数だけ（例：`1`）
  - それ以外は `1d(最大-最小+1)` に、最小が2以上なら `+(最小-1)` を付ける（例：[1,2]→`1d2`、[2,4]→`1d3+1`、[1,5]→`1d5`、[3,5]→`1d3+2`）
  - 変換は libraryDice の近傍に小さなヘルパーを置く。
- 「呪文抵抗（魔／僧）」を「攻撃回数」の直後に追加。値は魔法使い抵抗・僧侶抵抗を百分率の整数で `魔/僧` の順に並べた文字列（例：`30/50`、`0/0`）。%記号は付けない。データは `d.mageResist` / `d.priestResist`（0.0〜0.7 の小数、5%刻み）で、`Math.round(x*100)` で整数化する。

追加後の項目順：種族、出現階、集団数、HP、物理ダメージ、攻撃回数、呪文抵抗（魔／僧）、特殊能力、使用呪文、経験値、撃破数（全11項目）。

## 2. モンスター情報の2列表記（dist/index.html の CSS）

- モンスタータブの各エントリの詳細リスト（dl）を、1行に2項目（ラベル＋値の組が横に2つ）並ぶグリッドにする。項目は上記の順序のまま横に流れる。
- 対象はモンスタータブだけ（`#librarybody.library-monsters` 配下に限定する）。アイテム・呪文タブのリストは現行の1項目／行のまま変えない。
- ラベル列は内容に応じた幅（auto）とし、値列が残りを分け合う形を基本とする。特殊能力のタグは値の中で折り返してよい。
- 390px 幅でも読めること（ラベルと値が潰れて重ならないこと）。どうしても収まらない場合の調整は最小限にし、報告に明記する。
- CSS の運用ルール（1行1規則、色は :root トークン経由）を守る。新規ルールが必要なら追加してよく、その場合は tests/css-structure.cjs の固定値（ルール数など）を追従修正し、報告に明記する。

## 3. 進捗表示の移動（dist/index.html）

- `<p id="libraryprogress">`（「モンスター X/100 · アイテム Y/76」）を、現在の見出し下の独立行から、ダイアログ見出し行 `.dialoghead` の中、閉じるボタン `#libraryclose` の直前（左隣）へ移す。
- 見出し行の中で右寄せの組（進捗＋×ボタン）になるよう最小限の CSS を当てる。`role="status"` とテキスト内容の生成（renderLibrary の textContent 設定）は変えない。
- 独立行が消えた分、本文 `#librarybody` の表示領域が広がること（ダイアログのレイアウト構造上そうなることを確認する）。
