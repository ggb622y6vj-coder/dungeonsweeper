# 指示書091：発動中の呪文の確認・重複使用防止、気付け薬ログの色、装備ボタンの出し分け

## ユーザーの要望（原文）

> 実装の依頼です
>
> - 気付薬の使用ログで「沈黙」が呪文の色になっている
> - 呪文を唱えた後に効果が残り続けるものを、パーティーステータス画面で確認できるようにする。「パーティー」と書いてあるヘッダーの横に、「発動中の呪文」というボタンを設置し、透視・大透視の呪文を唱えたなら「透視」状態が確認でき、効果がわかるウィンドウを開くようにする。それ以外の効果が続く呪文の状態も定義し、確認できるようにする。「発動中の呪文」ボタンは、発動している効果のある呪文がなければ見えない。また、その効果が発動している最中は、パーティー全体で同様の効果を使う呪文がグレーアウトし、使えないようにする
> - 職業によって装備できない装備を持っている時、アイテム欄に「装備」のボタンが出ないようにする

## 変更1：気付け薬の使用ログで「沈黙」が呪文色になる（dist/game.js の coloredLog）

### 原因（実施者の調査）

- coloredLog() は呪文名を部分一致で色付けする。「沈黙」は呪文名（montino）でもあるため、状態異常の名前として出てくる文中の「沈黙」まで呪文色になる。
- 該当ログ：気付け薬（気付薬、id は paralysisCure、spell は dialko）の使用時と、強壮（dialko）で治したときの「〇〇の麻痺・睡眠・沈黙・恐怖が解けた。」（dist/items.js の useMedicine、dist/spells.js の cure 効果）、気付け薬が使えないときの「〇〇は麻痺・睡眠・沈黙・恐怖していない。」、沈黙が自然に解けたときの「〇〇の沈黙が解けた。」（dist/game.js）。
- 073 ではアイテム名を「分割できない1語」として色付け対象から外した。本件も同じ考え方で、状態異常を列挙する語句を色付けしない語句として扱う。

### 修正

- coloredLog() に、アイテム名と同様に色を付けない語句の一覧（plain な語句）を持たせ、次の2語句を入れる。
  - 「麻痺・睡眠・沈黙・恐怖」（状態異常の列挙。薬と強壮の使用ログ・不可ログに出る）
  - 「沈黙が解けた」（沈黙の自然解けログ）
- 呪文「沈黙」を唱えたログ「〇〇は沈黙を唱えた。」の「沈黙」は従来どおり呪文色のままにする。敵が沈黙したログ「〇〇は沈黙した。」も変更しない。
- ログの文言、薬と呪文の効果、セーブは変更しない。

## 変更2：発動中の呪文（持続効果）の確認と重複使用の防止

### 状態の定義（実施者の調査に基づく解釈）

唱えた後にパーティー側の状態として残り続ける呪文は、現行コードでは次の3グループ。

| 状態名 | 呪文 | 状態の置き場 | 続く期間 |
|---|---|---|---|
| 透視 | 透視（milwa）／大透視（lomilwa） | s.milwaSteps（透視は30歩）／ s.light（大透視） | 透視は残り歩数、大透視は町へ戻るまで |
| 警戒結界 | 警戒結界（watchful） | s.watchful | 町へ戻るまで |
| 鉄壁 | 鉄壁（teppeki） | s.teppeki | 町に戻るまで |

- 透視と大透視は、ユーザーの指定どおり同じ「透視」状態として扱う（どちらが発動していても状態名は「透視」）。
- 対象外とするもの：防御（kalki）・大防御（matu）は戦闘中だけ敵側の戦闘状態（s.enemy.partyAC）に残るもので、戦闘が終われば消えるため、この画面の対象にしない。敵への弱体（減退など）も敵側の状態なので対象外。判別（dumapic）・開放（floodfill）は即時効果で、残るのは使用回数によるMP増加だけなので対象外。この解釈は報告書にも明記する。

### ボタンとウィンドウ（dist/index.html、レンダリング側）

- パーティーステータス画面（#statsdialog）のヘッダー（「パーティー」の見出しがある .dialoghead）に「発動中の呪文」ボタンを置く。
- 発動中の状態が1つもなければボタンは見えない（hidden）。状態が変われば表示も追随する（renderStats／render の再描画で hidden を更新する）。
- ボタンを押すとウィンドウ（ダイアログ）を開き、発動中の状態ごとに「状態名」「効果の説明」「残り期間」を表示する。
  - 透視：効果は呪文の説明（左右斜め前のマスを壁越しに表示。未探索の数字は隠したまま）。残り期間は、大透視なら「町へ戻るまで」、透視なら「あとN歩」（s.milwaSteps）。
  - 警戒結界：敵の奇襲を防ぐ。「町へ戻るまで」。
  - 鉄壁：味方全員のAC-2。「町に戻るまで」。
- ダイアログの作りは既存のダイアログ（地図ダイアログ等）に倣い、閉じるボタンを付ける。

### 重複使用の防止（dist/spells.js）

- ある状態が発動している間、その状態のグループに属する呪文は、パーティーの誰が唱える場合でも使えないようにする。判定は spellReason() に集約し、理由文字列は「発動中」とする（既存の理由表示・グレーアウトの仕組み（086）に乗る）。
- 置く位置は spellReason() の最後（MP不足などの他の理由より後）で、既存の理由の優先順位を変えない。
- これにより探索中の呪文一覧（renderMagic）と戦闘中の呪文選択（chooseBattleSpell、castMagic）の両方でグレーアウト＋使用不可になる。透視の残り歩数を回復するための再唱も不可（仕様としてそうなる）。
- 呪文の効果・MP・習得条件などのデータは変更しない。

## 変更3：装備できない装備に「装備」ボタンを出さない（dist/game.js の renderInventory）

- アイテム欄（#inventoryslots）で、そのメンバーの職業では装備できない装備（weapon(id).classes に jobOf(i) を含まないもの）には「装備」ボタンを表示しない。
- ただし、そのアイテムを現在装備している場合はボタンを残す（「外す」「装備中」の操作ができなくなるのを防ぐ）。売却ボタンや薬の「使う」ボタンは変更しない。
- 装備可否の判定自体（equip() のガード）は変更しない。

## 検証

- node テスト全件（tests/game.cjs）とブラウザテスト全37件を全合格。compile-monsters --check、sim selftest、MANIFEST 照合。
- 実経路の確認：
  - 気付け薬を実際に useMedicine で使い、生成されるログの HTML で「沈黙」が呪文色になっていないこと。あわせて呪文「沈黙」を castMagic で唱えたログでは呪文色になること。
  - 透視を唱えると「発動中の呪文」ボタンが現れ、ウィンドウに「透視」と残り歩数が出ること。大透視では「町へ戻るまで」になること。警戒結界・鉄壁も同様に表示されること。何も発動していなければボタンが見えないこと。
  - 透視の発動中に透視・大透視が spellReason で「発動中」になり唱えられないこと（別の僧侶でも同様）。
  - 装備できない職業のメンバー（例：魔法使いに剣）のアイテム欄に「装備」ボタンが出ないこと。装備できる場合は出ること。
