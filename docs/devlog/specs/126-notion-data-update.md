## 6. 新規武器「伐採の鎌」と種族特効の仕組み

`dist/weapons.js` へ追加：
- id `sickle`、name 伐採の鎌、range は近距離（既存の近距離武器と同じ値）、dice [1,6,2]、classes [0,3,4,6]（戦士・盗賊・侍・忍者）、price 200、sell 100、lootRank 1、drop true、minFloor 1、shop false
- desc：「植物に対して与えるダメージが2倍。」
- effect：種族特効を表す新しい kind を、魔弓の `{"kind":"firstHitUnexplored","pct":25}` と同じ流儀で定義する（例：`{"kind":"raceSlayer","race":"植物","mult":2}`。名前は実装側で既存命名に合わせ可）

挙動（戦闘の物理ダメージ計算）：
- 装備者が物理攻撃（通常攻撃・奇襲とも）で、種族が「植物」の敵に命中した場合、確定した物理ダメージ合計を2倍にする。
- 倍率は既存の倍率チェーン（旗の倍率、奇襲の2倍）と同じ「確定合計への乗算」として重ねる。奇襲と併用した場合は 2×2=4倍。MP吸収は倍率適用後のダメージを入力とする（奇襲の現行規則と同一）。
- 呪文・アイテム・ブレスには影響しない。味方への攻撃や敵の攻撃には適用しない（武器効果は装備した味方の攻撃のみ）。
- ログやUIに倍率の内訳・ダイス内部計算を出さない（既存ルール）。
