## 目的
状態異常「恐怖」を追加する。

## 効果の選択: 「戦う」ができない（防御・呪文・アイテムは可）
- 「行動不能」は麻痺と重複、「勝手に逃げる」は6人パーティ一括の逃走システムと衝突し隊列（032）も乱す、「命中低下」は数値に埋もれて体感しにくい。
- 「殴れないが呪文や防御はできる」は沈黙（呪文不可・攻撃可）と対になり、戦士系に効き術者には効きにくいという役割差が出る。

## 変更内容
- `ailments[i].fear`（残りターン数）。かかると **3**、戦闘ターンごとに −1、0で「〇〇は落ち着きを取り戻した。」。**戦闘終了で0**。
- 恐怖中は「戦う」コマンドがグレーアウト（理由の表示は「恐怖で攻撃できない」）。
- 治療: **ディアルコ**（説明「麻痺・睡眠・沈黙・恐怖を治す」）・**マディ**・**気付け薬**。新アイテムなし。
- 032 自動並び替え: **対象外**。理由: 防御で前衛の盾役は果たせ、3ターンで治る一時異常。毎回隊列が動くと煩雑。
- 帰還: freshAilments で解除。
- 味方の恐怖呪文は追加しない。Wizardry の MORLIS/MAMORLIS は本来「恐怖」の呪文で、本作ではモーリス/マモーリス（敵AC低下）として既に実装済み。説明文に「敵を怯えさせ守りを崩す」と追記するだけ。
- 敵の付与（CSV 状態異常列に `恐怖/命中時N%` を追加、compile-monsters で 'fear' に変換）:
  - 亡霊 6F 15% / 地獄の猟犬 7F 15% / 魔界の猟犬 9F 15% / 死神 10F 20%
- monsterOnHit が fear を扱う（既存の毒・麻痺・石化と同じ判定経路）。
- 表示: 状態タグ `恐怖`（.ailment-fear）、図鑑の特殊攻撃欄に「恐怖 15%」。
- sim: 恐怖メンバーは攻撃不可→ 呪文が使えれば呪文、なければ防御。

## OKの判定方法
1. node: 死神の命中10000回で恐怖付与率 20%±1.5%、他3体 15%±1.5%。
2. fear=3 → 3ターンで0、戦闘終了・帰還・ディアルコ・マディ・気付け薬で0。
3. 恐怖中は攻撃コマンド不可、防御・呪文・アイテムは可。恐怖メンバーは自動並び替えで動かない。
4. compile-monsters --check・selftest PASS。tests/fear.cjs と fear-browser.py を新規追加、ブラウザ（1280/390）で表示確認。
