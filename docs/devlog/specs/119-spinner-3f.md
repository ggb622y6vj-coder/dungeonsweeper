# 指示書119 仕様: 3F の回転床

- 日付：2026-11-19
- ブランチ：hold/119（基準 main 979be3b）
- 経緯：ユーザーの発案。3F に、入るとプレイヤーの向きが変わる「回転床」を設ける。個数は個数方式（ユーザー決定：1d4個）。実装担当は Codex（ユーザーが指定）。
- 同時に確認した件（実装なし）：反呪文の結界内では探索中も呪文が打ち消される（指示書117の実装どおり、全詠唱が castMagic を通る）。呪禁の旗は探索中の詠唱でも既に効果がある（罠マスに置いた正旗の抽選で発動し MP 半減。仕様書の記載どおりで、実機でも確認済み）。

## 生成

- 対象は地下3階のみ。他の階には生成しない。
- 3F の階生成（fresh）で、罠と特殊マスの配置が終わった後に、1d4（1〜4）の個数を振り、その数だけ対象マスから重複なくランダムに選んで回転床にする。
- 対象マス：罠がなく（`trap` が false）、特殊マスでない（`type` が空）通常マス。
- 回転床はマスの属性として保持する（例：セルオブジェクトに `spin: true`）。既存の階保存（rememberFloor／セーブ）でそのまま残ること。古いセーブのマスには属性がない（= 回転床でない）として扱い、セーブ形式の版数は変えない。
- 回転床は永続する。何度入ってもそのたびに発動する。旗を立てても消えない。

## 発動

- プレイヤーが通常移動（歩行）でそのマスに入ったときだけ発動する。移動が確定した時点で、プレイヤーの向き `s.dir` を 1d4 でランダムな向き（0〜3、今と同じ向きになる場合もあり）に変える。
- 発動しない経路：その場での方向転換、転移の罠、落とし穴、転移呪文、階段・昇降機での到着、戦闘からの逃走・守護者戦の回避など、歩行以外の位置変更では発動しない（setPlayerPosition の共通処理には入れないこと。歩行の移動処理の中でのみ判定する）。
- マスは通常の移動どおり探索済み（open）になる。回転は移動に付随する処理で、ログは出さない。
- 移動先で戦闘や罠などの処理が起きる場合でも、回転は1回だけ静かに適用される（適用順序は移動処理の自然な流れに任せるが、ログや表示に回転を示す要素を足さない）。

## 表示

- 回転床は目視できない。盤面・地図ダイアログ・一人称視点のどこにも印や追加の描画を出さない。プレイヤーは一人称視点の景色の変化でだけ気づける。
- 3F の地図ブラインドゾーン（指示書115）とは無関係に生成・発動する（ゾーン内にも生成されうる）。

## テスト（新規）

- `tests/119-spinner-browser.py` を新規追加する（115〜118 のブラウザテストの様式に従う）。検証内容：
  1. 生成：fresh(3) を複数回生成し、毎回、回転床が1〜4個で、すべて対象マス（罠なし・特殊マスでない）にあること。他の階（2F・4F）には生成されないこと。
  2. 発動：既知の回転床マスへ歩いて入り、乱数を固定して、向きが振られた値に変わること、ログが増えないこと、マスが探索済みになること。
  3. 非発動：歩行以外の到着（例：同階への転移呪文で回転床マスへ着地）では向きが変わらないこと。
  4. 永続性：階の保存・再読み込み（セーブ→リロード）後も回転床の位置が同じであること。同じマスに再度入ると再度発動すること。
- 既存テストは原則変更しない。新仕様で壊れるものがあれば最小限の追従修正にとどめ、報告に明記する。
