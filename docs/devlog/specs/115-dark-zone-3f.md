# 指示書115: 3F中心部の「地図が見えない」ゾーン

> 2026-11-18 にユーザーが承認し、実装担当に Codex を指定した。Muse の解釈提示をユーザーが承認済み。ゾーン出入り時のログは出さない（ユーザーが明示）。

## 背景と決定
- 3F のマップ中心から半径3マスの範囲を、そのマスにいる間だけ地図（盤面）の描写が隠れるゾーンにする。
- 一人称視点など、それ以外の機能はいつも通り使う。これは原作 Wizardry の暗闇ゾーンに近い仕掛けを、本作の盤面表示に適用するもの。

## 定義
- 3F の盤面は 12×12（`size = min(12, 6 + floor*2)`）。セルの座標は x = i % size、y = i / size の整数部。
- 中心は盤面の幾何中心（(size-1)/2, (size-1)/2）= (5.5, 5.5)。
- ゾーン = 中心からのユークリッド距離が 3 以下のセル（3F で 32 マス）。
- ブラインド状態 = `s.floor === 3` かつ現在地 `s.pos` がゾーン内。状態は保持せず、描画のたびに階と現在地から導出する。

## 仕様
### ブラインド中の盤面描画（#board）
- 全セルを一様に描く。次を一切出さない：開閉の区別、周囲の罠の数字、階段・昇降機・守護者・宝箱・遺体のグリフ、旗、safe の ✓、現在地マーカーと方向マーカー、in-view のハイライト、旗視界カウント。
- 見た目は専用の CSS クラスで統一する。色は既存のパレットトークンのみを使う（新しい色が必要なら :root にトークンを追加し、tests/css-structure.cjs を通過させる）。
- セルの aria-label からも情報を漏らさない：周囲の罠の数、現在地・遺体・昇降機などの内容を含めず、全セル共通の中立なラベルにする。
- セルはボタンのまま data-i を保持し、クリックによる移動・探索は通常どおり機能する。キーボード操作も通常どおり。

### 変更しないもの
- 一人称視点（scene）、移動コントロール、戦闘、呪文（dumapic の調査結果など呪文の効果は地図描画ではないので通常どおり）、パーティ・ステータス表示、ログの挙動。
- ゾーンへの出入りでログは出さない（ユーザー決定）。
- セーブ形式（ash-v1 のまま。新フィールドを追加しない）。
- 3F 以外の階（4F 以降も 12×12 だが対象外）。
- ゾーンを出れば即座に通常描画に戻る。探索済みの情報は消えない。地図ダイアログは同じ #mappanel を表示するため、ブラインド中はそちらも隠れる（個別対応は不要だが、そうなっていることを確認する）。

### 実装の目安
- ゾーン判定の小さなヘルパーを用意し、render() の盤面生成分岐でのみ使う。render() 全体の再構成はしない。
- 守護者・階段などがゾーン内に配置されることはありうるが、イベント・戦闘は現在地ベースで通常どおり発生する（変更しない）。

## テスト
- ブラウザテストを新規追加する（tests/115-dark-zone-browser.py、既存の *-browser.py の流儀に合わせる）：
  1. 3F で現在地をゾーン内へ移すと、全セルの表示内容が一様で、数字・現在地マーカーが出ない。
  2. 現在地をゾーン外へ移すと通常描画に戻る。
  3. 2F の中心付近ではブラインドにならない。
