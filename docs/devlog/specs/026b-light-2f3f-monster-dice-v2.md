## 目的
## 目的
2F 一律 2d6 による 1F→2F の崖を緩める。026a は 3F を 2d6+1 まで下げて 3F が軽くなりすぎ、「2F が 3F より難しくない」を満たせなかった。3F の緩和を小さくする。ガーディアン（深層の魔将・奈落の監視者）とブレスは変えない。
## 変更内容（data/monsters.csv → scripts/compile-monsters.py）
- 2F: 2d6 → 1d8+1（毒スライム, 亡霊騎士, オーク戦士, 大蜘蛛, 洞窟の魔術師, 山賊の頭目, 腐肉食い, 石の番人）、火蜻蛉 2d5 → 1d8（026a と同じ）
- 3F: 3d6 → **2d6+2**（酸性スライム, 骸骨の射手, オーク呪術師, 影の盗人）、黒牙狼 3d9 → **2d8+2**
## OKの判定方法（scripts/sim/combat.cjs --jobs 0,0,2,3,1,2 --n 600）
- 装備なし: 2F Lv2 通常戦 勝率 ≥84%（試算 86.5%）、3F Lv3 通常戦 ≥66%（試算 66.0%）。
- --gear shop ガーディアン勝率 89-100%: 2F Lv2 / 2F Lv3 / 3F Lv3 / 3F Lv4（試算 94.3 / 97.8 / 96.2 / 96.0%）。
- --gear shop: 2F Lv2 通常戦の死者/戦 ≤ 3F Lv3 通常戦の死者/戦（試算 0.213 ≤ 0.227）。
- compile-monsters.py --check が通る。monsters.csv の差分は上記 14 行のみ。
- 回帰テスト: 上記モンスターのダメージダイス値を tests/ で検証。
## 参考（n=600, e54494b ベースのスクラッチ）
- 3F 据え置き案: 3F Lv3 死者 0.182 < 2F 0.213 → 不合格、装備なし 3F 64.3%。
- 2F を 1d8 まで下げる案: 2F Lv2 死者 0.192 でも 3F 据え置き 0.182 を下回らず不合格。
- sim は seed 固定で再実行しても同値。死者/戦の差は ±0.03 程度の誤差域なので、境界ぎりぎりの点は注意。
