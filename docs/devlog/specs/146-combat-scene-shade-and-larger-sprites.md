# 指示書146: 戦闘中の背景を暗くし、モンスター画像を少し大きくする

日付: 2026-11-26
担当: Codex（gpt-6.2-sol・medium）

## 背景と目的

オーナー指示:「モンスターとの戦闘時、背景を全体的にちょっと暗くして、モンスターのアイコンを強調する。モンスターのアイコンを今より若干拡大する。」

解釈（オーナー確認済み）:
- 対象は戦闘中（敵が表示されている間）のシーンだけ。町・通常探索・守護者の待機表示は変えない。
- 暗くするのは背景（壁・床）だけ。モンスター画像・左上の列一覧・遭遇通知には暗幕をかけず、相対的にモンスターを浮き上がらせる。追加の縁取りや発光は入れない。
- 拡大はモンスター画像（種族ドット絵）の目標サイズを現行の1.15倍にする。48の倍数への条件付き丸め（指示書144）はそのまま。

## 変更内容

### 1. 戦闘中の暗幕

- `scene()`（dist/game.js）が戦闘シーンを描くときだけ、背景SVGの上・モンスター画像の下に、黒・不透明度0.2の幕を1枚重ねる（例: `position:absolute; inset:0; background:#000; opacity:.2; pointer-events:none` の要素を SVG の直後・画像より前に挿入）。
- 左上の列一覧（.scene-enemies）と遭遇通知は幕より手前に出る（現行の重なり順を保つ）。
- 画像の読み込みに失敗したときの代替表示（枠＋icon文字）はSVG内にあるため幕の下になる。これは許容する（通常時は発生しない）。
- CSSは既存の運用に合わせる（1行1規則、色は必要なら :root トークンを追加）。

### 2. モンスター画像の拡大

- `enemySpriteSize()`（dist/game.js）の目標サイズを現行の1.15倍にする。計算の形（画面幅・高さからの導出と、48の倍数への条件付き丸め＝丸めた値が目標の±15%以内なら採用）は変えない。
- 画像の位置（下端25%、列ごとの中心）、色付けフィルタ、読み込み失敗時の代替表示は変えない。

## 変えないこと

- 戦闘以外（町・探索・守護者待機・遭遇通知の表示中を含む戦闘開始前）のシーン描画。
- 敵の列一覧の内容・位置・大きさ。
- ゲームのロジック、データ、セーブ形式。

## テスト

- tests/enemy-display-browser.py の画像サイズの期待値を新しい目標サイズ（1.15倍）に合わせて更新する。あわせて、戦闘中は暗幕が存在し、戦闘でないときは存在しないこと、画像が幕より手前に表示されることを検証に追加する。検証の強さは落とさない。
- tests/css-structure.cjs など構造を固定するテストが新しいCSS規則で失敗する場合は、その固定内容を新しい形に合わせて更新する。
- `node tests/game.cjs` を実行し全 PASS を確認する。
